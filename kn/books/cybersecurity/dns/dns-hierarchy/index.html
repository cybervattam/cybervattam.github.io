ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ವಿನವಲ್ ತೀರ್ವು ಮುರೈ

DNS ಶ್ರೇಣಿ / DNS Hierarchy

ರೂಟ್ ನೇಮ್ ಸರ್ವರ್‌ಗಳು / Root Name Servers

ತರ್ಪೋತು 13 ವೇರ್ ಪೆಯರ್ ವಳಙ್ಕನ್ಕಳ್ 13 ತನ್ನಾಟ್ಸಿ ನಿರುವನಙ್ಕಳ್ ಮೂಲಮ್ ಎವ್ವಳಿ ಪರಪ್ಪು ತಿಸೈವಿತ್ತಲ್ ನೆರಿಮುರೈಯಿಲ್ (Anycast Routing Protocol) ಇಯಕ್ಕಪ್ಪಟುಕಿರತು ಇವೈ ICANN ನಿರುವನತ್ತಾಲ್ ನಿರ್ವಕಿಕ್ಕಪ್ಪಟುಕಿನ್ರನ. ಒರು ವೇರ್ ವಳಙ್ಕನ್, ಒರು ಸುಳಲ್ನಿಲೈ ತೀರ್ವಿಯಿನ್ ವಿನವಲೈ ಏರ್ರುಕ್ಕೊಳ್ಕಿರತು, ಅನ್ತ ಕಳಪ್ಪೆಯರ್ ವಿರಿವಾಕ್ಕಮ್ ಅಟಿಪ್ಪಟೈಯಿಲ್, ಒರು ಮೇಲ್ ನಿಲೈ ಕಳಪ್ಪೆಯರ್ ವಳಙ್ಕನೈ ನೋಕ್ಕಿ ಮಟೈ ಮಾರ್ರಿ ವಿಟೈಯಳಿಕ್ಕುಮ್. https://root-servers.org/

ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈಯಿನ್ ವೇರ್ ಮಣ್ಟಲ ತರವೈ ನಿರ್ವಕಿಕ್ಕಿರತು. ಇತು ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ಮರತ್ತಿಲ್ ವರಿಸೈಕ್ಕು ಮೇಲೇ ಉಳ್ಳತು. ಇನ್ತ ಪಣಿಯಿಲ್ ಉಯರ್ ನಿಲೈ ಕಳಪ್ಪೆಯರ್ ತರವು ಪತಿವಾಳರ್ಕಳ್, ವೇರ್ ಕಳಪ್ಪೆಯರ್ ಸೇವೈಯಕಙ್ಕಳೈ ಇಯಕ್ಕಮ್ ಅಮೈಪ್ಪುಕಳ್ ಮರ್ರುಮ್ ICANN ಇನ್ ಕೊಳ್ಕೈ ಉರುವಾಕ್ಕುಮ್ ಕುಳು ಆಕಿಯವರ್ರುಟನ್ ತೊಟರ್ಪುಕೊಳ್ವತು ಅಟಙ್ಕುಮ್. ವೇರ್ ಮಣ್ಟಲತ್ತಿಲ್ ಪಾತುಕಾಪ್ಪಾನ ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈಯೈ (DNSSEC) ಇಯಕ್ಕುವತರ್ಕಾನ ತಿರವಿ ಒಪ್ಪಮಿಟಲ್ ವಿಳಾವೈಯುಮ್ ಇತು ಸೆಯ್ಕಿರತು. ಸೆಯಲ್ಪಾಟ್ಟಿಲ್ anycast ಇ.ನೆರಿ ಮುಕವರಿಯೈಪ್ ಪಯನ್ಪಟುತ್ತಿ 13 ವೇರ್ ಸೇವೈಯಕಙ್ಕಳ್ ಉಳ್ಳನ. ಪಿಣೈಯತ್ತಿಲ್ ಉಳ್ಳ ಕಣಿನಿಕಳ್ ಒರು ಉಯರ್ ನಿಲೈ ಕಳತ್ತಿನ್ ಮುಕವರಿಯೈ ವಿರೈವಕತ್ತಿಲ್ ಸೇಮಿಪ್ಪತಾಲ್, ವೇರ್ ಸೇವೈಯಕಙ್ಕಳ್ ಅಟಿಕ್ಕಟಿ ವಿನವಪ್ಪಟುವತಿಲ್ಲೈ. ಆನಾಲ್ ಅವೈ ಇಣೈಯ ಕಟ್ಟಮೈಪ್ಪಿನ್ ಒರು ಮುಕ್ಕಿಯ ಅಙ್ಕಮಾಕುಮ್. ವೇರ್ ಸೇವೈಯಕಙ್ಕಳಿನ್ ಇಯಕ್ಕುನರ್ಕಳ್ ಪೆರುಮ್ಪಾಲುಮ್ ತನ್ನಾಟ್ಸಿ ಪೆರ್ರು ಇರುಪ್ಪಿನುಮ್, ಅವರ್ಕಳ್ ಒರುವರುಕ್ಕೊರುವರ್ ಮರ್ರುಮ್ ICANN ಉಟನ್ ಇಣೈನ್ತು ಪಣಿಯಾರ್ರ ವೇಣ್ಟುಮ್

ಉನ್ನತ ಮಟ್ಟದ ಡೊಮೇನ್ ನೇಮ್ ಸರ್ವರ್‌ಗಳು / Top Level Domain Name Servers

ಒರು ಮೇಲ್ ನಿಲೈ ಕಳಪ್ಪೆಯರ್ ವಳಙ್ಕನ್, ಕುರಿಪ್ಪಿಟ್ಟ ಕಳಪ್ಪೆಯರ್ ವಿರಿವಾಕ್ಕತ್ತುಟನ್ ಮುಟಿವಟೈಯುಮ್ ಅನೈತ್ತು ಕಳಪ್ಪೆಯರ್ಕಳಿನ್ ತಕವಲೈಪ್ ಪರಾಮರಿಕ್ಕಿರತು. ಇವೈ ಅನ್ತನ್ತ ಮೇಲ್ ನಿಲೈ ಕಳಪ್ಪೆಯರೈ ತೊಟಙ್ಕಿಯ ನಿರುವನಙ್ಕಳ್ ಮರ್ರುಮ್ ಮೇಲ್ ನಿಲೈ ಕಳಪ್ಪೆಯರ್ ಪತಿವಾಳರ್ಕಳಾಲ್ ಇಯಕ್ಕಪ್ಪಟುಕಿನ್ರನ. ಪೊತು ಮೇಲ್ನಿಲೈ ಕಳಪ್ಪೆಯರ್ (gTLD- .com, .net), ನಾಟ್ಟು ಕುರಿಯೀಟು ಮೇಲ್ನಿಲೈ ಕಳಪ್ಪೆಯರ್ (ccTLD- .in, .uk)

ಅಧಿಕೃತ ನೇಮ್ ಸರ್ವರ್ / Authoritative Name Server

ಕುರಿಪ್ಪಿಟ್ಟ ಪೆಯರ್ ಕೊಣ್ಟ ಕಳತ್ತಿನ್ ತಕವಲ್ಕಳೈಕ್ ಕೊಣ್ಟುಳ್ಳತು. A ಏಟ್ಟಿಲ್ ಕಾಣಪ್ಪಟುಮ್ ಕಳತ್ತಿನ್ ಇ.ನೆರಿ ಮುಕವರಿಯೈ ವಳಙ್ಕುಕಿರತು. CNAME ಏಟು ಇರುನ್ತಾಲ್ ಮಾರ್ರು ಕಳಪ್ಪೆಯರೈ ವಳಙ್ಕುಕಿರತು

ರಿಕರ್ಸಿವ್ ರಿಸಾಲ್ವರ್‌ಗಳು / Recursive Resolvers

ಒರು ಕಳಪ್ಪೆಯರ್ ವಿನವಲಿಲ್ ಇತು ಮುತಲ್ ನಿರುತ್ತಮಾಕುಮ್. ಇತು ಕಿಳೈಯನ್ (Client) ಮರ್ರುಮ್ ಕಳಪ್ಪೆಯರ್ ವಳಙ್ಕನ್ ಇಟೈಯಿಲ್ ಒರು ಇಟೈತ್ತರಕರಾಕ ಸೆಯಲ್ಪಟುಕಿರತು. ಒರು ವಿನವಲಿನ್ ಪತಿಲಾಕ ಮಾರ್ರು ಕಳಪ್ಪೆಯರೈ ಪೆರ್ರಾಲ್, ಅನ್ತ ಮಾರ್ರು ಪೆಯರುಕ್ಕು ಒರು ಪುತಿಯ ಸುಳಲ್ನಿಲೈ ಕಳಪ್ಪೆಯರ್ ವಿನವಲೈತ್ (Recursive DNS Query) ತೊಟಙ್ಕುಮ್. ಸುಳಲ್ನಿಲೈ ತೀರ್ವಿಕಳ್ ಪೆರುಮ್ಪಾಲುಮ್ ಇಣೈಯ ಸೇವೈ ನಿರುವನಙ್ಕಳಾಲ್ ವಳಙ್ಕಪ್ಪಟುಮ್. ಇವೈಯಲ್ಲಾಮಲ್, ಸಿಲ ಪೊತು ನಿರುವನಙ್ಕಳುಮ್ ಸುಳಲ್ನಿಲೈ ತೀರ್ವಿ ಸೇವೈಕಳೈ ವಳಙ್ಕುಕಿನ್ರನ.
