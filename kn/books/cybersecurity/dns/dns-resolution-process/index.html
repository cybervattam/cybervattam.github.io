DNS ದಾಖಲೆಗಳು

ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ವಿನವಲ್ ತೀರ್ವು ಮುರೈ / DNS Query Resolution Process

ಕ್ಲೈಂಟ್ ಡೊಮೇನ್ ಹೆಸರನ್ನು ಕೇಳಿದಾಗ, DNS ಪ್ರಶ್ನೆಯು ಸಾಮಾನ್ಯವಾಗಿ ಈ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಅನುಸರಿಸುತ್ತದೆ:

  1. ಕ್ಲೈಂಟ್ ಸಂರಚಿಸಲಾದ ರಿಸಾಲ್ವರ್‌ಗೆ ರಿಕರ್ಸಿವ್ DNS ಪ್ರಶ್ನೆಯನ್ನು ಕಳುಹಿಸುತ್ತದೆ.
  2. ಉತ್ತರ ಈಗಾಗಲೇ ತಿಳಿದಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಲು ರಿಸಾಲ್ವರ್ ತನ್ನ ಕ್ಯಾಶ್ ಅನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ.
  3. ಕ್ಯಾಶ್‌ನಲ್ಲಿ ಉತ್ತರ ಇಲ್ಲದಿದ್ದರೆ, ಸೂಕ್ತ TLD ಸರ್ವರ್ ಅನ್ನು ಹುಡುಕಲು ರಿಸಾಲ್ವರ್ ರೂಟ್ ಸರ್ವರ್ ಅನ್ನು ಕೇಳುತ್ತದೆ.
  4. ನಂತರ ರಿಸಾಲ್ವರ್ ನಿರ್ದಿಷ್ಟ ಡೊಮೇನ್‌ನ ಅಧಿಕೃತ ಹೆಸರು ಸರ್ವರ್ ಅನ್ನು ಕೇಳುತ್ತದೆ.
  5. ಅಧಿಕೃತ ಸರ್ವರ್ ಸಂಬಂಧಿತ DNS ದಾಖಲೆಗಳನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.
  6. ರಿಸಾಲ್ವರ್ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಕ್ಲೈಂಟ್‌ಗೆ ಕಳುಹಿಸುತ್ತದೆ ಮತ್ತು ಭವಿಷ್ಯದ ಬಳಕೆಗಾಗಿ ಅದನ್ನು ಕ್ಯಾಶ್ ಮಾಡಬಹುದು.

ಈ ಪ್ರಕ್ರಿಯೆಯು ಕ್ಲೈಂಟ್‌ಗೆ ಮಾನವರು ಓದಬಹುದಾದ ಡೊಮೇನ್ ಹೆಸರನ್ನು ಸರಿಯಾದ IP ವಿಳಾಸವಾಗಿ ಪರಿಹರಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.
