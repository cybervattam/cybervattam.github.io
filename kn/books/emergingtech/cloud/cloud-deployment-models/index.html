ಕ್ಲೌಡ್ ವಿತರಣಾ ಮಾದರಿಗಳು / Cloud Deployment Models




1. ಸಾರ್ವಜನಿಕ ಕ್ಲೌಡ್ / Public Cloud

ಕ್ಲೌಡ್ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ ಅನ್ನು ಸಾರ್ವಜನಿಕರಿಗೆ ಅಥವಾ ದೊಡ್ಡ ಸಂಸ್ಥೆಗಳಿಗೆ ನೀಡಲಾಗುತ್ತದೆ. ಈ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರ ಸ್ವಾಮ್ಯಕ್ಕೆ ಸಂಬಂಧಿಸಿದೆ.

ಯಾರೇ ಬೇಕಾದವರು ಕ್ಲೌಡ್ ಸೇವೆಗಳನ್ನು ಬಳಸಬಹುದು.

ಉದಾಹರಣೆಗಳು:

  • ಅಮೆಜಾನ್ ವೆಬ್ ಸರ್ವಿಸ್‌ಸ್ / Amazon Web Services
  • ಮೈಕ್ರೋಸಾಫ್ಟ್ Azure / Microsoft Azure
  • Google Cloud Platform / ಗೂಗಲ್ ಕ್ಲೌಡ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್

2. ಖಾಸಗಿ ಕ್ಲೌಡ್ / Private Cloud

ಈ ರೀತಿಯ ಕ್ಲೌಡ್ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ ಅನ್ನು ಒಂದು ಸಂಸ್ಥೆಯೆಗಾಗಿ ಮಾತ್ರ ನಿರ್ವಹಿಸಲಾಗುತ್ತದೆ.

ಇದನ್ನು ಸಂಸ್ಥೆಯ ಮೂಲಕ ಅಥವಾ ತೃತೀಯ ಪಕ್ಷದ ಮೂಲಕ ನಿರ್ವಹಿಸಬಹುದು ಮತ್ತು ಸಂಸ್ಥೆಯ ಆವರಣದ ಒಳಗೆ ಅಥವಾ ಹೊರಗೆ ಇರಬಹುದು.

ಉದಾಹರಣೆಗಳು:

  • Rackspace
  • VMware vCloud
  • Azure Stack
  • IBM Cloud Private

3. ಸಂಯುಕ್ತ ಕ್ಲೌಡ್ / Hybrid Cloud

ಈ ರೀತಿಯ ಕ್ಲೌಡ್ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ ಎರಡು ಅಥವಾ ಹೆಚ್ಚಿನ ವಿತರಣಾ ಮಾದರಿಗಳ (ಖಾಸಗಿ, ಸಮುದಾಯ ಅಥವಾ ಸಾರ್ವಜನಿಕ) ಸಂಯೋಜನೆಯಾಗಿದೆ. ಇದನ್ನು ಒಂದೇ ಸಂಸ್ಥೆ ನಿರ್ವಹಿಸುತ್ತದೆ. ಇವುಗಳನ್ನು ಮಾನದಂಡ ಅಥವಾ ಸ್ವಾಮ್ಯ ತಂತ್ರಜ್ಞಾನಗಳಿಂದ ಸೇರಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಡೇಟಾ ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್‌ಗಳ ಸ್ಥಳಾಂತರವನ್ನು ಅನುಮತಿಸುತ್ತದೆ. ಸಾಮಾನ್ಯವಾಗಿ ಸಂಯುಕ್ತ ಕ್ಲೌಡ್ ಅನ್ನು ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರೊಂದಿಗೆ ನೇರವಾಗಿ ಸಂಪರ್ಕಿಸದ ಇತರ ಡೇಟಾ ಸೆಂಟರ್‌ಗಳನ್ನು ವಿವರಿಸಲು ಬಳಸಲಾಗುತ್ತದೆ.

4. ಸಮುದಾಯ ಕ್ಲೌಡ್ / Community Cloud

ತಂತ್ರಜ್ಞಾನದ ದೃಷ್ಟಿಕೋನದಿಂದ, ಸಮುದಾಯ ಕ್ಲೌಡ್ ಎನ್ನುವುದು ನಿರ್ದಿಷ್ಟ ಗ್ರಾಹಕರು ಮಾತ್ರ ಪ್ರವೇಶಿಸಲು ಅವಕಾಶ ನೀಡುವ ಹಂಚಿದ ಕ್ಲೌಡ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಆಗಿದೆ. ಕ್ಲೌಡ್ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ ನಿರ್ದಿಷ್ಟ ಸಂಸ್ಥೆಗಳ ಮೂಲಕ ಬಹು-ಯಾಜಕತೆಯೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳಲಾಗುತ್ತದೆ. ಇವು ಕಾರ್ಯ, ಭದ್ರತಾ ಅವಶ್ಯಕತೆಗಳು, ನೀತಿ ಅಥವಾ ಸಂಗ್ರಹಣಾ ಅನುಷ್ಠಾನಗಳ ಪ್ರಕಾರಗಳೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳುವ ನಿರ್ದಿಷ್ಟ ಸಮುದಾಯಕ್ಕೆ ಸೇವೆ ನೀಡುತ್ತವೆ. ಇದನ್ನು ಒಂದು ಸಂಸ್ಥೆ ಅಥವಾ ತೃತೀಯ ಪಕ್ಷ ನಿರ್ವಹಿಸಬಹುದು ಮತ್ತು ಸಂಸ್ಥೆಯ ಆವರಣದ ಒಳಗೆ ಅಥವಾ ಹೊರಗೆ ಇರಬಹುದು.

ಉದಾಹರಣೆ: ಸರ್ಕಾರದ ಕ್ಲೌಡ್ (Gov Cloud)
