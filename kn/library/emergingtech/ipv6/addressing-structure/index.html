ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

IPv6 ವಿಳಾಸ ರಚನೆ

IPv6 ವಿಳಾಸಗಳನ್ನು ಕೋಲನ್‌ಗಳಿಂದ ಬೇರ್ಪಡಿಸಿದ ಎಂಟು ಹೆಕ್ಸಾಡೆಸಿಮಲ್ ಗುಂಪುಗಳಾಗಿ ರಚಿಸಲಾಗಿದೆ.

ಉದಾಹರಣೆ:

2001:0db8:0000:0000:0000:8a2e:0370:7334

ವಿಳಾಸ ಸಂಕ್ಷಿಪ್ತಗೊಳಿಸುವ ನಿಯಮಗಳು

  • ಪ್ರತಿ ಹೆಕ್ಸೆಟ್‌ನಲ್ಲಿರುವ ಆರಂಭಿಕ ಸೊನ್ನೆಗಳನ್ನು ತೆಗೆದುಹಾಕಿ
  • ಸತತವಾಗಿ ಬರುವ ಒಂದು ಅಥವಾ ಹೆಚ್ಚು ಎಲ್ಲಾ-ಸೊನ್ನೆ ಗುಂಪುಗಳನ್ನು ಡಬಲ್ ಕೋಲನ್ (::)ನಿಂದ ಬದಲಿಸಿ

Example:

2001:0000:3238:DFE1:0063:0000:0000:FEFB

ಹೀಗೆ ಬದಲಾಗುತ್ತದೆ:

2001:0:3238:DFE1:63::FEFB

ಪ್ರಮುಖ ಟಿಪ್ಪಣಿಗಳು

  • IPv6 ವಿಳಾಸಗಳು IPv4 ವಿಳಾಸಗಳಿಗಿಂತ ಬಹಳ ದೊಡ್ಡದಾಗಿವೆ.
  • ಸ್ವರೂಪವು ಶ್ರೇಣೀಕೃತವಾಗಿದ್ದು ಪರಿಣಾಮಕಾರಿ ರೂಟಿಂಗ್‌ಗಾಗಿ ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ.
  • ವಿಳಾಸದ ಮೌಲ್ಯವನ್ನು ಬದಲಾಯಿಸದೆ ಸಂಕ್ಷಿಪ್ತಗೊಳಿಸುವಿಕೆ ಓದಲು ಸುಲಭವಾಗಿಸುತ್ತದೆ.
Note

ತಂತ್ರಜ್ಞಾನ. ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ.
