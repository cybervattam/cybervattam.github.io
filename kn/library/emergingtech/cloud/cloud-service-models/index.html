ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕ್ಲೌಡ್ ಕಂಪ್ಯೂಟಿಂಗ್ ಗ್ರಂಥಾಲಯ ಕ್ಲೌಡ್ ವಿತರಣಾ ಮಾದರಿಗಳು →

ಕ್ಲೌಡ್ ಸೇವಾ ಮಾದರಿಗಳು / Cloud Service Models




1. ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಆಸ್ ಎ ಸರ್ವೀಸ್ / Infrastructure as a Service (IaaS)

ವಾಸ್ತವಿಕ ಕಂಪ್ಯೂಟರ್ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ಗಳಾದ ವಾಸ್ತವೀಕರಣಗೊಂಡ ಕಂಪ್ಯೂಟಿಂಗ್, ನೆಟ್‌ವರ್ಕ್ ಮತ್ತು ಸಂಗ್ರಹಣೆಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಮತ್ತು ಅವುಗಳ ಪ್ರವೇಶವನ್ನು ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರು ಸಂಪನ್ಮೂಲಗಳ ಮೂಲಕ ಒದಗಿಸುತ್ತಾರೆ. ಕ್ಲೌಡ್ ಬಳಕೆದಾರರು ತಮ್ಮ ಅಗತ್ಯತೆಗಳಿಗೆ ಅನುಗುಣವಾಗಿ ವಿವಿಧ ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್‌ಗಳು ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಅದರ ಮೇಲೆ ಸ್ಥಾಪಿಸಬಹುದು.

2. ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಆಸ್ ಎ ಸರ್ವೀಸ್ / Platform as a Service (PaaS)

ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರು ಡೇಟಾಬೇಸ್‌ಗಳು, ಅಪ್ಲಿಕೇಶನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳು, ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳು, ರನ್‌ಟೈಮ್ ಪರಿಸರಗಳು ಮುಂತಾದ ತಳಗಳನ್ನು ಅಮೂರ್ತ ರೂಪದಲ್ಲಿ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ವಾಗಿ ಒದಗಿಸುತ್ತಾರೆ.

ಉದಾಹರಣೆಗಳು:

  • ಪೈಥಾನ್, PHP ಅಥವಾ ಇತರ ಮೂಲ ಕೋಡ್‌ಗಳನ್ನು ಚಲಾಯಿಸಲು ಅನುಕೂಲವಿರುವ ಸ್ಥಳ
  • ಸೇವೆಯಾಗಿ ಡೇಟಾಬೇಸ್ (Database as a Service)
  • ಸೇವೆಯಾಗಿ ಡೇಟಾವೇರ್ಹೌಸ್ (Data Warehouse as a Service)
  • ಸೇವೆಯಾಗಿ ಸಂಗ್ರಹಣೆ (Data Storage as a Service)
  • ಸೇವೆಯಾಗಿ ಯಂತ್ರ ಕಲಿಕೆ (Machine Learning as a Service)

ಮುಖ್ಯ ವ್ಯತ್ಯಾಸವೆಂದರೆ, ನೀವು ಆಧಾರವಾಗಿರುವ ಸರ್ವರ್ಗಳು, ನೆಟ್‌ವರ್ಕ್‌ಗಳು ಅಥವಾ ಇತರ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್‌ಗಳನ್ನು ನಿರ್ವಹಿಸುವುದಿಲ್ಲ.

3. ಸಾಫ್ಟ್‌ವೇರ್ ಆಸ್ ಎ ಸರ್ವೀಸ್ / Software as a Service (SaaS)

ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರು ನಿರ್ವಹಿಸಲ್ಪಡುವ ಮತ್ತು ಒದಗಿಸಲ್ಪಡುವ ಪೂರ್ಣ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ನೀಡುತ್ತಾರೆ. ಬಳಕೆದಾರರು ಇಂಟರ್ನೆಟ್ ಬ್ರೌಸರ್, ಮೊಬೈಲ್ ಆ್ಯಪ್ ಅಥವಾ ತೆಳುವಾದ ಕ್ಲೈಂಟ್ ಆ್ಯಪ್ ಮೂಲಕ ಇದನ್ನು ಪ್ರವೇಶಿಸಬಹುದು.

ವೈಯಕ್ತೀಕರಣ/ಕಾನ್ಫಿಗ್ಯುರೇಶನ್‌ ಲಭ್ಯವಿರಬಹುದು. ತಂತ್ರಾಂಶದ ವೈಶಿಷ್ಟ್ಯಗಳು ಅಥವಾ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಬದಲಾಯಿಸಲಾಗುವುದಿಲ್ಲ.

ಉದಾಹರಣೆಗಳು:

  • ನೆಟ್‌ಫ್ಲಿಕ್ಸ್
  • ಪ್ರೈಮ್ ವಿಡಿಯೋ
  • ಜಿಮೇಲ್
  • ಯೂಟ್ಯೂಬ್
  • ಜೂಮ್
  • ಮೈಕ್ರೋಸಾಫ್ಟ್ 365 ಮುಂತಾದ ಸೇವೆಗಳು
