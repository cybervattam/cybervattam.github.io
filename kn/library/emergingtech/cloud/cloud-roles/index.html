ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕ್ಲೌಡ್ ಕಂಪ್ಯೂಟಿಂಗ್ ಗ್ರಂಥಾಲಯ ಕ್ಲೌಡ್ ಕಂಪ್ಯೂಟಿಂಗ್‌ನ ಪ್ರಯೋಜನಗಳು →

ಕ್ಲೌಡ್ ಕಂಪ್ಯೂಟಿಂಗ್ ಪಾತ್ರಗಳು / Cloud Computing Roles

  • ಕ್ಲೌಡ್ ಪೂರೈಕೆದಾರ / Cloud Provider
    • ಕೌಟುಂಬಿಕ ಅಥವಾ ಸಂಸ್ಥೆಗಾಗಿ ಕ್ಲೌಡ್ ಸೇವೆಯನ್ನು ಲಭ್ಯಗೊಳಿಸುವ ವ್ಯಕ್ತಿ, ಸಂಸ್ಥೆ ಅಥವಾ ಕಂಪನಿ.
  • ಕ್ಲೌಡ್ ಬಳಕೆದಾರ / ಗ್ರಾಹಕ / Cloud Consumer
    • ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರೊಂದಿಗೆ ವ್ಯವಹಾರ ಸಂಬಂಧವನ್ನು ಹೊಂದಿರುವ ಮತ್ತು ಸೇವೆಯನ್ನು ಬಳಸುವ ವ್ಯಕ್ತಿ ಅಥವಾ ಸಂಸ್ಥೆ.
  • ಕ್ಲೌಡ್ ಕ್ಯಾರಿಯರ್ / Cloud Carrier
    • ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರಿಂದ ಬಳಕೆದಾರಿಗೆ ಕ್ಲೌಡ್ ಸೇವೆಗಳ ಸಂಪರ್ಕ ಮತ್ತು ಸಂಚಾರವನ್ನು ನೀಡುವ ಮಧ್ಯವರ್ತಿ.
  • ಕ್ಲೌಡ್ ಬ್ರೋಕರ್ / Cloud Broker
    • ಕ್ಲೌಡ್ ಸೇವೆಗಳ ಬಳಕೆ, ಕಾರ್ಯಕ್ಷಮತೆ ಮತ್ತು ವಿತರಣೆ ನಿರ್ವಹಿಸುವ ಮತ್ತು ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರೊಂದಿಗೆ ಬಳಕೆದಾರರ ನಡುವಿನ ಸಂಬಂಧವನ್ನು ಸುಧಾರಿಸಲು ಮಾತುಕತೆ ನಡೆಸುವ ಸಂಸ್ಥೆ.
  • ಕ್ಲೌಡ್ ಅಕ್ಸೆಸ್ ಸೆಕ್ಯೂರಿಟಿ ಬ್ರೋಕರ್ / Cloud Access Security Broker (CASB)
    • ಈ ರೀತಿಯ ಸಾಫ್ಟ್‌ವೇರ್‌ಗಳು ಕ್ಲೌಡ್‌ಗೆ ಹೋಗುವ ಸಂವಹನಗಳನ್ನು ತಡೆದು ಅಥವಾ ಗಮನಿಸಿ, ನೀತಿಗಳನ್ನು ಜಾರಿಗೆ ತಂದು, ಭದ್ರತಾ ಅಸಮರ್ಪಣೆಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಿ ತಡೆಯಲು API ಮೂಲಕ ಅಥವಾ ಸರ್ವರ್‌ಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್‌ಗಳ ಮೂಲಕ ನಿರ್ವಹಿಸಲಾಗುತ್ತದೆ. ಇವು ಸಾಮಾನ್ಯವಾಗಿ ಸಂಸ್ಥೆಯ ಅನುಮತಿತ ಮತ್ತು ಅನುಮತಿಸಲಾಗದ ಸೇವೆಗಳನ್ನು (SaaS) ನಿರ್ವಹಿಸಲು ಉಪಯೋಗಿಸುತ್ತವೆ.
Note

ತಂತ್ರಜ್ಞಾನ. ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ.
