DNS ವಲಯಗಳು

DNS ವಲಯಗಳು / DNS Zones

DNS ವಲಯವು ನಿರ್ದಿಷ್ಟ ಸಂಸ್ಥೆ ಅಥವಾ ನಿರ್ವಾಹಕರು ನಿರ್ವಹಿಸುವ ಡೊಮೇನ್ ಹೆಸರಿನ ಒಂದು ಭಾಗವಾಗಿದೆ. ಒಂದು ವಲಯದಲ್ಲಿ ಅನೇಕ ಉಪಡೊಮೇನ್‌ಗಳು ಇರಬಹುದು ಮತ್ತು ಒಂದೇ ಸರ್ವರ್‌ನಲ್ಲಿ ಅನೇಕ ವಲಯಗಳು ಇರಬಹುದು. ಆಡಳಿತಾತ್ಮಕ ನಿಯಂತ್ರಣವನ್ನು ಹಂಚಿಕೊಳ್ಳಲು ವಲಯಗಳನ್ನು ಬಳಸಲಾಗುತ್ತದೆ. DNS ದಾಖಲೆಗಳು (ವಲಯ ಕಡತಗಳು) ಅಧಿಕೃತ ಹೆಸರು ಸರ್ವರ್‌ನಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಸೂಚನೆಗಳನ್ನು ಒಳಗೊಂಡಿರುತ್ತವೆ. DNS ದಾಖಲೆಗಳು ಪಠ್ಯ ಕಡತಗಳ ಸರಣಿಯನ್ನು ಹೊಂದಿರುತ್ತವೆ. ಇವುಗಳನ್ನು DNS ಸಿಂಟ್ಯಾಕ್ಸ್ ಎಂದು ಕರೆಯಲಾಗುತ್ತದೆ. ಹೆಸರು ಸರ್ವರ್ ನಿರ್ವಹಿಸಬೇಕಾದ ಕಾರ್ಯಗಳಿಗಾಗಿ ಈ ಪಠ್ಯ ಕಡತಗಳು ಆದೇಶಗಳನ್ನು ಒಳಗೊಂಡಿರುತ್ತವೆ.
