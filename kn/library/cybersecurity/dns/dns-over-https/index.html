HTTPS ಮೇಲಿನ DNS

HTTPS ಮೇಲಿನ DNS / DNS over HTTPS (DoH)

HTTPS ಮೇಲಿನ DNS (DoH) ಒಂದು ಭದ್ರತಾ ಪ್ರೋಟೋಕಾಲ್ ಆಗಿದೆ. ಇದು DNS ಪ್ರಶ್ನೆಗಳನ್ನು ಗೂಢಲಿಪೀಕರಿಸಿ HTTPS ಮೂಲಕ ಕ್ಲೈಂಟ್‌ನಿಂದ ರಿಕರ್ಸಿವ್ ರಿಸಾಲ್ವರ್‌ಗೆ ಸುರಕ್ಷಿತವಾಗಿ ಕಳುಹಿಸುತ್ತದೆ. ಮಾಹಿತಿ ವಿನಿಮಯದ ಸಮಯದಲ್ಲಿ ಮಧ್ಯವರ್ತಿಗಳು ಪ್ರಶ್ನೆಗಳನ್ನು ಕದ್ದಾಲಿಕೆ ಮಾಡುವುದನ್ನು ತಡೆಯುವುದು ಮತ್ತು ಮಾಹಿತಿಯನ್ನು ಬದಲಾಯಿಸಲು ಅಥವಾ ಹಾನಿಗೊಳಿಸಲು ಸಾಧ್ಯವಾಗದಂತೆ ರಕ್ಷಿಸುವುದು ಇದರ ಉದ್ದೇಶವಾಗಿದೆ.
