ಡೊಮೇನ್ ಹೆಸರು ವ್ಯವಸ್ಥೆಯ ಪರಿಚಯ

ಡೊಮೇನ್ ಹೆಸರು ವ್ಯವಸ್ಥೆಯ ಪರಿಚಯ / DNS Introduction

ಡೊಮೇನ್ ಹೆಸರು ವ್ಯವಸ್ಥೆ (DNS) ಎನ್ನುವುದು ಕಂಪ್ಯೂಟರ್ ಸರ್ವರ್‌ಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ವಿಶೇಷ ಸಾಫ್ಟ್‌ವೇರ್ ವ್ಯವಸ್ಥೆಯಾಗಿದೆ. ಇದು ಸರ್ವರ್ ಹೆಸರುಗಳನ್ನು ಅವುಗಳಿಗೆ ಸಂಬಂಧಿಸಿದ IP ವಿಳಾಸಗಳೊಂದಿಗೆ ಜೋಡಿಸುತ್ತದೆ. ಇದು ನಮ್ಮ ಮೊಬೈಲ್‌ನ ಸಂಪರ್ಕಗಳ ಅಪ್ಲಿಕೇಶನ್ ಅಥವಾ ದೂರವಾಣಿ ಸಂಖ್ಯೆಗಳ ವಿಳಾಸ ಪುಸ್ತಕದಂತಿದೆ. ಇಂಟರ್ನೆಟ್ ಅಥವಾ ಆಂತರಿಕ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಪ್ರವೇಶಿಸುವಾಗ ಬ್ರೌಸರ್‌ಗಳು ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್‌ಗಳ ಡೊಮೇನ್ ಹೆಸರುಗಳನ್ನು DNS, IP ವಿಳಾಸಗಳಿಗೆ ಪರಿವರ್ತಿಸುತ್ತದೆ. DNS ಸರ್ವರ್‌ಗಳು ವಿಶೇಷ ಸಾಫ್ಟ್‌ವೇರ್‌ಗಳನ್ನು ನಡೆಸುತ್ತವೆ ಮತ್ತು ಹೆಸರುಗಳನ್ನು ಪರಿಹರಿಸಲು ಪರಸ್ಪರ ಸಂಪರ್ಕ ಸಾಧಿಸುತ್ತವೆ. DNS ಅನ್ನು ಆರಂಭದಿಂದಲೇ UDP ಮತ್ತು TCP ಸಾರಿಗೆ ಪ್ರೋಟೋಕಾಲ್‌ಗಳ ಪೋರ್ಟ್ 53 ಬಳಸಿ ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ; ಸಾಮಾನ್ಯವಾಗಿ ಇದು UDP ಮೂಲಕ ಮತ್ತು ಅಗತ್ಯವಿದ್ದಾಗ TCP ಮೂಲಕ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.
