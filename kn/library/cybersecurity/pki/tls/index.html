ಟ್ರಾನ್ಸ್‌ಪೋರ್ಟ್ ಲೇಯರ್ ಸಿಕ್ಯೂರಿಟಿ ಪ್ರಮಾಣಪತ್ರಗಳ ವಿಧಗಳು / Transport Layer Security Certificate Types

1. ಡೊಮೇನ್ ಪರಿಶೀಲನೆ / Domain Validation

ಕಡಿಮೆ ಮಟ್ಟದ ಭರವಸೆಯನ್ನು ನೀಡುವ ಪ್ರಮಾಣಪತ್ರಗಳಾಗಿವೆ. ಇವುಗಳನ್ನು ಪಡೆಯುವುದು ಸುಲಭ. ಕೇವಲ ವೆಬ್‌ಸೈಟಿನ ಡೊಮೇನ್ ಹೆಸರು ಮಾತ್ರ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ. ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಹೊಂದಿರುವ ವೆಬ್‌ಸೈಟುಗಳಲ್ಲಿ ಕೇವಲ ಸುರಕ್ಷಿತ ಲಾಕ್ ಚಿಹ್ನೆ ಮಾತ್ರ ಕಾಣಿಸುತ್ತದೆ. ಆ ವೆಬ್‌ಸೈಟಿನ ಮಾಲೀಕನ ಹೆಸರು ಅಥವಾ ವಾಣಿಜ್ಯ ಸಂಸ್ಥೆಯ ಹೆಸರು ಇರುತ್ತದೆ. ಆದ್ದರಿಂದ ಸುರಕ್ಷಿತ ಗುರುತಿನ ಉಪಸ್ಥಿತಿಯಲ್ಲಿಯೂ, ಬಳಕೆದಾರರು ಆ ಸೈಟ್ ನಿಜವಾಗಿಯೂ ಅವರು ಹುಡುಕುತ್ತಿರುವ ವ್ಯವಹಾರದೊಂದಿಗೆ ಸಂಬಂಧಿತವಾಗಿದೆಯೇ ಎಂಬುದನ್ನು ಪರಿಶೀಲಿಸಲು ಯಾವುದೇ ಮಾರ್ಗವಿಲ್ಲ.


2. ಸಂಸ್ಥೆ ಪರಿಶೀಲನೆ / Organization Validation

ಇದೇ ಅತ್ಯಂತ ಸಾಮಾನ್ಯವಾಗಿ ಬಳಸುವ ಸುರಕ್ಷತಾ ಭರವಸೆ ಮಟ್ಟ. ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಹೊಂದಿರುವ ವೆಬ್‌ಸೈಟುಗಳು ಸುರಕ್ಷಿತ ಲಾಕ್ ಚಿಹ್ನೆಯೊಂದಿಗೆ ತಮ್ಮ ವಾಣಿಜ್ಯ ಹೆಸರನ್ನು ಸಹ ತೋರಿಸುತ್ತವೆ. ಈ ಪ್ರಮಾಣಪತ್ರಗಳು ಹೆಚ್ಚಿನ ಭರವಸೆಯನ್ನು ನೀಡುತ್ತವೆ. ಆದ್ದರಿಂದ, ಅವುಗಳನ್ನು ಪ್ರಮಾಣಪತ್ರ ಅಧಿಕಾರಿಗಳ ಸರಿಯಾದ ಪರಿಶೀಲನೆ ನಂತರವೇ ನೀಡಲಾಗುತ್ತದೆ. ಪ್ರಮುಖ ಗ್ರಾಹಕ ಡೇಟಾವನ್ನು ನಿರ್ವಹಿಸುವ ಸಂಸ್ಥೆಗಳು ಈ ರೀತಿಯ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಹೆಚ್ಚಾಗಿ ಬಳಸುತ್ತವೆ.


3. ವಿಸ್ತರಿತ ಪರಿಶೀಲನೆ / Extended Validation

ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳು ಅತ್ಯುನ್ನತ ಸುರಕ್ಷತಾ ಭರವಸೆಯನ್ನು ನೀಡುತ್ತವೆ ಮತ್ತು ಪಡೆಯುವುದು ಕಷ್ಟ. ವಿಸ್ತರಿತ ಪರಿಶೀಲಿತ ಪ್ರಮಾಣಪತ್ರ ಪಡೆಯಲು ಬಯಸುವ ಸಂಸ್ಥೆಯನ್ನು ಪ್ರಮಾಣಪತ್ರ ಅಧಿಕಾರಿಗಳು ಕಠಿಣ ಪರಿಶೀಲನೆಗೆ ಒಳಪಡಿಸುತ್ತಾರೆ. ಇದರಲ್ಲಿ ವ್ಯವಹಾರದ ನಿಜವಾದ ಸ್ಥಳ, ಕ್ಷೇತ್ರ ಇತ್ಯಾದಿಗಳನ್ನು ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ. ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಹೊಂದಿರುವ ವೆಬ್‌ಸೈಟುಗಳಲ್ಲಿ ಸಂಸ್ಥೆಯ ಹೆಸರು, ದೇಶದ ಕೋಡ್ ಮತ್ತು ಸುರಕ್ಷಿತ ಲಾಕ್ ಚಿಹ್ನೆ ಹಸಿರು ಬಣ್ಣದಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ.

4. ಏಕ ಡೊಮೇನ್ ಪ್ರಮಾಣಪತ್ರಗಳು (Single Domain Certificates)

ಪ್ರಮಾಣಪತ್ರದಲ್ಲಿ ಸೂಚಿಸಲಾದ ಒಂದು ಡೊಮೇನ್ ಅನ್ನು ರಕ್ಷಿಸುತ್ತದೆ. ಈ ಪ್ರಮಾಣಪತ್ರಗಳ ಪ್ರಕಾರ ಡೊಮೇನ್ ಹೆಸರು ಮತ್ತು ಉಪಡೊಮೇನ್ ಹೆಸರುಗಳಿಗೆ ನೀಡಲಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗೆ www.google.com, mail.google.com.


5. ಬಹು ಡೊಮೇನ್ ಪ್ರಮಾಣಪತ್ರಗಳು (Multi-Domain Certificates)

ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ವಿಷಯ ಪರ್ಯಾಯ ಹೆಸರು ಪ್ರಮಾಣಪತ್ರಗಳು (Subject Alternative Name Certificates) ಅಥವಾ ಏಕೀಕೃತ ಸಂವಹನ ಪ್ರಮಾಣಪತ್ರಗಳು (Unified Communications Certificates) ಎಂದೂ ಕರೆಯುತ್ತಾರೆ. ಕೆಲವು ಸರ್ವರ್ ಪರಿಸರಗಳು ಹಲವಾರು ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಸ್ಥಾಪಿಸಲು ಅನುಮತಿಸುವುದಿಲ್ಲ. ಈ ಸಮಸ್ಯೆಯನ್ನು ಪರಿಹರಿಸಲು ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳು ಸುಲಭ ಮತ್ತು ಕಡಿಮೆ ವೆಚ್ಚದ ಪರಿಹಾರವಾಗಿದೆ. ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಎಲ್ಲಾ ಪರಿಶೀಲನೆ ವಿಧಾನಗಳಲ್ಲಿ ನೀಡಲಾಗುತ್ತದೆ. ಒಂದು ಪ್ರಮಾಣಪತ್ರದಲ್ಲಿ 250 ಪರ್ಯಾಯ ಡೊಮೇನ್‌ಗಳನ್ನು ಸಂಯೋಜಿಸಬಹುದು. ಈ ಪ್ರಮಾಣಪತ್ರಗಳು ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಮೊದಲು ಎಲ್ಲಾ ಪರ್ಯಾಯ ಹೆಸರುಗಳಿಗೆ ಡೊಮೇನ್ ಪರಿಶೀಲನೆ ಯಶಸ್ವಿಯಾಗಿ ಮುಗಿದಿರಬೇಕು.


6. ವೈಲ್ಡ್ಕಾರ್ಡ್ ಪ್ರಮಾಣಪತ್ರಗಳು (Wildcard Certificates)

ಒಂದೇ ಡೊಮೇನ್‌ನಲ್ಲಿರುವ ಹಲವಾರು ಉಪಡೊಮೇನ್‌ಗಳನ್ನು ಹೊಂದಿರುವ ವಾಣಿಜ್ಯ ಸಂಸ್ಥೆಗಳಿಗೆ ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳು ತುಂಬಾ ಜನಪ್ರಿಯವಾಗಿವೆ. ರಚನೆಯ ಸಮಯದಲ್ಲಿ ನಕ್ಷತ್ರ ಚಿಹ್ನೆ () ಬಳಸಿಕೊಂಡು, ಸಂಸ್ಥೆಯ ಸಾಮಾನ್ಯ ಹೆಸರನ್ನು “.domain.com” ರೂಪದಲ್ಲಿ ಉಲ್ಲೇಖಿಸಿ ನೀಡಲಾಗುತ್ತದೆ. “*” ಎಂಬುದು ಯಾವುದೇ ಅಥವಾ ಎಲ್ಲವನ್ನು ಸೂಚಿಸುವ ಚಿಹ್ನೆ. ಈ ಚಿಹ್ನೆಯು “domain.com” ಡೊಮೇನ್‌ನೊಂದಿಗೆ ಮುಗಿಸುವ ಎಲ್ಲಾ ಉಪಡೊಮೇನ್ಗಳನ್ನೂ ಸೂಚಿಸುತ್ತದೆ. ಆದ್ದರಿಂದ ಎಲ್ಲಾ ಉಪಡೊಮೇನ್‌ಗಳನ್ನು ರಕ್ಷಿಸುತ್ತದೆ. ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಸಂಸ್ಥೆ ಪರಿಶೀಲನೆ ಮತ್ತು ವಿಸ್ತರಿತ ಪರಿಶೀಲನೆ ವಿಧಾನಗಳಲ್ಲಿ ಮಾತ್ರ ನೀಡಲಾಗುತ್ತದೆ.


7. ಬಹು ಡೊಮೇನ್ ವೈಲ್ಡ್ಕಾರ್ಡ್ ಪ್ರಮಾಣಪತ್ರಗಳು (Wildcard Multi-Domain Certificates)

ಇಂತಹ ಪ್ರಮಾಣಪತ್ರಗಳನ್ನು ಸಂಕೀರ್ಣ ವೆಬ್ ಆಧಾರಿತ ಆರ್ಥಿಕತೆ ಹೊಂದಿರುವ ಸಂಸ್ಥೆಗಳಿಗೆ ಬಳಸಲಾಗುತ್ತದೆ. ಈ ಪ್ರಮಾಣಪತ್ರಗಳು ಮಾರಾಟಗಾರನ ಮೇಲೆ ಅವಲಂಬಿಸಿ ಒಂದು ಪ್ರಮಾಣಪತ್ರದಲ್ಲಿ 250 ಡೊಮೇನ್‌ಗಳನ್ನು ರಕ್ಷಿಸುತ್ತದೆ. ಸಾಮಾನ್ಯ ಹೆಸರು ಸಂಪೂರ್ಣ ವಿಶ್ವಾಸಾರ್ಹ ಡೊಮೇನ್ ಹೆಸರು ಆಗಿರಬೇಕು (www.domain.com). ನಿಮ್ಮ ಪರ್ಯಾಯ ಡೊಮೇನ್‌ಗಳ ಪಟ್ಟಿ ಸಂಪೂರ್ಣ ಲಾಯುಕ್ತ ಡೊಮೇನ್ ಹೆಸರು (www1.domain.com), ವೈಲ್ಡ್ಕಾರ್ಡ್ ಡೊಮೇನ್ (*.domain.com) ಅಥವಾ ಎರಡರ ಸಂಯೋಜನೆಯಾಗಿರಬಹುದು.

Note

ತಂತ್ರಜ್ಞಾನ. ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ.
