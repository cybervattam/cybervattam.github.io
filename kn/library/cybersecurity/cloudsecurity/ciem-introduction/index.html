ಕ್ಲೌಡ್ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಎಂಟೈಟಲ್‌ಮೆಂಟ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CIEM)

ಕ್ಲೌಡ್ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಎಂಟೈಟಲ್‌ಮೆಂಟ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CIEM) ಕನಿಷ್ಠ ಸವಲತ್ತು ತತ್ವದ (POLP) ಪ್ರಕಾರ ಗುರುತುಗಳು ಮತ್ತು ಕ್ಲೌಡ್ ಅನುಮತಿಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಬಳಸುವ ಕ್ಲೌಡ್ ಭದ್ರತಾ ಪರಿಹಾರವಾಗಿದೆ.

ಮಲ್ಟಿ-ಕ್ಲೌಡ್ ಪರಿಸರಗಳಲ್ಲಿ ಖಾತೆ ಅನುಮತಿಗಳಲ್ಲಿನ ಅಸಂಗತತೆಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಲು CIEM ಯಂತ್ರ ಕಲಿಕೆ ಮತ್ತು ವಿಶ್ಲೇಷಣೆಯನ್ನು ಬಳಸುತ್ತದೆ. ಈ ಗೋಚರತೆ ಸಂಸ್ಥೆಗಳು ತಮ್ಮ ಕ್ಲೌಡ್ ಸೇವೆಗಳಾದ್ಯಂತ ಸ್ಥಿರವಾದ ಗುರುತು ಮತ್ತು ಪ್ರವೇಶ ನಿರ್ವಹಣೆಯನ್ನು ಅನ್ವಯಿಸಲು ಹಾಗೂ ಡೇಟಾ ಉಲ್ಲಂಘನೆ ಮತ್ತು ಹೊರತೆಗೆತದ ಅಪಾಯವನ್ನು ಕಡಿಮೆ ಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

ಸಾಮಾನ್ಯ CIEM ಆರ್ಕಿಟೆಕ್ಚರ್

  • ಕಂಟ್ರೋಲ್ ಪ್ಲೇನ್
  • ಡೇಟಾ ಪ್ಲೇನ್
  • API ಏಕೀಕರಣ
  • ಕನೆಕ್ಟರ್‌ಗಳು
  • ಪತ್ತೆ, ಸಂಬಂಧೀಕರಣ ಮತ್ತು ಆಪ್ಟಿಮೈಸೇಶನ್ ಎಂಜಿನ್
  • ಭದ್ರತಾ ಎಂಟೈಟಲ್‌ಮೆಂಟ್ ಡೇಟಾಬೇಸ್
  • ನಿರ್ವಹಣಾ ಪೋರ್ಟಲ್
  • ಸಂಸ್ಥೆಯ ನೀತಿಗಳು
  • ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಮತ್ತು ದೃಶ್ಯೀಕರಣ

ಗುರಿ

ಹೆಚ್ಚುವರಿ ಅನುಮತಿಗಳನ್ನು ತೆಗೆದುಹಾಕಿ, ಗುರುತುಗಳಿಗೆ ತಮ್ಮ ಕೆಲಸ ನಿರ್ವಹಿಸಲು ಅಗತ್ಯವಿರುವ ಪ್ರವೇಶ ಮಾತ್ರ ಇರುವುದನ್ನು ಖಚಿತಪಡಿಸುವ ಮೂಲಕ CIEM ಸಂಸ್ಥೆಗಳು ದಾಳಿ ವ್ಯಾಪ್ತಿಯನ್ನು ಕಡಿಮೆ ಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

Note
