ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕ್ಲೌಡ್ ವರ್ಕ್‌ಲೋಡ್ ಪ್ರೊಟೆಕ್ಷನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ (CWPP) ಕ್ಲೌಡ್ ಭದ್ರತೆ SaaS ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (SSPM) →

ಕ್ಲೌಡ್ ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CSPM)

ಕ್ಲೌಡ್ ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CSPM)

ಕ್ಲೌಡ್ ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ ಕ್ಲೌಡ್ ಮೂಲಸೌಕರ್ಯದಲ್ಲಿನ ತಪ್ಪು ಸಂರಚನೆಗಳು, ನೀತಿ ಉಲ್ಲಂಘನೆಗಳು ಮತ್ತು ಅನುಸರಣೆ ಅಂತರಗಳನ್ನು ನಿರಂತರವಾಗಿ ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ, IaaS ಮತ್ತು PaaS ಪರಿಸರಗಳಾದ್ಯಂತ ಅವುಗಳನ್ನು ಸರಿಪಡಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

CSPM ಸಾಮರ್ಥ್ಯಗಳು

  • ಸ್ವತ್ತುಗಳ ಪತ್ತೆ ಮತ್ತು ಗುರುತಿಸುವಿಕೆ: ಸ್ವತ್ತುಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಿ, ಅಪಾಯವನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ ಆದ್ಯತೆ ನೀಡಿ, ಪರಿಹಾರಕ್ಕೆ ಬೆಂಬಲ ನೀಡಿ ಅಥವಾ ಅದನ್ನು ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸಿ
  • ಕ್ಲೌಡ್ ಆಡಳಿತ ಮತ್ತು ಅನುಸರಣೆ: ನಿಯಂತ್ರಣಾತ್ಮಕ ಮತ್ತು ಚೌಕಟ್ಟಿನ ಅನುಸರಣೆ ಪ್ಯಾಕ್‌ಗಳು ಹಾಗೂ ಸ್ವಯಂಚಾಲಿತ ಮತ್ತು ನಿಗದಿತ ವರದಿಗಳು
  • ಕ್ಲೌಡ್ ಡೇಟಾ ರಕ್ಷಣೆ: ವಿನ್ಯಾಸದಲ್ಲೇ ಭದ್ರತೆ ಮತ್ತು ಗೌಪ್ಯತೆ, ಕ್ಲೌಡ್ ಎನ್‌ಕ್ರಿಪ್ಶನ್ ಮತ್ತು DLP
  • ಕ್ಲೌಡ್ ಬೆದರಿಕೆ ರಕ್ಷಣೆ: ಸಾರ್ವಜನಿಕ ಕ್ಲೌಡ್‌ಗಳಾದ್ಯಂತ ಏಕೀಕೃತ ನೀತಿ, ನಿರಂತರ ವರ್ತನೆ ಮೇಲ್ವಿಚಾರಣೆ ಮತ್ತು ಸುರಕ್ಷತಾ ಗಡಿಗಳು
  • DevSecOps: CI/CD ಏಕೀಕರಣ, API ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ ಮತ್ತು ಸುರಕ್ಷಿತ ಮೂಲಸೌಕರ್ಯ-ಕೋಡ್ (IaC) ಟೆಂಪ್ಲೇಟ್‌ಗಳು

CSPM ಘಟಕಗಳು

CSPM ಕ್ಲೌಡ್ ಪೂರೈಕೆದಾರರ APIಗಳಿಂದ ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸಿ, ಅದನ್ನು ಸಾಮಾನ್ಯ ಸ್ವರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸುತ್ತದೆ. ನಂತರ ವರದಿ, ಪ್ರತಿಕ್ರಿಯೆ ಮತ್ತು ಏಕೀಕರಣಗಳಿಗೆ ನೆರವಾಗುವಂತೆ ನೀತಿ ಆಧಾರಿತ ಹಾಗೂ ಯಂತ್ರ-ಕಲಿಕೆ ನೆರವಿನ ಪತ್ತೆ ವಿಧಾನಗಳನ್ನು ಅನ್ವಯಿಸುತ್ತದೆ.

ಭದ್ರತಾ ಉದ್ದೇಶ

ಕ್ಲೌಡ್ ಅಪಾಯದ ನಿರಂತರ ಗೋಚರತೆಯನ್ನು ಒದಗಿಸಿ, ಪರಿಸರವು ಭದ್ರತಾ ನೀತಿ ಮತ್ತು ಅನುಸರಣೆ ಅಗತ್ಯಗಳಿಗೆ ಹೊಂದಿಕೊಂಡಿರುವಂತೆ ನೋಡಿಕೊಳ್ಳುವುದು.

← ಕ್ಲೌಡ್ ವರ್ಕ್‌ಲೋಡ್ ಪ್ರೊಟೆಕ್ಷನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ (CWPP) ಗ್ರಂಥಾಲಯ SaaS ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (SSPM) →
