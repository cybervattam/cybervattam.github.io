ಸಾರ್ವಜನಿಕ ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರು ವರ್ಕ್‌ಲೋಡ್‌ಗಳು, ಗುರುತುಗಳು, ನೆಟ್‌ವರ್ಕ್‌ಗಳು ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಸುರಕ್ಷಿತಗೊಳಿಸಲು ಸಹಾಯ ಮಾಡುವ ವಿವಿಧ ನೆಟಿವ್ ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳನ್ನು ಒದಗಿಸುತ್ತಾರೆ.
