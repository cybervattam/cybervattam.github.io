ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕ್ಲೌಡ್ ಭದ್ರತೆ ಗ್ರಂಥಾಲಯ ಕ್ಲೌಡ್ ನಿರ್ವಹಣಾ ಪ್ಲೇನ್ ಮತ್ತು API ಭದ್ರತೆ →

ಕ್ಲೌಡ್ ಕೋರ್ ಸಂಪರ್ಕ ಭದ್ರತೆ

ಕ್ಲೌಡ್ ಪೂರೈಕೆದಾರರು ವಿಶಾಲ ಖಾಸಗಿ ನೆಟ್‌ವರ್ಕ್‌ಗಳು ಮತ್ತು ಸಮರ್ಪಿತ ಬ್ಯಾಕ್‌ಬೋನ್ ಸಂಪರ್ಕಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತಾರೆ. ಡೇಟಾ ಸೆಂಟರ್‌ಗಳು, ಎಡ್ಜ್ ಸ್ಥಳಗಳು ಮತ್ತು ಪ್ರದೇಶಗಳು ಜಾಗತಿಕ ಫೈಬರ್ ಹಾಗೂ ಸಮುದ್ರದಡಿಯ ಕೇಬಲ್ ನೆಟ್‌ವರ್ಕ್‌ಗಳಿಂದ ಸಂಪರ್ಕಗೊಂಡಿವೆ. ಆದ್ದರಿಂದ ಹೆಚ್ಚಿನ ಕ್ಲೌಡ್ ಟ್ರಾಫಿಕ್ ಸಾರ್ವಜನಿಕ ಇಂಟರ್ನೆಟ್ ಬದಲಿಗೆ ಪೂರೈಕೆದಾರರ ನಿಯಂತ್ರಣದಲ್ಲಿರುವ ಸಂಪರ್ಕ ಮಾರ್ಗಗಳ ಮೂಲಕ ಸಾಗುತ್ತದೆ.

ಸಂಪರ್ಕಕ್ಕೆ ರಕ್ಷಣೆ ಏಕೆ ಅಗತ್ಯ

ಖಾಸಗಿ ಬ್ಯಾಕ್‌ಬೋನ್ ಇದ್ದರೂ, ಒಳಗಿನ ಮತ್ತು ಹೊರಗಿನ ಟ್ರಾಫಿಕ್ ಮಾರ್ಗಗಳನ್ನು ತಡೆಹಿಡಿಯುವಿಕೆ, ಹಸ್ತಕ್ಷೇಪ ಮತ್ತು ಸೇವಾ ನಿರಾಕರಣೆ ದಾಳಿಗಳಿಂದ ರಕ್ಷಿಸಬೇಕು. ಭೌತಿಕ ಫೈಬರ್ ಮಾರ್ಗಗಳು, ಇಂಟರ್‌ಕನೆಕ್ಟ್ ಬಿಂದುಗಳು ಮತ್ತು ಎಡ್ಜ್ ಸ್ಥಳಗಳೂ ದಾಳಿ ಮೇಲ್ಮೈಯ ಭಾಗವಾಗಿವೆ.

ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳು

  • ಫೈರ್‌ವಾಲ್‌ಗಳು ಮತ್ತು ಗೇಟ್‌ವೇಗಳು
  • ಪ್ರಾಕ್ಸಿಗಳು
  • ಒಳನುಗ್ಗುವಿಕೆ ಪತ್ತೆ ಮತ್ತು ತಡೆ ವ್ಯವಸ್ಥೆಗಳು (IDS/IPS)
  • ಹನಿಪಾಟ್‌ಗಳು ಮತ್ತು ಮೋಸ ತಂತ್ರಜ್ಞಾನಗಳು
  • ಸಾಗಣೆಯಲ್ಲಿರುವ ಟ್ರಾಫಿಕ್‌ಗೆ VPN ಮತ್ತು ಎನ್‌ಕ್ರಿಪ್ಶನ್
  • ದೃಢೀಕರಣ ಮತ್ತು ಅನುಮೋದನೆ
  • DDoS ರಕ್ಷಣೆ
  • ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ರಕ್ಷಣೆಗಳ ನಿರಂತರ ಸುಧಾರಣೆ

ಒಟ್ಟಾರೆ ಗುರಿ

ಗ್ರಾಹಕರು, ಎಡ್ಜ್ ಸ್ಥಳಗಳು ಮತ್ತು ಕ್ಲೌಡ್ ಪ್ರದೇಶಗಳ ನಡುವಿನ ಟ್ರಾಫಿಕ್ ಗೌಪ್ಯ, ಸಮಗ್ರ ಮತ್ತು ಲಭ್ಯವಾಗಿರುವುದನ್ನು ಖಚಿತಪಡಿಸುವುದೇ ಕೋರ್ ಸಂಪರ್ಕ ಭದ್ರತೆಯ ಗುರಿ. ಇದಕ್ಕಾಗಿ ನೆಟ್‌ವರ್ಕ್ ನಿಯಂತ್ರಣಗಳು, ಪತ್ತೆ ಸಾಮರ್ಥ್ಯಗಳು ಮತ್ತು ಬಲವಾದ ಆಡಳಿತವನ್ನು ಒಟ್ಟುಗೂಡಿಸಲಾಗುತ್ತದೆ.
