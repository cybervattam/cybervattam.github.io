ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕ್ಲೌಡ್ ಭದ್ರತೆ ಗ್ರಂಥಾಲಯ ಕ್ಲೌಡ್ ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CSPM) →

ಕ್ಲೌಡ್ ವರ್ಕ್‌ಲೋಡ್ ಪ್ರೊಟೆಕ್ಷನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ (CWPP)

ಸಾರ್ವಜನಿಕ ಮತ್ತು ಖಾಸಗಿ ಕ್ಲೌಡ್‌ಗಳು ಹಾಗೂ ಡೇಟಾ ಸೆಂಟರ್‌ಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಭೌತಿಕ ಸರ್ವರ್‌ಗಳು, ವರ್ಚುವಲ್ ಯಂತ್ರಗಳು, ಕಂಟೇನರ್‌ಗಳು ಮತ್ತು ಸರ್ವರ್‌ಲೆಸ್ ಫಂಕ್ಷನ್‌ಗಳು ಸೇರಿದಂತೆ, ಅವು ಎಲ್ಲೇ ಕಾರ್ಯನಿರ್ವಹಿಸಿದರೂ CWPP ವರ್ಕ್‌ಲೋಡ್‌ಗಳನ್ನು ರಕ್ಷಿಸುತ್ತದೆ.

ವರ್ಕ್‌ಲೋಡ್‌ಗಳ ವಿಕಾಸ

ವರ್ಕ್‌ಲೋಡ್‌ಗಳು ಹೆಚ್ಚು ಸಣ್ಣದಾಗಿಯೂ ಅಲ್ಪಾವಧಿಯದ್ದಾಗಿಯೂ ಆಗಿವೆ; ಇದರಿಂದ ಅವುಗಳನ್ನು ಸುರಕ್ಷಿತಗೊಳಿಸುವ ವಿಧಾನ ಬದಲಾಗುತ್ತದೆ.

ಜೀವನಚಕ್ರದಾದ್ಯಂತ ರಕ್ಷಣೆ

ವರ್ಕ್‌ಲೋಡ್ ಜೀವನಚಕ್ರದ ನಿರ್ಮಾಣ ಮತ್ತು ರನ್‌ಟೈಮ್ ಎರಡೂ ಹಂತಗಳನ್ನು CWPP ಒಳಗೊಂಡಿರುತ್ತದೆ.

ಸುರಕ್ಷಿತ ನಿರ್ಮಾಣ

  • ದುರ್ಬಲ ಘಟಕಗಳು
  • ಕ್ಲೌಡ್ ಸಂರಚನೆ
  • ರಹಸ್ಯಗಳು
  • ಮಾಲ್‌ವೇರ್
  • API ಪತ್ತೆ

ರನ್‌ಟೈಮ್ ರಕ್ಷಣೆ

  • ವರ್ಕ್‌ಲೋಡ್ ದುರ್ಬಲತೆಗಳು ಮತ್ತು ಸಂರಚನೆ
  • ವರ್ಕ್‌ಲೋಡ್ ವಿಭಜನೆ
  • ಸಮಗ್ರತೆ ಮೇಲ್ವಿಚಾರಣೆ
  • ಅಪ್ಲಿಕೇಶನ್ ನಿಯಂತ್ರಣ
  • ವರ್ತನೆ ಮೇಲ್ವಿಚಾರಣೆ
  • ಹೋಸ್ಟ್ ಒಳನುಗ್ಗುವಿಕೆ ತಡೆ (HIPS)
  • ಮಾಲ್‌ವೇರ್ ವಿರೋಧಿ ರಕ್ಷಣೆ

ಅಪಾಯ ಆಧಾರಿತ ನಿಯಂತ್ರಣಗಳ ಶ್ರೇಣಿ

ಹಾರ್ಡನಿಂಗ್, ಸಂರಚನೆ, ದುರ್ಬಲತೆ ನಿರ್ವಹಣೆ ಮತ್ತು ನೆಟ್‌ವರ್ಕ್ ವಿಭಜನೆಯಿಂದ ಪ್ರಾರಂಭಿಸಿ, ಮೂಲಭೂತ ನಿಯಂತ್ರಣಗಳಿಗೆ ಮೊದಲ ಆದ್ಯತೆ ನೀಡುವಂತೆ ನಿಯಂತ್ರಣಗಳನ್ನು ಶ್ರೇಣೀಕರಿಸಬಹುದು.

ಭದ್ರತಾ ಉದ್ದೇಶ

ಕ್ಲೌಡ್ ಒದಗಿಸುವ ಚುರುಕುತನವನ್ನು ಕುಂಠಿತಗೊಳಿಸದೆ ವರ್ಕ್‌ಲೋಡ್‌ಗಳನ್ನು ಸ್ಥಿರವಾಗಿ ಸುರಕ್ಷಿತಗೊಳಿಸುವುದು.
