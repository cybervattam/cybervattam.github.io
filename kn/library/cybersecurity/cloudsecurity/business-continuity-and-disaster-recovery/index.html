ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕ್ಲೌಡ್ ನಿರ್ವಹಣಾ ಪ್ಲೇನ್ ಮತ್ತು API ಭದ್ರತೆ ಕ್ಲೌಡ್ ಭದ್ರತೆ ಕ್ಲೌಡ್ ಭದ್ರತೆಯ ಮೂಲಸ್ತಂಭಗಳು →

ವ್ಯವಹಾರ ನಿರಂತರತೆ ಮತ್ತು ವಿಪತ್ತು ಮರುಪಡೆಯುವಿಕೆ

ವ್ಯವಹಾರ ನಿರಂತರತೆ ಮತ್ತು ವಿಪತ್ತು ಮರುಪಡೆಯುವಿಕೆ

ಅಡಚಣೆಗಳ ಸಂದರ್ಭದಲ್ಲೂ ನಿರ್ಣಾಯಕ ಸೇವೆಗಳು ಕಾರ್ಯನಿರ್ವಹಿಸುವಂತೆ ವ್ಯವಹಾರ ನಿರಂತರತೆ (BC) ನೋಡಿಕೊಳ್ಳುತ್ತದೆ; ದೊಡ್ಡ ವೈಫಲ್ಯದ ನಂತರ ವ್ಯವಸ್ಥೆಗಳು ಮತ್ತು ಡೇಟಾವನ್ನು ಮರುಸ್ಥಾಪಿಸುವುದು ವಿಪತ್ತು ಮರುಪಡೆಯುವಿಕೆ (DR). ಕ್ಲೌಡ್ ಪೂರೈಕೆದಾರರು ಸ್ಥಿತಿಸ್ಥಾಪಕ ಮೂಲಸೌಕರ್ಯ ಒದಗಿಸುತ್ತಾರೆ, ಆದರೆ ತಮ್ಮ ವರ್ಕ್‌ಲೋಡ್‌ಗಳು ಅದನ್ನು ಬಳಸುವಂತೆ ವಿನ್ಯಾಸಗೊಳಿಸುವ ಜವಾಬ್ದಾರಿ ಗ್ರಾಹಕರದ್ದೇ.

ಪೂರೈಕೆದಾರರ ಸಾಮರ್ಥ್ಯಗಳು

  • ಹಲವು ಪ್ರದೇಶಗಳು ಮತ್ತು ಲಭ್ಯತಾ ವಲಯಗಳು
  • ವಿದ್ಯುತ್, ಶೀತಲೀಕರಣ ಮತ್ತು ನೆಟ್‌ವರ್ಕ್ ಪುನರಾವರ್ತನೆ
  • ಪ್ರತಿಕೃತಿಗೊಳಿಸಿದ ಮತ್ತು ದೀರ್ಘಕಾಲಿಕ ಸಂಗ್ರಹಣೆ
  • ಬ್ಯಾಕಪ್ ಮತ್ತು ಸ್ನ್ಯಾಪ್‌ಶಾಟ್ ಸೇವೆಗಳು

ಗ್ರಾಹಕರ ಜವಾಬ್ದಾರಿಗಳು

  • ಪ್ರತಿ ವರ್ಕ್‌ಲೋಡ್‌ಗೆ ಮರುಪಡೆಯುವಿಕೆ ಸಮಯ ಗುರಿ (RTO) ಮತ್ತು ಮರುಪಡೆಯುವಿಕೆ ಬಿಂದು ಗುರಿ (RPO) ನಿರ್ಧರಿಸಿ
  • ವಲಯಗಳು ಅಥವಾ ಪ್ರದೇಶಗಳಾದ್ಯಂತ ಹೆಚ್ಚಿನ ಲಭ್ಯತೆಗಾಗಿ ವಿನ್ಯಾಸಗೊಳಿಸಿ
  • ಡೇಟಾವನ್ನು ನಿಯಮಿತವಾಗಿ ಬ್ಯಾಕಪ್ ಮಾಡಿ; ಎನ್‌ಕ್ರಿಪ್ಶನ್ ಮತ್ತು ಪ್ರವೇಶ ನಿಯಂತ್ರಣಗಳಿಂದ ಬ್ಯಾಕಪ್‌ಗಳನ್ನು ರಕ್ಷಿಸಿ
  • ಮರುಪಡೆಯುವಿಕೆ ಯೋಜನೆಗಳು ಮತ್ತು ಫೇಲ್ಓವರ್ ವಿಧಾನಗಳನ್ನು ದಾಖಲಿಸಿ ಪರೀಕ್ಷಿಸಿ
  • ಪೂರೈಕೆದಾರರ ಸೇವಾ ವ್ಯತ್ಯಯಗಳು ಮತ್ತು ಕ್ಲೌಡ್‌ನಿಂದ ನಿರ್ಗಮನದ ಸಂದರ್ಭಗಳಿಗೂ ಯೋಜಿಸಿ

ಪ್ರಮುಖ ಪರಿಗಣನೆಗಳು

  • ರ್ಯಾನ್ಸಮ್‌ವೇರ್‌ನಿಂದ ರಕ್ಷಿಸಲು ಬ್ಯಾಕಪ್‌ಗಳನ್ನು ಉತ್ಪಾದನಾ ಪರಿಸರದ ರುಜುವಾತುಗಳಿಂದ ಪ್ರತ್ಯೇಕಿಸಬೇಕು
  • ಮರುಪಡೆಯುವಿಕೆ ವಿಧಾನಗಳನ್ನು ದಾಖಲಿಸುವುದಷ್ಟೇ ಅಲ್ಲ, ನಿಯಮಿತವಾಗಿ ಪರೀಕ್ಷಿಸಬೇಕು
  • ಗುರುತು, DNS ಮತ್ತು ಕೀ ನಿರ್ವಹಣೆಯಂತಹ ಅವಲಂಬನೆಗಳನ್ನೂ ಮರುಪಡೆಯಲು ಸಾಧ್ಯವಾಗಬೇಕು

ಭದ್ರತಾ ಉದ್ದೇಶ

ಸೇವಾ ವ್ಯತ್ಯಯಗಳು, ದಾಳಿಗಳು ಅಥವಾ ವಿಪತ್ತುಗಳ ಸಂದರ್ಭದಲ್ಲಿಯೂ ಒಪ್ಪಿಕೊಂಡ ಗುರಿಗಳೊಳಗೆ ಸೇವೆಗಳು ಮತ್ತು ಡೇಟಾ ಲಭ್ಯವಾಗಿರಬೇಕು ಹಾಗೂ ಮರುಪಡೆಯಲು ಸಾಧ್ಯವಾಗಿರಬೇಕು.

← ಕ್ಲೌಡ್ ನಿರ್ವಹಣಾ ಪ್ಲೇನ್ ಮತ್ತು API ಭದ್ರತೆ ಗ್ರಂಥಾಲಯ ಕ್ಲೌಡ್ ಭದ್ರತೆಯ ಮೂಲಸ್ತಂಭಗಳು →

ತಂತ್ರಜ್ಞಾನ. ನಿಮ್ಮ ಭಾಷೆಯಲ್ಲಿ.
