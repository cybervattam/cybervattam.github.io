ಪಲ ಕಾರಣಿ ಸಾನ್ರುರುತಿ

ಪಲ ಕಾರಣಿ ಸಾನ್ರುರುತಿ (Multifactor Authentication)

ಪಲ ಕಾರಣಿ ಸಾನ್ರುರುತಿ ಎನ್ಪತು ಒರು ಪಯನರಿನ್ ಅಟೈಯಾಳತ್ತೈ ಉರುತಿ ಸೆಯ್ಯ ಒನ್ರುಕ್ಕುಮ್ ಮೇಲಾನ ಕಾರಣಿಕಳೈ ಪಯನ್ಪಟುತ್ತ ನಿರ್ಪನ್ತಿಕ್ಕುಮ್ ಒರು ಪಾತುಕಾಪ್ಪು ಮುರೈ. ಇಮ್ಮುರೈ, ಇರಣ್ಟು ಅಲ್ಲತು ಅತರ್ಕುಮ್ ಮೇಲಾನ ತೊಟರ್ಪಿಲ್ಲಾತ ಕಾರಣಿಕಳೈ ಸರಿಪಾರ್ತ್ತ ಪಿನ್ನರ್ ಒರು ಅಟೈಯಾಳತ್ತಿರ್ಕು ಸಾನ್ರುರುತಿ ಅಳಿಕ್ಕುಮ್. ಇತರ್ಕು ಪಯನ್ಪಟುಮ್ ಸಿಲ ಕಾರಣಿಕಳೈ ಕೀಳೇ ಕಾಣಲಾಮ್.

← ಪ್ರಮಾಣೀಕರಣ ಮತ್ತು ದೃಢೀಕರಣ ಗ್ರಂಥಾಲಯ ಓರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ →
