ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಅತಿಕಾರಮ್ ವಳಙ್ಕಲ್ ಗುರುತು ಮತ್ತು ಪ್ರವೇಶ ನಿರ್ವಹಣೆ ಅಟೈಯಾಳ ವರೈವುಕಳ್ →

ಅತಿಕಾರಮ್ ವಳಙ್ಕಲ್ ವಕೈಕಳ್

ಅತಿಕಾರಮ್ ವಳಙ್ಕಲ್ ವಕೈಕಳ್ / Provisioning Types

ವಿರುಪ್ಪುರಿಮೈ ಅತಿಕಾರಮ್ ವಳಙ್ಕಲ್ / Discretionary access provisioning

  • ಪೆರುಮ್ಪಾಲುಮ್ ಸಿರಿಯ ಮುತಲ್ ನಟುತ್ತರ ಅಳವಿಲಾನ ನಿರುವನಙ್ಕಳಿಲ್ ಪಯನ್ಪಟುತ್ತಪ್ಪಟುಮ್, ಇನ್ತ ಅಣುಕುಮುರೈ ಎನ್ತ ಪಯನ್ಪಾಟುಕಳ್ ಮರ್ರುಮ್ ತರವುಕಳೈ ಪಯನರ್ಕಳ್ ಅಣುಕ ಮುಟಿಯುಮ್ ಎನ್ಪತೈ ಮುಟಿವು ಸೆಯ್ಯ ಒರು ಪಿಣೈಯ ನಿರ್ವಾಕಿಯೈ ಅನುಮತಿಕ್ಕಿರತು..

ಸುಯಸೇವೈ ಅತಿಕಾರಮ್ ವಳಙ್ಕಲ್ / Self-service access provisioning

  • ಪೊತುವಾಕ, ಇನ್ತ ಅಣುಕುಮುರೈ ಒರು ನಿರ್ವಾಕಿಯಿನ್ ಪಣಿಸ್ಸುಮೈಯೈ ಕುರೈಕ್ಕ ಉತವುಕಿರತು. ಇತು ಪಯನರ್ಕಳ್ ಒರು ಕಣಕ್ಕೈಕೋರುತಲ್ ಮರ್ರುಮ್ ಸುಯ-ಮೇಲಾಣ್ಮೈ ಕಟವುಸ್ಸೊರ್ಕಳೈ ಕೋರುತಲ್ ಪೋನ್ರ ವಳಙ್ಕಲ್ ಸೆಯಲ್ಮುರೈಯಿನ್ ಸಿಲ ಅಮ್ಸಙ್ಕಳಿಲ್ ಪಙ್ಕೇರ್ಕ ಉತವುಕಿರತು.

ಪಣಿಪ್ಪಾಯ್ವು ಅಟಿಪ್ಪಟೈಯಿಲಾನ ಕಣಕ್ಕು ವಳಙ್ಕುತಲ್ / Workflow based account provisioning

  • ಒರು ಪಯನ್ಪಾಟು ಅಲ್ಲತು ತರವುಕ್ಕಾನ ಪಯನರ್ ಅಣುಕ ಅತಿಕಾರಮ್ ವಳಙ್ಕುವತರ್ಕು ಮುನ್, ನಿಯಮಿಕ್ಕಪ್ಪಟ್ಟ ಒಪ್ಪುತಲ್ ಅಳಿಪ್ಪವರ್ಕಳಿಟಮಿರುನ್ತು ಒಪ್ಪುತಲ್ ತೇವೈ. ಉತಾರಣಮಾಕ, ನಿತಿ ಮೇಲಾಣ್ಮೈ ಅಮೈಪ್ಪೈ ಅಣುಕ ಅತಿಕಾರಮ್ ವಳಙ್ಕುವತರ್ಕು ಮುನ್, ಅನ್ನಿರುವನತ್ತಿನ್ ತಲೈಮೈ ನಿತಿ ಅತಿಕಾರಿ ಒಪ್ಪುತಲ್ ತೇವೈಪ್ಪಟುಮ್.

ತಾನಿಯಙ್ಕು ಕಣಕ್ಕು ವಳಙ್ಕುತಲ್ / Automated account provisioning

  • ಒವ್ವೊರು ಕಣಕ್ಕುಮ್ ಒರು ಮೈಯಪ್ಪಟುತ್ತಪ್ಪಟ್ಟ ಮೇಲಾಣ್ಮೈ ಪಯನ್ಪಾಟ್ಟು ಇಟೈಮುಕಮ್ ಮೂಲಮ್ ಒರೇ ಮುರೈಯಿಲ್ ಸೇರ್ಕ್ಕಪ್ಪಟುಕಿರತು.
  • ಇತು ಪಯನರ್ ನಮ್ಪಿಕ್ಕೈಸ್ಸಾನ್ರುಕಳೈಸ್ ಸೇರ್ಪ್ಪತು ಮರ್ರುಮ್ ನಿರ್ವಕಿಪ್ಪತು ಪೋನ್ರ ಸೆಯಲ್ಮುರೈಯೈ ಒಳುಙ್ಕುಪಟುತ್ತುಕಿರತು ಮರ್ರುಮ್ ಕುರಿಪ್ಪಿಟ್ಟ ಪಯನ್ಪಾಟುಕಳ್ ಮರ್ರುಮ್ ತರವು ಆತಾರಙ್ಕಳೈ ಯಾರ್ ಅಣುಕುಕಿರಾರ್ಕಳ್ ಎನ್ಪತೈಕ್ ಕಣ್ಕಾಣಿಕ್ಕ ನಿರ್ವಾಕಿಕಳುಕ್ಕು ಮಿಕವುಮ್ ತುಲ್ಲಿಯಮಾನ ವಳಿಯೈ ವಳಙ್ಕುಕಿರತು.
  • ವಳಙ್ಕಲ್ ಮರ್ರುಮ್ ಅಟೈಯಾಳ ಮೇಲಾಣ್ಮೈ ಸೆಯಲ್ಮುರೈಕಳ್ ಒರೇ ಮಾತಿರಿಯಾಕ ಇರುನ್ತಾಲುಮ್, ಪಲ್ವೇರು ಪಯನರ್ಕಳಿಟೈಯೇ (ಎ.ಕಾ. ನೋಯಾಳಿಕಳ್, ಮರುತ್ತುವರ್ಕಳ್, ವಾಟಿಕ್ಕೈಯಾಳರ್ಕಳ್ ಮರ್ರುಮ್ ಕೂಟ್ಟಾಳರ್ಕಳ್) ವಳಙ್ಕಲ್ ಅಳವು ಮರ್ರುಮ್ ವಕೈ ಪೆರಿತುಮ್ ವೇರುಪಟುಕಿರತು
