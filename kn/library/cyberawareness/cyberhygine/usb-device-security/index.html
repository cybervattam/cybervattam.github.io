ಸೈಟ್‌ನಲ್ಲಿ ಹುಡುಕಿ

ಪ್ರಸ್ತುತ ಭಾಷೆಯಲ್ಲಿ ಹುಡುಕಲು ಟೈಪ್ ಮಾಡಿ.

← ಕಂಪ್ಯೂಟರ್ ಸುರಕ್ಷತೆ ಸಲಹೆಗಳು ಸೈಬರ್ ನೈರ್ಮಲ್ಯ ಪಾಸ್ವರ್ಡ್ ಭದ್ರತಾ ನಿರ್ವಹಣೆ →

USB ಸಾಧನ ಭದ್ರತೆ

USB ಸಾಧನಗಳು ಡೇಟಾವನ್ನು ವರ್ಗಾಯಿಸಲು ಅನುಕೂಲಕರವಾಗಿದೆ, ಆದರೆ ಅವುಗಳ ಪೋರ್ಟಬಿಲಿಟಿ ಡೇಟಾ ಕಳ್ಳತನ, ಡೇಟಾ ಸೋರಿಕೆ ಮತ್ತು ಮಾಲ್‌ವೇರ್ ಅಪಾಯಗಳನ್ನು ಪರಿಚಯಿಸಬಹುದು. ಉದಾಹರಣೆಗಳಲ್ಲಿ ಫ್ಲಾಶ್ ಡ್ರೈವ್‌ಗಳು, ಪೋರ್ಟಬಲ್ ಹಾರ್ಡ್ ಡ್ರೈವ್‌ಗಳು, ಮೆಮೊರಿ ಕಾರ್ಡ್‌ಗಳು, ಕ್ಯಾಮೆರಾಗಳು, ಮೊಬೈಲ್ ಫೋನ್‌ಗಳು ಮತ್ತು USB ಕೀಬೋರ್ಡ್‌ಗಳು ಅಥವಾ ಮೌಸ್‌ಗಳು ಸೇರಿವೆ.

ಸುರಕ್ಷಿತ ಅಭ್ಯಾಸಗಳು

  • ಪ್ರತಿ USB ಸಾಧನವನ್ನು ಬಳಸುವ ಮೊದಲು ಆಂಟಿವೈರಸ್ ಅಥವಾ ಎಂಡ್‌ಪಾಯಿಂಟ್ ರಕ್ಷಣೆಯೊಂದಿಗೆ ಸ್ಕ್ಯಾನ್ ಮಾಡಿ.
  • USB ಸಾಧನಗಳನ್ನು ಬಳಸುವಾಗ ಕಂಪ್ಯೂಟರ್‌ಗಳಲ್ಲಿ ಆಟೋರನ್ ಮತ್ತು ಆಟೋಪ್ಲೇ ಅನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸಿ.
  • ಅಪರಿಚಿತ ಅಥವಾ ವಿಶ್ವಾಸಾರ್ಹವಲ್ಲದ USB ಸಾಧನಗಳನ್ನು ಸಂಪರ್ಕಿಸುವುದನ್ನು ತಪ್ಪಿಸಿ.
  • ಯುಎಸ್‌ಬಿ ಸಾಧನಗಳು ಅಗತ್ಯವಿಲ್ಲದಿದ್ದಾಗ ಅವುಗಳನ್ನು ನಿಷ್ಕ್ರಿಯಗೊಳಿಸಿ ಅಥವಾ ತೆಗೆದುಹಾಕಿ.
