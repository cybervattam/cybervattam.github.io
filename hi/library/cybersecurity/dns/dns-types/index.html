DNS के प्रकार

DNS के प्रकार / DNS Types

आंतरिक DNS / Internal DNS

यह वह DNS है जो किसी संगठन के निजी नेटवर्क के भीतर चलने वाले सर्वरों और उनके IP एड्रेस को मैप करता है।

बाहरी DNS / External DNS

यह वह DNS है जो इंटरनेट या सार्वजनिक नेटवर्क पर उपलब्ध सर्वरों और उनके IP एड्रेस का प्रबंधन करता है।

रिवर्स DNS / Reverse DNS

यह रिवर्स क्वेरी का प्रकार है। यह किसी निश्चित IP एड्रेस से संबंधित डोमेन नाम लौटाता है। DNS में PTR रिकॉर्ड इस प्रकार का डेटा arpa फॉर्मेट में संग्रहीत करता है। रिवर्स क्वेरी में यही मान लौटाया जाता है। सुरक्षा लॉगिंग सॉफ़्टवेयर और ईमेल गेटवे इसी विधि का उपयोग करते हैं।

डायनेमिक DNS / Dynamic DNS

जब किसी डोमेन का IP एड्रेस बार-बार बदलता रहता है, तो इस विधि से IP एड्रेस को स्वचालित रूप से अपडेट किया जाता है। Microsoft Active Directory में यह एक महत्वपूर्ण हिस्सा है। डोमेन नियंत्रक उस डोमेन में उपलब्ध सेवाओं के लिए DNS प्रविष्टियाँ अपडेट करता है, जिन्हें अन्य कंप्यूटर उपयोग करते हैं।
