DNS परिचय

DNS परिचय / DNS Introduction

DNS (डोमेन नेम सिस्टम) विशेष सॉफ़्टवेयर है, जो कंप्यूटर सर्वर पर चलता है। यह सर्वर नामों और उनके संबंधित IP एड्रेस के बीच मैपिंग रखता है। यह मोबाइल फोन की संपर्क सूची या फोनबुक जैसा है, जहाँ नाम से जानकारी ढूँढी जाती है। ब्राउज़र और एप्लिकेशन इंटरनेट या अन्य नेटवर्क संसाधनों तक पहुँचने के लिए डोमेन नाम को IP एड्रेस में बदलते हैं। DNS सर्वर विशेष सॉफ़्टवेयर चलाते हैं और नामों को हल करने के लिए एक विशिष्ट प्रोटोकॉल के आधार पर आपस में संवाद करते हैं। DNS को शुरुआत से ही UDP (User Datagram Protocol) और TCP (Transmission Control Protocol) पोर्ट 53 पर काम करने के लिए डिज़ाइन किया गया है, और सामान्यतः यह UDP में काम करता है, जबकि TCP का उपयोग भी किया जा सकता है।
