क्लाउड कंप्यूटिंग की भूमिकाएँ

क्लाउड कंप्यूटिंग की भूमिकाएँ / Cloud Computing Roles

  • क्लाउड सेवा प्रदाता / Cloud Provider
    • वह व्यक्ति, संस्था या कंपनी जो इच्छुक पक्षों को क्लाउड कंप्यूटिंग सेवाएँ उपलब्ध कराने की जिम्मेदारी लेती है।
  • क्लाउड उपभोक्ता / ग्राहक / Cloud Consumer
    • वह व्यक्ति या संस्था जो क्लाउड सेवा प्रदाता के साथ व्यावसायिक संबंध रखती है और सेवा का उपयोग करती है।
  • क्लाउड कैरियर / Cloud Carrier
    • वह मध्यस्थ जो क्लाउड सेवा प्रदाता से उपभोक्ता तक क्लाउड सेवाओं की कनेक्टिविटी और परिवहन उपलब्ध कराता है।
  • क्लाउड ब्रोकर / Cloud Broker
    • वह संस्था जो क्लाउड सेवाओं के उपयोग, प्रदर्शन और वितरण का प्रबंधन करती है तथा क्लाउड सेवा प्रदाताओं और उपभोक्ताओं के बीच संबंधों को बेहतर बनाने के लिए बातचीत करती है।
  • क्लाउड एक्सेस सिक्योरिटी ब्रोकर / Cloud Access Security Broker (CASB)
    • इस प्रकार का सॉफ़्टवेयर क्लाउड की ओर भेजे जा रहे संचार को रोकने या गतिविधि की निगरानी करने, नीतियाँ लागू करने और सुरक्षा समस्याओं का पता लगाकर उन्हें रोकने के लिए API के माध्यम से या सीधे Software as a Service से जुड़ता है। इसका उपयोग सामान्यतः किसी संस्था की अनुमत और अनधिकृत सेवाओं (Software as a Service) को प्रबंधित करने के लिए किया जाता है।
