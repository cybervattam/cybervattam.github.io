क्लाउड कंप्यूटिंग सेवा मॉडल / Cloud Service Models




1. सेवा के रूप में इन्फ्रास्ट्रक्चर / Infrastructure as a Service (IaaS)

क्लाउड सेवा प्रदाता वर्चुअलाइज्ड कंप्यूटिंग, नेटवर्क या स्टोरेज जैसे मूल कंप्यूटिंग इन्फ्रास्ट्रक्चर का प्रबंधन करके संसाधन पूल तक पहुँच प्रदान करते हैं। क्लाउड उपभोक्ता अपनी आवश्यकता के अनुसार इसके ऊपर अलग-अलग ऑपरेटिंग सिस्टम और एप्लिकेशन स्थापित कर सकते हैं।

2. सेवा के रूप में प्लेटफ़ॉर्म / Platform as a Service (PaaS)

क्लाउड सेवा प्रदाता डेटाबेस, एप्लिकेशन प्लेटफ़ॉर्म, प्रोग्रामिंग प्लेटफ़ॉर्म और रनटाइम वातावरण जैसे प्लेटफ़ॉर्म को अमूर्त रूप में उपलब्ध कराते हैं।

उदाहरण:

  • Python, PHP या अन्य स्रोत कोड चलाने का वातावरण
  • Database as a Service
  • Data Warehouse as a Service
  • Data Storage as a Service
  • Machine Learning as a Service

मुख्य अंतर यह है कि आपको अंतर्निहित सर्वर, नेटवर्क या अन्य इन्फ्रास्ट्रक्चर का प्रबंधन नहीं करना पड़ता।

3. सेवा के रूप में सॉफ़्टवेयर / Software as a Service (SaaS)

यह क्लाउड सेवा प्रदाता द्वारा प्रबंधित और उपलब्ध कराया गया पूर्ण एप्लिकेशन होता है। उपभोक्ता इसे वेब ब्राउज़र, मोबाइल एप्लिकेशन या हल्के क्लाइंट एप्लिकेशन के माध्यम से एक्सेस कर सकते हैं।

कस्टमाइज़ेशन या कॉन्फ़िगरेशन उपलब्ध हो सकता है, लेकिन सुविधाओं या क्षमताओं को बदला नहीं जा सकता।

उदाहरण:

  • Netflix
  • Prime Video
  • Gmail
  • YouTube
  • Zoom
  • Microsoft 365 जैसी सेवाएँ
