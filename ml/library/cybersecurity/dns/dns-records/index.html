DNS റെക്കോർഡുകൾ

  • A റെക്കോർഡ് - ഒരു ഡൊമെയ്‌നിന്റെ IPv4 വിലാസം സൂക്ഷിക്കുന്നു.
  • AAAA റെക്കോർഡ് - ഒരു ഡൊമെയ്‌നിന്റെ IPv6 വിലാസം സൂക്ഷിക്കുന്നു.
  • CNAME റെക്കോർഡ് - ഒരു അലിയാസ് നാമം സൂക്ഷിക്കുന്നു. CNAME ഉള്ളപ്പോൾ IP വിലാസം നേരിട്ട് നൽകില്ല.
  • MX റെക്കോർഡ് - ഒരു ഡൊമെയ്‌നിലേക്കുള്ള ഇമെയിൽ അനുയോജ്യമായ മെയിൽ സെർവറിലേക്ക് അയയ്ക്കുന്നു.
  • TXT റെക്കോർഡ് - അഡ്മിനിസ്ട്രേറ്റർമാരോ സേവനങ്ങളോ ഉപയോഗിക്കുന്ന ടെക്സ്റ്റ് വിവരങ്ങൾ സൂക്ഷിക്കുന്നു.
  • NS റെക്കോർഡ് - ഡൊമെയ്‌നിന്റെ ഓതറിറ്റേറ്റീവ് നെയിം സെർവർ സൂക്ഷിക്കുന്നു.
  • SOA റെക്കോർഡ് - സോണിനെക്കുറിച്ചുള്ള ഭരണപരമായ വിവരങ്ങൾ സൂക്ഷിക്കുന്നു.
  • SRV റെക്കോർഡ് - ഒരു പ്രത്യേക സേവനത്തിനുള്ള പോർട്ടും ഹോസ്റ്റും വ്യക്തമാക്കുന്നു.
  • PTR റെക്കോർഡ് - റിവേഴ്സ് ലുക്കപ്പിനായി ഉപയോഗിക്കുന്നു; IP വിലാസത്തെ വീണ്ടും ഹോസ്റ്റ് നാമത്തിലേക്ക് മാപ്പ് ചെയ്യുന്നു.

DNSSEC-നുള്ള പ്രത്യേക റെക്കോർഡുകൾ:

  • RRSIG റെക്കോർഡ് - DNS റെക്കോർഡുകളുടെ ഒരു സെറ്റിനുള്ള ഡിജിറ്റൽ ഒപ്പുകൾ സൂക്ഷിക്കുന്നു.
  • DNSKEY റെക്കോർഡ് - DNSSEC-ൽ ഉപയോഗിക്കുന്ന പൊതു കീ സൂക്ഷിക്കുന്നു.
  • DS റെക്കോർഡ് - ഡെലിഗേഷനായി DNSKEY റെക്കോർഡിന്റെ ഹാഷ് സൂക്ഷിക്കുന്നു.
  • NSEC, NSEC3 റെക്കോർഡുകൾ - ഒരു റെക്കോർഡ് നിലവിലില്ലെന്ന് വ്യക്തമായി തെളിയിക്കുന്നു.
  • CDNSKEY, CDS റെക്കോർഡുകൾ - പാരന്റ് സോണിലെ DS റെക്കോർഡ് അപ്ഡേറ്റ് ചെയ്യാൻ ചൈൽഡ് സോൺ ഉപയോഗിക്കുന്നു.
Note
