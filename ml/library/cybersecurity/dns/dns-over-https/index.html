HTTPS വഴിയുള്ള DNS (DoH)

DNS അന്വേഷണങ്ങൾ എൻക്രിപ്റ്റ് ചെയ്ത് HTTPS വഴി റിക്കർസീവ് റിസോൾവറിലേക്ക് അയയ്ക്കുന്ന സുരക്ഷാ പ്രോട്ടോക്കോളാണ് DNS over HTTPS.

നെറ്റ്‌വർക്ക് പാതയിലെ മൂന്നാം കക്ഷികൾക്ക് DNS അന്വേഷണവും പ്രതികരണ ഡാറ്റയും കാണാനോ മാറ്റം വരുത്താനോ കഴിയാതിരിക്കുക എന്നതാണ് ലക്ഷ്യം. ഇത് ഉപയോക്തൃ സ്വകാര്യത മെച്ചപ്പെടുത്തുകയും ഡാറ്റ കൈമാറ്റത്തിനിടെ സംരക്ഷിക്കുകയും ചെയ്യുന്നു.

Note

സാങ്കേതികവിദ്യ. നിങ്ങളുടെ ഭാഷയിൽ.
