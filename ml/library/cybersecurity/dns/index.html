◎ ലൈബ്രറി

ഡൊമെയ്ൻ നെയിം സിസ്റ്റം (DNS)

ഡൊമെയ്ൻ നെയിം സിസ്റ്റം (DNS) മനുഷ്യർക്ക് വായിക്കാനാകുന്ന ഡൊമെയ്ൻ നാമങ്ങളെ IP വിലാസങ്ങളാക്കി മാറ്റുന്ന പ്രധാന ഇന്റർനെറ്റ് സേവനമാണ്. ആവശ്യമായപ്പോൾ ഇത് റിവേഴ്സ് ലുക്കപ്പുകളും പിന്തുണയ്ക്കുന്നു.

DNS ഉപയോക്താക്കളെയും ആപ്ലിക്കേഷനുകളെയും ദീർഘമായ സംഖ്യാ വിലാസങ്ങൾ ഓർമ്മിക്കാതെ വെബ്സൈറ്റുകൾ, സേവനങ്ങൾ, മറ്റ് വിഭവങ്ങൾ എന്നിവയിലെത്താൻ സഹായിക്കുന്നു. ഇത് ഇന്റർനെറ്റ് അടിസ്ഥാനസൗകര്യത്തിന്റെ പ്രധാന ഭാഗമാണ്; നാമപരിഹാരം, സേവന കണ്ടെത്തൽ, ഇമെയിൽ റൂട്ടിംഗ്, സുരക്ഷാ പ്രവർത്തനങ്ങൾ എന്നിവയെ പിന്തുണയ്ക്കുന്നു.

ഈ വിഭാഗത്തിൽ DNS ശ്രേണി, ക്വറി പരിഹാരം, റെക്കോർഡുകൾ, സോണുകൾ, സുരക്ഷാ വിപുലീകരണങ്ങൾ, DNS സ്വകാര്യത, ആധുനിക DNS പ്രോട്ടോക്കോളുകൾ എന്നിവ ഉൾപ്പെടുന്നു.
