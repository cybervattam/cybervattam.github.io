DNS ആമുഖം

DNS ആമുഖം

സെർവറുകളിൽ പ്രവർത്തിക്കുന്ന ഒരു പ്രത്യേക സോഫ്റ്റ്‌വെയർ സേവനമാണ് DNS. ഹോസ്റ്റ് നാമങ്ങളും അവയുമായി ബന്ധപ്പെട്ട IP വിലാസങ്ങളും തമ്മിലുള്ള മാപ്പിംഗ് ഇത് സൂക്ഷിക്കുന്നു.

ഇത് മൊബൈൽ ഫോണിലെ കോൺടാക്ട് ലിസ്റ്റിനെയോ ഫോൺബുക്കിനെയോ പോലെയാണ്. ഉപയോക്താക്കളും ആപ്ലിക്കേഷനുകളും ഡൊമെയ്ൻ നാമങ്ങൾ ഉപയോഗിക്കുമ്പോൾ കമ്പ്യൂട്ടറുകൾക്ക് സംഖ്യാത്മക IP വിലാസങ്ങളാണ് മനസ്സിലാകുന്നത്. DNS നാമങ്ങളെ വിലാസങ്ങളാക്കി മാറ്റി ട്രാഫിക് ശരിയായ ലക്ഷ്യസ്ഥാനത്ത് എത്തിക്കുന്നു.

DNS സെർവറുകൾ പരസ്പരം ആശയവിനിമയം നടത്താനും നാമങ്ങൾ പരിഹരിക്കാനും പ്രത്യേക പ്രോട്ടോക്കോളുകൾ ഉപയോഗിക്കുന്നു. DNS സാധാരണയായി UDP പോർട്ട് 53 ഉപയോഗിക്കുന്നു; വലിയ പ്രതികരണങ്ങൾക്കും സോൺ ട്രാൻസ്ഫറുകൾക്കും TCP പോർട്ട് 53 ഉപയോഗിക്കാം.
