സൈറ്റിൽ തിരയുക

നിലവിലെ ഭാഷയിൽ തിരയാൻ ടൈപ്പ് ചെയ്യുക.

← ക്ലൗഡ് നേറ്റീവ് ആപ്ലിക്കേഷൻ പ്രൊട്ടക്ഷൻ പ്ലാറ്റ്‌ഫോം (CNAPP) ക്ലൗഡ് സുരക്ഷ ക്ലൗഡ് സെക്യൂരിറ്റി പോസ്‌ചർ മാനേജ്മെന്റ് (CSPM) →

ക്ലൗഡ് വർക്ക്‌ലോഡ് പ്രൊട്ടക്ഷൻ പ്ലാറ്റ്‌ഫോം (CWPP)

ക്ലൗഡ് വർക്ക്‌ലോഡ് പ്രൊട്ടക്ഷൻ പ്ലാറ്റ്‌ഫോം (CWPP)

പൊതു ക്ലൗഡുകളിലും സ്വകാര്യ ക്ലൗഡുകളിലും ഡാറ്റാ സെന്ററുകളിലും പ്രവർത്തിക്കുന്ന ഭൗതിക സെർവറുകൾ, വിർച്ച്വൽ മെഷീനുകൾ, കണ്ടെയ്‌നറുകൾ, സർവർലെസ് ഫംഗ്ഷനുകൾ എന്നിവയുൾപ്പെടെ, എവിടെ പ്രവർത്തിച്ചാലും വർക്ക്‌ലോഡുകളെ സംരക്ഷിക്കുന്നതാണ് ക്ലൗഡ് വർക്ക്‌ലോഡ് പ്രൊട്ടക്ഷൻ പ്ലാറ്റ്‌ഫോം.

വർക്ക്‌ലോഡുകളുടെ പരിണാമം

വർക്ക്‌ലോഡുകൾ കൂടുതൽ ചെറുതും കുറഞ്ഞ ആയുസ്സുള്ളതുമായി മാറി; അതിനാൽ അവയെ സുരക്ഷിതമാക്കേണ്ട രീതിയും മാറുന്നു.

ജീവിതചക്രത്തിലുടനീളമുള്ള സംരക്ഷണം

വർക്ക്‌ലോഡിന്റെ ബിൽഡ് ഘട്ടവും റൺടൈം ഘട്ടവും CWPP സംരക്ഷിക്കുന്നു.

സുരക്ഷിത ബിൽഡ്

  • ദുർബലതകളുള്ള ഘടകങ്ങൾ
  • ക്ലൗഡ് ക്രമീകരണം
  • രഹസ്യ ക്രെഡൻഷ്യലുകൾ
  • മാൽവെയർ
  • API കണ്ടെത്തൽ

റൺടൈം സംരക്ഷണം

  • വർക്ക്‌ലോഡിലെ ദുർബലതകളും ക്രമീകരണവും
  • വർക്ക്‌ലോഡ് സെഗ്മെന്റേഷൻ
  • സമഗ്രതാ നിരീക്ഷണം
  • ആപ്ലിക്കേഷൻ നിയന്ത്രണം
  • പെരുമാറ്റ നിരീക്ഷണം
  • ഹോസ്റ്റ് ഇൻട്രൂഷൻ പ്രിവൻഷൻ (HIPS)
  • ആന്റി-മാൽവെയർ

അപകടസാധ്യതയെ അടിസ്ഥാനമാക്കിയുള്ള നിയന്ത്രണ മുൻഗണന

ഹാർഡനിംഗ്, ക്രമീകരണം, ദുർബലതാ മാനേജ്മെന്റ്, നെറ്റ്‌വർക്ക് സെഗ്മെന്റേഷൻ എന്നിവയിൽനിന്ന് ആരംഭിച്ച്, അടിസ്ഥാനപരമായ നിയന്ത്രണങ്ങൾക്ക് ആദ്യം മുൻഗണന നൽകാം.

സുരക്ഷാ ലക്ഷ്യം

ക്ലൗഡ് നൽകുന്ന വേഗതയും വഴക്കവും കുറയ്ക്കാതെ വർക്ക്‌ലോഡുകളെ സ്ഥിരതയോടെ സുരക്ഷിതമാക്കുക.
