IP വിലാസ പരിധിയും ഓട്ടോണമസ് സിസ്റ്റം നമ്പറുകളും (ASN)

ഇന്റർനെറ്റ് അസൈൻഡ് നമ്പേഴ്സ് അതോറിറ്റി (IANA), IP വിലാസ പരിധിയും ഓട്ടോണമസ് സിസ്റ്റം നമ്പറുകളും (ASN) ഉൾപ്പെടെയുള്ള ഇന്റർനെറ്റ് നമ്പർ വിഭവങ്ങളുടെ വിനിയോഗ ചുമതല റീജിയണൽ ഇന്റർനെറ്റ് രജിസ്ട്രികൾക്ക് (RIRs) ഏൽപ്പിക്കുന്നു. നിലവിൽ ARIN, LACNIC, RIPE NCC, AFRINIC, APNIC എന്നീ അഞ്ച് RIR-കൾ പ്രവർത്തിക്കുന്നു.


റീജിയണൽ ഇന്റർനെറ്റ് രജിസ്ട്രികൾക്ക് IP വിലാസ പരിധിയും ASN-കളും നേരിട്ട് നിയന്ത്രിക്കാം, അല്ലെങ്കിൽ ആ ചുമതല ഒരു നാഷണൽ ഇന്റർനെറ്റ് രജിസ്ട്രിക്ക് (NIR) ഏൽപ്പിക്കാം.

ഉദാഹരണത്തിന്, ഇന്ത്യയിലെ രജിസ്ട്രി ചുമതലകൾ Indian Registry for Internet Names and Numbers (IRINN) എന്ന സ്ഥാപനത്തിന് ഏൽപ്പിച്ചിരിക്കുന്നു: https://www.irinn.in.



Border Gateway Protocol (BGP) റൂട്ടിംഗിനായി ഓരോ ഓട്ടോണമസ് സിസ്റ്റത്തിനും ഒരു സവിശേഷ ഓട്ടോണമസ് സിസ്റ്റം നമ്പർ നൽകുന്നു. ഇതുവഴി ഇന്റർനെറ്റിലെ ഓരോ നെറ്റ്‌വർക്കിനെയും സവിശേഷമായി തിരിച്ചറിയാൻ കഴിയും.

ഒന്നോ അതിലധികമോ നെറ്റ്‌വർക്ക് ഓപ്പറേറ്റർമാരുടെ നിയന്ത്രണത്തിലുള്ള, ബന്ധിപ്പിച്ച IP റൂട്ടിംഗ് പ്രിഫിക്സുകളുടെ ഒരു ശേഖരമാണ് ഓട്ടോണമസ് സിസ്റ്റം. ഇത് ഇന്റർനെറ്റിൽ വ്യക്തമായി നിർവചിച്ച റൂട്ടിംഗ് നയം അവതരിപ്പിക്കുന്ന ഒരു ഭരണസംഘടനയെയോ ഡൊമെയ്‌നെയോ പ്രതിനിധീകരിക്കുന്നു.
