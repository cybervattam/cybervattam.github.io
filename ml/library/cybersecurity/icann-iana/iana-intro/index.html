ഇന്റർനെറ്റ് അസൈൻഡ് നമ്പേഴ്സ് അതോറിറ്റി (IANA)

ആഗോള ഡൊമെയ്ൻ നാമങ്ങൾ, നമ്പർ വിഭവങ്ങൾ, പ്രോട്ടോക്കോൾ അസൈൻമെന്റുകൾ എന്നിവ ഏകോപിപ്പിക്കുന്ന സ്ഥാപനമാണ് ഇന്റർനെറ്റ് അസൈൻഡ് നമ്പേഴ്സ് അതോറിറ്റി.

ഈ അതോറിറ്റി ആദ്യം അമേരിക്കൻ സർക്കാരിന്റെ നിയന്ത്രണത്തിലായിരുന്നു. ഇന്റർനെറ്റ് ലോകമെമ്പാടും വ്യാപകമായി സ്വീകരിക്കപ്പെട്ടതോടെ, ഈ പ്രവർത്തനങ്ങൾ ഒരു രാജ്യം മാത്രം നിയന്ത്രിക്കരുതെന്ന് തീരുമാനിച്ചു.

ഇപ്പോൾ ഈ പ്രവർത്തനങ്ങൾ Internet Corporation for Assigned Names and Numbers (ICANN) എന്ന അന്താരാഷ്ട്ര ലാഭേച്ഛയില്ലാത്ത പൊതുജനക്ഷേമ സംഘടനയാണ് നിയന്ത്രിക്കുന്നത്. അതോറിറ്റിയുടെ പ്രവർത്തനങ്ങളിൽ ഉൾപ്പെടുന്നത്:

* 1. ഡൊമെയ്ൻ നെയിം സേവനങ്ങൾ


  • 1.1 DNS റൂട്ട് സോൺ മാനേജ്മെന്റും കീ സൈനിംഗ് സെറിമണിയും
    • DNS ശ്രേണിയുടെ മുകളിലുള്ള റൂട്ട് സോൺ ഡാറ്റ IANA നിയന്ത്രിക്കുന്നു.
    • ടോപ്പ്-ലെവൽ ഡൊമെയ്ൻ രജിസ്ട്രികൾ, റൂട്ട് സെർവർ ഓപ്പറേറ്റർ സ്ഥാപനങ്ങൾ, ICANN-ന്റെ നയരൂപീകരണ സമിതികൾ എന്നിവയുമായി ഏകോപിപ്പിക്കുന്നതും ഈ പ്രവർത്തനത്തിൽ ഉൾപ്പെടുന്നു.
    • റൂട്ട് സോണിൽ DNSSEC പ്രവർത്തിപ്പിക്കുന്നതിനുള്ള കീ സൈനിംഗ് സെറിമണിയും IANA നടത്തുന്നു.
    • anycast IP വിലാസം ഉപയോഗിക്കുന്ന 13 റൂട്ട് സെർവർ ഐഡന്റിറ്റികളാണ് റൂട്ട് സേവനം നൽകുന്നത്.
    • കമ്പ്യൂട്ടറുകൾ ടോപ്പ്-ലെവൽ ഡൊമെയ്ൻ സെർവറുകളുടെ വിലാസങ്ങൾ കാഷെ ചെയ്യുന്നതിനാൽ റൂട്ട് സെർവറുകൾ ഇടയ്ക്കിടെ മാത്രമേ അന്വേഷിക്കപ്പെടുന്നുള്ളൂ. എന്നിരുന്നാലും അവ ഇന്റർനെറ്റ് ഇൻഫ്രാസ്ട്രക്ചറിന്റെ നിർണായക ഭാഗമാണ്.
    • റൂട്ട് സെർവർ ഓപ്പറേറ്റർമാർ ഭൂരിഭാഗവും സ്വതന്ത്രരാണെങ്കിലും, അവർ പരസ്പരവും ICANN-ുമായും ഏകോപിക്കണം: https://root-servers.org/

  • 1.2 ടോപ്പ്-ലെവൽ ഡൊമെയ്‌നുകളുടെ ഡാറ്റാബേസ്
    • .com പോലുള്ള ജനറിക് ടോപ്പ്-ലെവൽ ഡൊമെയ്‌നുകളും (gTLD) .uk പോലുള്ള കൺട്രി-കോഡ് ടോപ്പ്-ലെവൽ ഡൊമെയ്‌നുകളും (ccTLD) ഉൾപ്പെടെയുള്ള ടോപ്പ്-ലെവൽ ഡൊമെയ്‌നുകളുടെ ഡെലിഗേഷൻ വിവരങ്ങൾ റൂട്ട് സോൺ ഡാറ്റാബേസിൽ അടങ്ങിയിരിക്കുന്നു.
    • DNS റൂട്ട് സോണിന്റെ മാനേജർ എന്ന നിലയിൽ, നിശ്ചയിച്ച നയങ്ങൾക്കും നടപടിക്രമങ്ങൾക്കും അനുസരിച്ച് ഈ ഡെലിഗേഷനുകൾ ഏകോപിപ്പിക്കുന്നത് IANA-യുടെ ഉത്തരവാദിത്തമാണ്.

  • 1.3 .int രജിസ്ട്രി
    • ഒരു രാജ്യത്തിന്റെ കൺട്രി-കോഡ് ടോപ്പ്-ലെവൽ ഡൊമെയ്‌നിൽ സ്വാഭാവികമായി ഉൾപ്പെടാത്ത അന്താരാഷ്ട്ര സ്ഥാപനങ്ങൾക്കും സംഘടനകൾക്കുമായി .int ടോപ്പ്-ലെവൽ ഡൊമെയ്ൻ രൂപകൽപ്പന ചെയ്തതാണ്. ഉദാഹരണത്തിന്, ലോകാരോഗ്യ സംഘടന who.int എന്ന ഡൊമെയ്ൻ ഉപയോഗിക്കുന്നു.

  • 1.4 .arpa രജിസ്ട്രി
    • IP വിലാസങ്ങളുടെ റിവേഴ്സ് മാപ്പിംഗും ENUM ടെലിഫോൺ നമ്പർ മാപ്പിംഗും പോലുള്ള ഇന്റർനെറ്റ് ഇൻഫ്രാസ്ട്രക്ചർ പ്രവർത്തനങ്ങൾക്ക് .arpa ഡൊമെയ്ൻ ഉപയോഗിക്കുന്നു.
    • .arpa-യുടെ നയചുമതലയുള്ള Internet Architecture Board-ുമായി അടുത്ത ഏകോപനത്തിലാണ് IANA ഈ ഡൊമെയ്ൻ നിയന്ത്രിക്കുന്നത്.

* 2. നമ്പർ വിഭവങ്ങൾ

  • IP വിലാസങ്ങൾ
  • ഓട്ടോണമസ് സിസ്റ്റം നമ്പറുകൾ

* 3. പ്രോട്ടോക്കോൾ അസൈൻമെന്റുകൾ


  • 3.1 പ്രോട്ടോക്കോൾ രജിസ്ട്രി
    • Internet Engineering Task Force (IETF)-മായി ഏകോപിച്ച് ഇന്റർനെറ്റ് പ്രോട്ടോക്കോളുകളിൽ ഉപയോഗിക്കുന്ന നിരവധി കോഡുകളും നമ്പറുകളും IANA പരിപാലിക്കുന്നു.
    • IANA നിയന്ത്രിക്കുന്ന പ്രോട്ടോക്കോളുകളുടെ പട്ടിക https://www.iana.org/protocols എന്ന വിലാസത്തിൽ ലഭ്യമാണ്.
    • പ്രോട്ടോക്കോൾ രജിസ്ട്രിയുടെ ഭാഗമായി IANA പോർട്ട് നമ്പറുകൾ നിയന്ത്രിക്കുകയും well-known, രജിസ്റ്റർ ചെയ്ത പോർട്ട് പരിധികളുടെ ഔദ്യോഗിക പട്ടിക പരിപാലിക്കുകയും ചെയ്യുന്നു.
      • Well-known പോർട്ട് നമ്പറുകൾ (0 മുതൽ 1023 വരെ)
      • രജിസ്റ്റർ ചെയ്ത പോർട്ട് നമ്പറുകൾ (1024 മുതൽ 49151 വരെ)
      • ഡൈനാമിക് അല്ലെങ്കിൽ സ്വകാര്യ പോർട്ട് നമ്പറുകൾ (49152 മുതൽ 65535 വരെ)

  • 3.2 ടൈം സോൺ ഡാറ്റാബേസ്
    • tz അല്ലെങ്കിൽ zoneinfo എന്നും അറിയപ്പെടുന്ന ടൈം സോൺ ഡാറ്റാബേസിൽ ലോകമെമ്പാടുമുള്ള പ്രതിനിധി പ്രദേശങ്ങളിലെ പ്രാദേശിക സമയ ചരിത്രം വിവരിക്കുന്ന കോഡും ഡാറ്റയും അടങ്ങിയിരിക്കുന്നു.
    • രാഷ്ട്രീയ അധികാരികൾ വരുത്തുന്ന ടൈം സോൺ അതിർത്തി, UTC ഓഫ്സെറ്റ്, ഡേലൈറ്റ് സേവിംഗ് ടൈം നിയമങ്ങളിലെ മാറ്റങ്ങൾ പ്രതിഫലിപ്പിക്കുന്നതിനായി ഇത് ഇടയ്ക്കിടെ പുതുക്കുന്നു.
    • ടൈം സോണുകളുടെ ഔദ്യോഗിക പട്ടിക https://www.iana.org/time-zones എന്ന വിലാസത്തിൽ പ്രസിദ്ധീകരിച്ചിരിക്കുന്നു.
