ഐഡന്റിറ്റി മാപ്പിംഗും ഓർഫൻ അക്കൗണ്ടുകളും

  • വിവിധ രൂപത്തിലുള്ള ആപ്ലിക്കേഷൻ അക്കൗണ്ടുകളെ ഹ്യൂമൻ റിസോഴ്‌സ് അല്ലെങ്കിൽ ഓപ്പറേഷണൽ ഡയറക്ടറിയിലെ അധികാരമുള്ള ഐഡന്റിറ്റിയുമായി ബന്ധിപ്പിക്കുന്ന പ്രക്രിയയാണ് ഐഡന്റിറ്റി മാപ്പിംഗ്.
  • അധികാരമുള്ള ഐഡന്റിറ്റിയുമായി ബന്ധിപ്പിക്കാത്ത ആപ്ലിക്കേഷൻ അക്കൗണ്ടുകളോ ഐഡന്റിറ്റികളോ ആണ് ഓർഫൻ അക്കൗണ്ടുകൾ.
  • ഓർഫൻ അക്കൗണ്ടുകൾ രണ്ട് തരത്തിലുള്ള സുരക്ഷാ അപകടങ്ങൾ സൃഷ്ടിക്കാം:
    • അക്കൗണ്ട് ഉടമ സ്ഥാപനം വിട്ടുപോയാൽ അക്കൗണ്ട് ദുരുപയോഗം ചെയ്യപ്പെടാം. സജീവ ഉടമ ഇല്ലാത്തതിനാൽ അസാധാരണ പ്രവർത്തനം കണ്ടെത്താൻ കഴിയില്ല.
    • ഉടമ സ്ഥാപനം വിട്ടുപോകുമ്പോൾ ഓർഫൻ അക്കൗണ്ടുകൾ വിശ്വസനീയമായി പ്രവർത്തനരഹിതമാക്കാൻ കഴിയില്ല.
Note

സാങ്കേതികവിദ്യ. നിങ്ങളുടെ ഭാഷയിൽ.
