സൈറ്റിൽ തിരയുക

നിലവിലെ ഭാഷയിൽ തിരയാൻ ടൈപ്പ് ചെയ്യുക.

← സീറോ ട്രസ്റ്റ് ലൈബ്രറി സീറോ ട്രസ്റ്റ് ഫ്രെയിംവർക്കും രൂപകൽപ്പനാ തത്വങ്ങളും →

സീറോ ട്രസ്റ്റിന്റെ അവലോകനവും അടിസ്ഥാന തത്വങ്ങളും

പരമ്പരാഗത നെറ്റ്‌വർക്ക് സുരക്ഷ കോർപ്പറേറ്റ് നെറ്റ്‌വർക്കിനുള്ളിലെ ഉപയോക്താക്കളും ഉപകരണങ്ങളും വിശ്വസനീയമാണെന്ന് പലപ്പോഴും കരുതുന്നു. സീറോ ട്രസ്റ്റ് ഈ ധാരണ മാറ്റുന്നു.

സീറോ ട്രസ്റ്റിൽ ഉപയോക്താക്കളെയും ഉപകരണങ്ങളെയും തിരിച്ചറിയൽ, സന്ദർഭം, നയം എന്നിവയുടെ അടിസ്ഥാനത്തിൽ തുടർച്ചയായി വിലയിരുത്തുന്നു. നെറ്റ്‌വർക്ക് തന്നെ വിശ്വസനീയമായ അതിർത്തിയായി കണക്കാക്കുന്നില്ല.

അടിസ്ഥാന ആശയം

  • ആന്തരിക നെറ്റ്‌വർക്ക് സ്വമേധയാ വിശ്വസനീയമല്ല
  • ബാഹ്യ നെറ്റ്‌വർക്ക് സ്വമേധയാ അവിശ്വസനീയമല്ല
  • ഓരോ ആക്സസ് അഭ്യർത്ഥനയ്ക്കും വിശ്വാസം വ്യക്തമായി പരിശോധിക്കണം
  • കുറഞ്ഞ പ്രത്യേകാവകാശവും സന്ദർഭ സൂചനകളും അടിസ്ഥാനമാക്കിയാണ് ആക്സസ് അനുവദിക്കുന്നത്

താരതമ്യം

മാതൃകവിശ്വാസ ധാരണ
പരമ്പരാഗത നെറ്റ്‌വർക്ക് സുരക്ഷകോർപ്പറേറ്റ് നെറ്റ്‌വർക്ക് = വിശ്വസനീയം
സീറോ ട്രസ്റ്റ്കോർപ്പറേറ്റ് നെറ്റ്‌വർക്ക് = അവിശ്വസനീയം

പ്രധാന ഫലം

സീറോ ട്രസ്റ്റ് സുരക്ഷയെ നെറ്റ്‌വർക്ക് കേന്ദ്രീകൃത മാതൃകയിൽ നിന്ന് തിരിച്ചറിയൽ കേന്ദ്രീകൃതവും നയാധിഷ്ഠിതവുമായ മാതൃകയിലേക്ക് മാറ്റുന്നു.
