IPv6 വിലാസ ഘടന

IPv6 വിലാസങ്ങൾ കോലനുകൾ ഉപയോഗിച്ച് വേർതിരിച്ച എട്ട് ഹെക്സാഡെസിമൽ ഗ്രൂപ്പുകളായി ക്രമീകരിച്ചിരിക്കുന്നു.

ഉദാഹരണം:

2001:0db8:0000:0000:0000:8a2e:0370:7334

വിലാസ ചുരുക്ക നിയമങ്ങൾ

  • ഓരോ ഹെക്സറ്റിലെയും തുടക്കത്തിലെ പൂജ്യങ്ങൾ നീക്കം ചെയ്യുക
  • തുടർച്ചയായ ഒന്നോ അതിലധികമോ പൂജ്യ ഗ്രൂപ്പുകളെ ഇരട്ട കോലൻ (::) ഉപയോഗിച്ച് മാറ്റിസ്ഥാപിക്കുക

Example:

2001:0000:3238:DFE1:0063:0000:0000:FEFB

ഇങ്ങനെ മാറുന്നു:

2001:0:3238:DFE1:63::FEFB

പ്രധാന കുറിപ്പുകൾ

  • IPv6 വിലാസങ്ങൾ IPv4 വിലാസങ്ങളേക്കാൾ വളരെ വലുതാണ്.
  • ഫോർമാറ്റ് ശ്രേണീബദ്ധമാണ്, കാര്യക്ഷമമായ റൂട്ടിംഗിനായി രൂപകൽപ്പന ചെയ്തതാണ്.
  • വിലാസ മൂല്യം മാറ്റാതെ ചുരുക്കം വായനാക്ഷമത മെച്ചപ്പെടുത്തുന്നു.
Note

സാങ്കേതികവിദ്യ. നിങ്ങളുടെ ഭാഷയിൽ.
