Oblivious DNS (ODoH)

IETF വികസിപ്പിച്ചുകൊണ്ടിരിക്കുന്ന ഒരു ഉയർന്നുവരുന്ന പ്രോട്ടോക്കോളാണ് Oblivious DNS. ഇത് പൊതു കീ ക്രിപ്റ്റോഗ്രഫി, ഒരു പ്രോക്സി, ടാർഗറ്റ് റിസോൾവർ എന്നിവ DNS അന്വേഷണ പരിഹാര പ്രക്രിയയിൽ സംയോജിപ്പിക്കുന്നു.

ഇത് ഉപയോക്താവിനും റിക്കർസീവ് റിസോൾവറിനും ഇടയിൽ സ്വകാര്യത സംരക്ഷിക്കുന്ന ഒരു പാളി സൃഷ്ടിക്കുന്നു. ഉപയോക്താവിന് ഒരു പ്രോക്സിയും ടാർഗറ്റ് റിസോൾവറും തിരഞ്ഞെടുക്കാം. ഈ രണ്ട് ഘടകങ്ങളുടെ സംയോജനം DNS അന്വേഷണവും ലക്ഷ്യമിടുന്ന IP വിലാസവും ഒരേസമയം കാണാൻ കഴിയുന്നത് ഉപയോക്താവിന് മാത്രമാണെന്ന് ഉറപ്പാക്കുന്നു.

ഉപയോക്തൃ സ്വകാര്യത സംരക്ഷിക്കുകയും ഉപയോക്താവ് ആവശ്യപ്പെടുന്ന വെബ്‌സൈറ്റുകൾ ഏതെന്ന് ഇന്റർനെറ്റ് സേവനദാതാക്കൾക്കും DNS റിസോൾവർമാർക്കും മനസ്സിലാക്കാൻ കഴിയാതിരിക്കുകയും ചെയ്യുന്നതാണ് ഈ പ്രോട്ടോക്കോളിന്റെ ലക്ഷ്യം.
