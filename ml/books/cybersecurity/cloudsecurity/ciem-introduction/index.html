ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ എന്റൈറ്റിൽമെന്റ് മാനേജ്മെന്റ് (CIEM)

CIEM ലൈഫ്‌സൈക്കിൾ

ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ എന്റൈറ്റിൽമെന്റ് മാനേജ്മെന്റ് (CIEM)

കുറഞ്ഞ അവകാശ തത്വമനുസരിച്ച് (POLP) തിരിച്ചറിയലുകളും ക്ലൗഡ് അനുമതികളും കൈകാര്യം ചെയ്യാൻ ഉപയോഗിക്കുന്ന ക്ലൗഡ് സുരക്ഷാ പരിഹാരമാണ് ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ എന്റൈറ്റിൽമെന്റ് മാനേജ്മെന്റ് (CIEM).

മൾട്ടി-ക്ലൗഡ് പരിസ്ഥിതികളിലെ അക്കൗണ്ട് അനുമതികളിലെ അസാധാരണതകൾ കണ്ടെത്താൻ CIEM മെഷീൻ ലേണിംഗും അനലിറ്റിക്സും ഉപയോഗിക്കുന്നു. ഈ ദൃശ്യപരത ക്ലൗഡ് സേവനങ്ങളിലുടനീളം സ്ഥിരതയുള്ള തിരിച്ചറിയൽ, ആക്‌സസ് മാനേജ്മെന്റ് പ്രയോഗിക്കാനും ഡാറ്റാ ലംഘനത്തിന്റെയും എക്സ്ഫിൽട്രേഷന്റെയും അപകടസാധ്യത കുറയ്ക്കാനും സ്ഥാപനങ്ങളെ സഹായിക്കുന്നു.

സാധാരണ CIEM ആർക്കിടെക്ചർ

  • കൺട്രോൾ പ്ലെയിൻ
  • ഡാറ്റാ പ്ലെയിൻ
  • API ഇന്റഗ്രേഷൻ
  • കണക്ടറുകൾ
  • ഡിസ്കവറി, കോറലേഷൻ, ഓപ്റ്റിമൈസേഷൻ എഞ്ചിൻ
  • സുരക്ഷാ എന്റൈറ്റിൽമെന്റ് ഡാറ്റാബേസ്
  • മാനേജ്മെന്റ് പോർട്ടൽ
  • സ്ഥാപന നയങ്ങൾ
  • ഡാഷ്ബോർഡും ദൃശ്യവൽക്കരണവും

ലക്ഷ്യം

അമിതമായ അനുമതികൾ നീക്കം ചെയ്യുകയും തിരിച്ചറിയലുകൾക്ക് ജോലി നിർവഹിക്കാൻ ആവശ്യമായ ആക്‌സസ് മാത്രം ഉണ്ടെന്ന് ഉറപ്പാക്കുകയും ചെയ്ത് അറ്റാക്ക് സർഫേസ് കുറയ്ക്കാൻ CIEM സ്ഥാപനങ്ങളെ സഹായിക്കുന്നു.
