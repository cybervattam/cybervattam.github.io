നേറ്റീവ് ക്ലൗഡ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ

പബ്ലിക് ക്ലൗഡ് സേവന ദാതാക്കൾ വർക്ക്‌ലോഡുകൾ, തിരിച്ചറിയലുകൾ, നെറ്റ്‌വർക്കുകൾ, ആപ്ലിക്കേഷനുകൾ എന്നിവ സുരക്ഷിതമാക്കാൻ സഹായിക്കുന്ന വിവിധ നേറ്റീവ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ നൽകുന്നു.
