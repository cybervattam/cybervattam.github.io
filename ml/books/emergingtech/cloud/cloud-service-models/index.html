ക്ലൗഡ് സേവന മാതൃകകൾ




1. ഇൻഫ്രാസ്ട്രക്ചർ ആസ് എ സർവീസ് (IaaS)

ക്ലൗഡ് സേവനദാതാക്കൾ വിർച്ച്വലൈസ്ഡ് കമ്പ്യൂട്ടിംഗ്, നെറ്റ്‌വർക്കിംഗ്, സ്റ്റോറേജ് തുടങ്ങിയ അടിസ്ഥാന കമ്പ്യൂട്ടിംഗ് ഇൻഫ്രാസ്ട്രക്ചർ നിയന്ത്രിക്കുകയും വിഭവ ശേഖരത്തിലേക്ക് പ്രവേശനം നൽകുകയും ചെയ്യുന്നു. ക്ലൗഡ് ഉപഭോക്താക്കൾക്ക് ആവശ്യാനുസരണം അതിന് മുകളിൽ വിവിധ ഓപ്പറേറ്റിംഗ് സിസ്റ്റങ്ങളും ആപ്ലിക്കേഷനുകളും ഇൻസ്റ്റാൾ ചെയ്യാം.

2. പ്ലാറ്റ്ഫോം ആസ് എ സർവീസ് (PaaS)

ക്ലൗഡ് സേവനദാതാക്കൾ ഡാറ്റാബേസുകൾ, ആപ്ലിക്കേഷൻ പ്ലാറ്റ്ഫോമുകൾ, പ്രോഗ്രാമിംഗ് പ്ലാറ്റ്ഫോമുകൾ, റൺടൈം പരിസ്ഥിതികൾ തുടങ്ങിയ പ്ലാറ്റ്ഫോമുകൾ അമൂർത്ത രൂപത്തിൽ നൽകുന്നു.

ഉദാഹരണങ്ങൾ:

  • Python, PHP, അല്ലെങ്കിൽ മറ്റ് സോഴ്സ് കോഡ് പ്രവർത്തിപ്പിക്കാനുള്ള പരിസ്ഥിതി
  • Database as a Service
  • Data Warehouse as a Service
  • Data Storage as a Service
  • Machine Learning as a Service

അടിസ്ഥാനത്തിലുള്ള സെർവറുകൾ, നെറ്റ്‌വർക്കുകൾ, അല്ലെങ്കിൽ മറ്റ് ഇൻഫ്രാസ്ട്രക്ചർ നിങ്ങൾ നിയന്ത്രിക്കേണ്ടതില്ല എന്നതാണ് പ്രധാന വ്യത്യാസം.

3. സോഫ്റ്റ്‌വെയർ ആസ് എ സർവീസ് (SaaS)

ക്ലൗഡ് സേവനദാതാവ് നിയന്ത്രിച്ച് നൽകുന്ന പൂർണ്ണമായ ആപ്ലിക്കേഷനാണിത്. വെബ് ബ്രൗസർ, മൊബൈൽ ആപ്ലിക്കേഷൻ, അല്ലെങ്കിൽ ലളിതമായ ക്ലയന്റ് ആപ്ലിക്കേഷൻ വഴി ഉപഭോക്താക്കൾക്ക് ഇത് ലഭ്യമാക്കാം.

കസ്റ്റമൈസേഷനോ കോൺഫിഗറേഷനോ ലഭ്യമായേക്കാം; എന്നാൽ സവിശേഷതകളും കഴിവുകളും മാറ്റാൻ കഴിയില്ല.

ഉദാഹരണങ്ങൾ:

  • Netflix
  • Prime Video
  • Gmail
  • YouTube
  • Zoom
  • Microsoft 365
