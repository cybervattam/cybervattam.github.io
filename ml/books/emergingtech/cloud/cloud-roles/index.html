ക്ലൗഡ് കമ്പ്യൂട്ടിംഗ് റോളുകൾ

  • ക്ലൗഡ് സേവനദാതാവ്
    • താൽപ്പര്യമുള്ള കക്ഷികൾക്ക് ക്ലൗഡ് കമ്പ്യൂട്ടിംഗ് സേവനങ്ങൾ ലഭ്യമാക്കുന്നതിനുള്ള ഉത്തരവാദിത്തമുള്ള വ്യക്തി, സ്ഥാപനം, അല്ലെങ്കിൽ കമ്പനി.
  • ക്ലൗഡ് ഉപഭോക്താവ് / ഉപയോക്താവ്
    • ക്ലൗഡ് സേവനദാതാവുമായി ബിസിനസ് ബന്ധം നിലനിർത്തുകയും അതിന്റെ സേവനങ്ങൾ ഉപയോഗിക്കുകയും ചെയ്യുന്ന വ്യക്തി അല്ലെങ്കിൽ സ്ഥാപനം.
  • ക്ലൗഡ് കാരിയർ
    • സേവനദാതാവിൽ നിന്ന് ഉപഭോക്താവിലേക്ക് ക്ലൗഡ് സേവനങ്ങൾക്ക് കണക്റ്റിവിറ്റിയും ഗതാഗതവും നൽകുന്ന ഇടനിലക്കാരൻ.
  • ക്ലൗഡ് ബ്രോക്കർ
    • ക്ലൗഡ് സേവനങ്ങളുടെ ഉപയോഗം, പ്രകടനം, വിതരണം എന്നിവ നിയന്ത്രിക്കുകയും സേവനദാതാക്കളും ഉപഭോക്താക്കളും തമ്മിലുള്ള ബന്ധം സംബന്ധിച്ച് ചർച്ച നടത്തുകയും ചെയ്യുന്ന സ്ഥാപനം.
  • ക്ലൗഡ് ആക്സസ് സെക്യൂരിറ്റി ബ്രോക്കർ (CASB)
    • ക്ലൗഡിലേക്ക് അയയ്ക്കുന്ന ആശയവിനിമയങ്ങൾ തടസ്സപ്പെടുത്താനും പ്രവർത്തനം നിരീക്ഷിക്കാനും നയങ്ങൾ നടപ്പാക്കാനും സുരക്ഷാ പ്രശ്നങ്ങൾ കണ്ടെത്തി തടയാനും API വഴിയോ Software as a Service-ലേക്ക് നേരിട്ടോ ബന്ധിപ്പിക്കുന്ന സോഫ്റ്റ്‌വെയർ. ഒരു സ്ഥാപനത്തിന്റെ അംഗീകൃതവും അംഗീകാരമില്ലാത്തതുമായ സേവനങ്ങൾ കൈകാര്യം ചെയ്യാൻ ഇവ സാധാരണയായി ഉപയോഗിക്കുന്നു.
