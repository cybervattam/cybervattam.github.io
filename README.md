# Cybervattam Website
The purpose of this website is to create the information and data needed to learn information technology in one's own mother tongue. Currently, information and data are available in Tamil. We are very interested in making this available in other languages as well. You can help make it available in your language.

## Setup Guide
Download the source code:

```bash
git clone https://github.com/cybervattam/cybervattam.github.io.git
```

Install the dependencies:

```bash
cd cybervattam.github.io
npm install
```

Start the service:

```bash
npm start
```

To view the local version of this website, open the following address in your browser:

```text
http://localhost:3000
```

# ಸೈಬರ್ವಟ್ಟಂ ವೆಬ್‌ಸೈಟ್

# సైబర్వట్టం వెబ్‌సైట్
