Secure Access Service Edge (SASE)

Secure Access Service Edge (SASE)

Secure Access Service Edge (SASE) combines two main capabilities:

  • Security Service Edge, which provides network security as a service
  • WAN Edge, which provides network connectivity as a service

Core Elements

  • Secure Web Gateway (SWG)
  • Cloud Access Security Broker (CASB)
  • Zero Trust Network Access (ZTNA)
  • Firewall as a Service (FWaaS)
  • Data loss prevention and TLS inspection
  • SD-WAN and WAN optimization
  • CDN and multi-cloud connectivity
  • Quality-of-service controls and SaaS acceleration

Design Goal

SASE modernizes network access by bringing networking and security together into a cloud-delivered architecture.
