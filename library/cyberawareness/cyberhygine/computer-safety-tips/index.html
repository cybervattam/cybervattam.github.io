Computer Safety Tips

Computer security protects computer systems and information from theft and unauthorized access. Use the following practices to reduce common risks.

Do

  • Download applications and software only from trusted sources.
  • Keep the operating system, applications, and antivirus software updated.
  • Back up important data, files, and documents at regular intervals.
  • Lock the computer screen whenever it is not in use.
  • Keep the computer firewall enabled.
  • Use an account with limited privileges where possible.
  • Use genuine and licensed software.
  • Scan files downloaded from websites, email, or USB devices.
  • Uninstall programs that are no longer needed.
  • Use Task Manager to identify unwanted programs running on the system.
  • Allow server access through multi-factor authentication.
  • Disable Remote Desktop and network file sharing when they are not needed.
  • Enable automatic operating system updates.

Do not

  • Install or use pirated software, which may contain malware.
  • Use weak or easily guessed passwords.
  • Click untrusted or unexpected pop-up advertisements and programs.
  • Dispose of a computer or hard drive without securely deleting and wiping its data.
