மேகக் கணிமைப் பணிச்சுமைப் பாதுகாப்புத் தளம் (CWPP)

மேகக் கணிமைப் பணிச்சுமைப் பாதுகாப்புத் தளம் (CWPP)

பொதுமேகம், தனியார் மேகம், தரவு மையம் என எங்கு இயங்கினாலும்—இயற்பியல் சேவையகங்கள், மெய்நிகர் இயந்திரங்கள், கன்டெய்னர்கள், சர்வரற்ற செயல்பாடுகள் உட்பட—பணிச்சுமைகளை மேகப் பணிச்சுமைப் பாதுகாப்புத் தளம் பாதுகாக்கிறது.

பணிச்சுமைகளின் பரிணாமம்

பணிச்சுமைகள் அளவில் சிறியதாகவும், குறுகிய காலம் மட்டுமே இயங்குபவையாகவும் மாறியுள்ளன; இதனால் அவற்றைப் பாதுகாக்கும் முறையும் மாறுகிறது.

வாழ்க்கைச் சுழற்சி முழுவதுமான பாதுகாப்பு

CWPP, பணிச்சுமை வாழ்க்கைச் சுழற்சியின் உருவாக்கம் மற்றும் இயக்க நேரம் ஆகிய இரு கட்டங்களையும் உள்ளடக்குகிறது.

பாதுகாப்பான உருவாக்கம்

  • பாதிப்புள்ள கூறுகள்
  • மேக உள்ளமைவு
  • இரகசியத் தகவல்கள்
  • தீநிரல்
  • API கண்டறிதல்

இயக்க நேரப் பாதுகாப்பு

  • பணிச்சுமைப் பாதிப்புகளும் உள்ளமைவும்
  • பணிச்சுமைப் பிரிப்பாக்கம்
  • ஒருமைப்பாட்டுக் கண்காணிப்பு
  • பயன்பாட்டுக் கட்டுப்பாடு
  • நடத்தை கண்காணிப்பு
  • ஹோஸ்ட் ஊடுருவல் தடுப்பு (HIPS)
  • தீநிரல் எதிர்ப்பு

அபாய அடிப்படையிலான கட்டுப்பாட்டு வரிசை

அடிப்படை நிலையிலிருந்து குறைந்த முன்னுரிமை வரை கட்டுப்பாடுகளுக்கு முன்னுரிமை வழங்கலாம்; கடினப்படுத்தல், உள்ளமைவு, பாதிப்பு மேலாண்மை, பிணையப் பிரிப்பாக்கம் ஆகியவற்றிலிருந்து தொடங்க வேண்டும்.

பாதுகாப்பு நோக்கம்

மேகம் வழங்கும் சுறுசுறுப்பைக் குறைக்காமல், பணிச்சுமைகளைச் சீராகப் பாதுகாத்தல்.
