மேகக் கணிமை உள்கட்டமைப்பு உரிமை மேலாண்மை (CIEM)

மேகக் கணிமை உள்கட்டமைப்பு உரிமை மேலாண்மை (CIEM)

குறைந்தபட்சச் சலுகைக் கொள்கையின்படி (POLP) அடையாளங்களையும் மேக அனுமதிகளையும் நிர்வகிக்கும் மேகப் பாதுகாப்புத் தீர்வே மேக உள்கட்டமைப்பு உரிமை மேலாண்மை (CIEM) ஆகும்.

பல மேகச் சூழல்களில் கணக்கு அனுமதிகளிலுள்ள முரண்பாடுகளைக் கண்டறிய CIEM இயந்திரக் கற்றலையும் பகுப்பாய்வையும் பயன்படுத்துகிறது. இந்தத் தெரிவுநிலை, மேகச் சேவைகள் முழுவதும் ஒரே மாதிரியான அடையாளம் மற்றும் அணுகல் மேலாண்மையைப் பின்பற்றவும், தரவு மீறல் மற்றும் வெளியேற்ற அபாயத்தைக் குறைக்கவும் நிறுவனங்களுக்கு உதவுகிறது.

வழக்கமான CIEM கட்டமைப்பு

  • கட்டுப்பாட்டுத் தளம்
  • தரவுத் தளம்
  • API ஒருங்கிணைப்பு
  • இணைப்பிகள்
  • கண்டறிதல், தொடர்புபடுத்தல், மேம்படுத்தல் இயந்திரம்
  • பாதுகாப்பு உரிமைத் தரவுத்தளம்
  • மேலாண்மை வலைவாசல் (Management portal)
  • நிறுவனக் கொள்கைகள்
  • பலகமும் காட்சிப்படுத்தலும்

இலக்கு

அளவுக்கு மீறிய அனுமதிகளை நீக்கி, அடையாளங்களுக்கு வேலையைச் செய்யத் தேவையான அணுகல் மட்டுமே இருப்பதை உறுதி செய்வதன் மூலம் தாக்குதல் மேற்பரப்பைக் குறைக்க CIEM உதவுகிறது.
