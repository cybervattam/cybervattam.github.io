மேகக் கணிமை உள்கட்டமைப்பு உரிமை மேலாண்மை (CIEM)

மேகக் கணிமை உள்கட்டமைப்பு உரிமை மேலாண்மை (CIEM) என்பது குறைந்தபட்சச் சலுகைக் கொள்கையின் (POLP) அடிப்படையில் அடையாளங்கள் மற்றும் மேகக் கணிமை அனுமதிகளை நிர்வகிக்கப் பயன்படுத்தப்படும் மேகக் கணிமை பாதுகாப்புத் தீர்வாகும்.

மல்டி-மேகக் கணிமை சூழல்களில் கணக்கு அனுமதிகளில் உள்ள முரண்பாடுகளைக் கண்டறிய CIEM இயந்திரக் கற்றல் மற்றும் பகுப்பாய்வைப் பயன்படுத்துகிறது. இந்தத் தெரிவுநிலை, நிறுவனங்கள் தங்கள் மேகக் கணிமை சேவைகள் முழுவதும் சீரான அடையாளம் மற்றும் அணுகல் மேலாண்மையைப் பயன்படுத்தவும், தரவு மீறல் மற்றும் வெளியேற்றத்தின் அபாயத்தைக் குறைக்கவும் உதவுகிறது.

வழக்கமான CIEM கட்டமைப்பு

  • கட்டுப்பாட்டு தளம்
  • தரவுத் தளம்
  • API ஒருங்கிணைப்பு
  • இணைப்பிகள்
  • கண்டறிதல், தொடர்புபடுத்தல் மற்றும் மேம்படுத்தல் இயந்திரம்
  • பாதுகாப்பு உரிமை தரவுத்தளம்
  • மேலாண்மை போர்டல்
  • நிறுவனக் கொள்கைகள்
  • டாஷ்போர்டு மற்றும் காட்சிப்படுத்தல்

இலக்கு

அதிகப்படியான அனுமதிகளை அகற்றி, அடையாளங்களுக்கு தங்கள் பணியைச் செய்யத் தேவையான அணுகல் மட்டுமே இருப்பதை உறுதி செய்வதன் மூலம் தாக்குதல் பரப்பைக் குறைக்க CIEM நிறுவனங்களுக்கு உதவுகிறது.
