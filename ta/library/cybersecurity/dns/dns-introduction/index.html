களப்பெயர் முறைமை அறிமுகம் / DNS Introduction

களப்பெயர் முறைமை என்பது ஒரு கணினிச் சேவையகத்தில் இயங்கும் ஒரு சிறப்பு மென்பொருள் ஆகும். இது சேவையகப் பெயர்கள் மற்றும் அதனுடன் தொடர்புடைய இ.நெறி முகவரி ஆகியவற்றின் விவரங்களை இணைத்துக் கொண்டுள்ளது. இது நமது கைப்பேசியில் உள்ள தொடர்புகள் செயலி அல்லது தொலைபேசி எண் விவரப் புத்தகத்திற்கு மிகவும் ஒத்திருக்கிறது. இணையம் / அக வளங்களை அணுக உலாவிகள் / பயன்பாடுகளுக்கான களப்பெயர்களை இ.நெறி முகவரிகளுக்கு களப்பெயர் முறைமை மொழிபெயர்க்கிறது. களப்பெயர் முறைமைச் சேவையகங்கள் சிறப்பு மென்பொருளை இயக்குகின்றன மற்றும் பெயரைத் தீர்க்க சிறப்பு நெறிமுறைகளைப் பயன்படுத்தித் தங்களுக்குள்ளே தொடர்பு கொள்கின்றன. தொடக்கத்திலிருந்தே பயனர் தரவுச்செய்தி நெறிமுறை (UDP) மற்றும் பரப்புகைக் கட்டுப்பாடு நெறிமுறை (TCP) துறை (Port) எண் 53-ஐப் பயன்படுத்த களப்பெயர் முறைமை வடிவமைக்கப்பட்டுள்ளது, இயல்புநிலையில் UDP-யிலும் வழிமாற்றாக TCP-யிலும் செயல்படும்.
