களப்பெயர் முறைமை வகைகள் / DNS Types

அக களப்பெயர் முறைமை / Internal DNS

ஒரு நிறுவன தனியார் பிணையத்திற்குள் உள்ள சேவையகங்கள் மற்றும் அதன் இணைய நெறிமுறை முகவரியின் தொடர்பைக் கொண்டுள்ள உள்நோக்குக் களப்பெயர் முறைமை.

புற களப்பெயர் முறைமை / External DNS

இணையம் / பொதுப் பிணையத்தில் தொடர்புகொள்ள கூடிய நிலையில் உள்ள சேவையகங்கள் மற்றும் அதன் இணைய நெறிமுறை முகவரியின் தொடர்பைக் கொண்டுள்ள வெளிநோக்குக் களப்பெயர் முறைமை.

எதிர் களப்பெயர் முறைமை / Reverse DNS

இது ஒரு எதிர் திசை வினவல். ஒரு குறிப்பிட்ட இணைய நெறிமுறை முகவரியைக் கொண்ட சேவையகத்தின் பெயரைப் பதிலாகக் கொடுக்கும். களப்பெயர் முறைமையில், ஒரு களத்தின் PTR ஏடு அந்தக் களத்தின் சேவையக இ.நெறி முகவரியைத் தலைகீழாக மாற்றி arpa வடிவில் சேமித்து வைத்திருக்கும். எதிர்த்திசை வினவலின் போது இந்த மதிப்பு பதிலாக வழங்கப்படும். பாதுகாப்பு நிகழ்வுகளைப் பதிவு செய்யும் மென்பொருள் மற்றும் மின்னஞ்சல் நுழைவாயில்கள் இந்த முறையைப் பயன்படுத்துகின்றன.

மாறு களப்பெயர் முறைமை / Dynamic DNS

ஒரு களத்தின் இ.நெறி முகவரி நிலையாக இல்லாமல் அடிக்கடி மாறிக்கொண்டே இருக்கும் சூழலில், அந்த களத்தின் இ.நெறி முகவரியை தானியக்கமாக புதுப்பிக்க, இம்முறை பயன்படுகிறது. மைக்ரோசாப்ட் செயற்படு கோப்பகத்தில் (Microsoft Active Directory) இது ஒரு முக்கிய அங்கம். கள கட்டுப்பாட்டாளர் அந்த களத்தில் கிடைக்கப் பெறும் சேவைகளை களப்பெயர் முறைமையில் பதிந்து வைக்கும். இதனை மற்ற கணினிகள் பயன்படுத்துகின்றன.
