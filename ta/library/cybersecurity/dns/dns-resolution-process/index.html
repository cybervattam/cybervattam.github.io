களப்பெயர் முறைமை வினவல் தீர்வு முறை

களப்பெயர் முறைமை வினவல் தீர்வு முறை / DNS Query Resolution Process

ஒரு கிளையன் (Client) ஒரு களப்பெயரைக் கோரும்போது, களப்பெயர் முறைமை வினவல் பொதுவாகப் பின்வரும் செயல்முறையைப் பின்பற்றுகிறது:

  1. கிளையன் தனக்குக் கட்டமைக்கப்பட்ட தீர்விக்கு (Resolver) ஒரு சுழல்நிலைக் களப்பெயர் முறைமை வினவலை (Recursive DNS query) அனுப்புகிறது.
  2. வினவலுக்கான பதில் ஏற்கனவே உள்ளதா என்பதை அறிய, தீர்வி தனது விரைவகத்தைச் (Cache) சரிபார்க்கிறது.
  3. விரைவகத்தில் பதில் இல்லையெனில், பொருத்தமான மேல் நிலைக் களப்பெயர் (TLD) சேவையகத்தைக் கண்டறியத் தீர்வி வேர் சேவையகத்திடம் (Root server) வினவுகிறது.
  4. பின்னர் அந்தக் குறிப்பிட்ட களத்திற்கான அதிகாரப்பூர்வக் களப்பெயர் சேவையகத்திடம் (Authoritative name server) தீர்வி வினவுகிறது.
  5. அதிகாரப்பூர்வச் சேவையகம் தொடர்புடைய களப்பெயர் முறைமை ஏடுகளைப் (DNS records) பதிலாக வழங்குகிறது.
  6. தீர்வி அந்தப் பதிலைக் கிளையனுக்குத் திருப்பி அனுப்புகிறது; மேலும் எதிர்காலக் கோரிக்கைகளுக்காக அந்த முடிவைத் தனது விரைவகத்தில் சேமித்து வைத்துக்கொள்ளும்.

இந்தச் செயல்முறை, மனிதர்கள் படிக்கக்கூடிய ஒரு களப்பெயரைச் சரியான இணைய நெறிமுறை (IP) முகவரியாக மாற்ற கிளையனுக்கு உதவுகிறது.
