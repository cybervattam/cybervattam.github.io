மேகக் கணிமை

மேகக் கணிமை / அயல்கணிச் சேவை / Cloud Computing

2011-ஆம் ஆண்டு, அமெரிக்காவின் தேசிய தரநிலைகள் மற்றும் தொழில்நுட்ப நிறுவனம் (NIST) இவ்வாறு மேகக் கணிமைக்கு விளக்கம் கொடுத்தது.

“எங்கும் நிறைந்துள்ள, வசதியான, உள்ளமைக்கக்கூடிய கணினி வளங்களின் (எ.கா., பிணையங்கள், சேவையகங்கள், சேமிப்பகங்கள், பயன்பாடுகள் மற்றும் சேவைகள்) பகிரப்பட்ட வளத் திரள்விற்கு தேவைக்கேற்ப பிணைய அணுகலை வழங்கக்கூடிய ஒரு தொழில்நுட்ப முறை. இது குறைந்தபட்ச மேலாண்மையுடன், சேவையாளரிடம் நேரடித் தொடர்பு இன்றி விரைவாக வழங்கப்பட்டு விடுவிக்கப்படக்கூடியது.”

மேகக் கணிமை 5 அத்தியாவசிய பண்புகள், 3 சேவை முறைகள் மற்றும் 4 பணியமர்த்தல் முறைகளை கொண்டுள்ளது.
