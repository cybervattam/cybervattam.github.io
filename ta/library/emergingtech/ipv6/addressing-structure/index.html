IPv6 முகவரியிடல் அமைப்பு

IPv6 முகவரிகள் கோலன்களால் பிரிக்கப்பட்ட எட்டு ஹெக்சாடெசிமல் குழுக்களாக அமைக்கப்பட்டுள்ளன.

உதாரணம்:

2001:0db8:0000:0000:0000:8a2e:0370:7334

முகவரி சுருக்க விதிகள்

  • ஒவ்வொரு ஹெக்ஸெட்டிலும் உள்ள தொடக்க பூஜ்ஜியங்களை நீக்கவும்
  • தொடர்ச்சியாக வரும் ஒன்று அல்லது அதற்கு மேற்பட்ட பூஜ்ஜியக் குழுக்களை இரட்டை கோலன் (::) கொண்டு மாற்றவும்

Example:

2001:0000:3238:DFE1:0063:0000:0000:FEFB

இவ்வாறு மாறும்:

2001:0:3238:DFE1:63::FEFB

முக்கியக் குறிப்புகள்

  • IPv6 முகவரிகள் IPv4 முகவரிகளைவிட மிகவும் பெரியவை.
  • வடிவம் படிநிலையானது மற்றும் திறமையான ரூட்டிங்கிற்காக வடிவமைக்கப்பட்டது.
  • முகவரி மதிப்பை மாற்றாமல் சுருக்கம் வாசிப்புத் தன்மையை மேம்படுத்துகிறது.
Note

தொழில்நுட்பம். உங்கள் மொழியில்.
