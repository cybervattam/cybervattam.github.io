தளத்தில் தேடுங்கள்

தற்போதைய மொழியில் தேட தட்டச்சு செய்யவும்.

சொத்து வில்லையாக்கம் செயல்முறை

ஒரு டோக்கனின் வாழ்க்கைச் சுழற்சி பொதுவாக மின்டிங்கிலிருந்து பரிமாற்றம் மற்றும் இறுதி ஓய்வு வரை ஒரு கட்டமைக்கப்பட்ட செயல்முறையைப் பின்பற்றுகிறது.

வில்லை வாழ்க்கைச் சுழற்சி

  1. தனித்துவமான பண்புகளைக் கொண்ட இயற்பியல் அல்லது டிஜிட்டல் சொத்து அடையாளம் காணப்படுகிறது.
  2. சொத்து வில்லையாக்கம் செய்யப்பட்டு கட்டச்சங்கிலியில் பதிவு செய்யப்படுகிறது.
  3. மீத்தரவு அல்லது தனித்துவமான பண்புகள் டோக்கனில் உட்பொதிக்கப்படுகின்றன.
  4. வில்லை மின்ட் செய்யப்பட்டு விற்பனை அல்லது ஏலத்திற்குப் பட்டியலிடப்படுகிறது.
  5. வில்லையை வாங்க மறை நாணயங்கள் பயன்படுத்தப்படுகிறது, மேலும் பரிவர்த்தனை கட்டச்சங்கிலியில் பதிவு செய்யப்படுகிறது.
  6. உரிமை மின்டர் இடமிருந்து வாங்குபவருக்கு மாற்றப்படுகிறது.
  7. பயன்பாடு அல்லது நுகர்வுக்குப் பிறகு வில்லை புழக்கத்திலிருந்து நீக்கப்படலாம்.

எரித்தல்

எரித்தல் என்பது ஒரு வில்லையை அணுக முடியாத பணப்பை முகவரிக்கு அனுப்பி, அதை மீண்டும் பயன்படுத்த முடியாதபடி செய்யும் செயல்முறையாகும். வில்லை கட்டச்சங்கிலியில் தொடர்ந்து இருந்தாலும், அது புழக்கத்திலிருந்து திறம்பட நீக்கப்படுகிறது.

முக்கிய விளைவு

பிளாக்செயின் தொழில்நுட்பத்தின் மூலம் இயற்பியல் அல்லது டிஜிட்டல் உரிமைகளை வெளிப்படையான மற்றும் பாதுகாப்பான முறையில் பிரதிநிதித்துவப்படுத்தவும், மாற்றவும், சரிபார்க்கவும் வில்லையாக்கம் அனுமதிக்கிறது.

Note
