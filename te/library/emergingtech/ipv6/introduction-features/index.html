IPv6 పరిచయం

ఇంటర్నెట్ ప్రోటోకాల్ వెర్షన్ 6 (IPv6) అనేది ఇంటర్నెట్ ప్రోటోకాల్ (IP) యొక్క తాజా వెర్షన్. ఇది నెట్‌వర్క్‌లలోని కంప్యూటర్‌లకు గుర్తింపు, స్థాన వ్యవస్థను అందించి, ఇంటర్నెట్ అంతటా ట్రాఫిక్‌ను రూట్ చేసే కమ్యూనికేషన్ ప్రోటోకాల్.

IPv4 అడ్రస్‌లు అయిపోయే చాలాకాలంగా ఊహించిన సమస్యను పరిష్కరించడానికి Internet Engineering Task Force (IETF) IPv6ను అభివృద్ధి చేసింది.

IPv4 ఉపయోగించే 32-బిట్ అడ్రస్ పొడవుతో పోలిస్తే IPv6 128-బిట్ అడ్రస్ పొడవును ఉపయోగిస్తుంది.

IPv6 అడ్రస్‌లు నాలుగు హెక్సాడెసిమల్ అంకెలతో కూడిన ఎనిమిది గ్రూపులుగా, కోలన్‌లతో వేరు చేసి సూచించబడతాయి. పూర్తి IPv6 అడ్రస్ ఉదాహరణ:

2001:0db8:0000:0000:0000:8a2e:0370:7334

లేదా సంక్షిప్త రూపంలో:

2001:db8::8a2e:370:7334
