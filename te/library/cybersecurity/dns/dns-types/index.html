డొమైన్ పేరు వ్యవస్థ రకాలు

డొమైన్ పేరు వ్యవస్థ రకాలు / DNS Types

అంతర్గత DNS / Internal DNS

ఒక సంస్థ యొక్క నెట్‌వర్క్‌లోని సర్వర్‌లు మరియు వాటి IP చిరునామాల మధ్య మ్యాపింగ్‌ను నిర్వహించే లోపలికి ఉండే డొమైన్ పేరు వ్యవస్థ.

బాహ్య DNS / External DNS

ఇంటర్నెట్/పబ్లిక్ నెట్‌వర్క్‌లో అందుబాటులో ఉన్న సర్వర్‌లు మరియు వాటి IP చిరునామాల మధ్య మ్యాపింగ్‌ను నిర్వహించే బాహ్య డొమైన్ పేరు వ్యవస్థ.

రివర్స్ DNS / Reverse DNS

ఇది రివర్స్ క్వెరీ విధానం. ఒక నిర్దిష్ట IP చిరునామా ఉన్న సర్వర్‌కు సంబంధించిన పేరును అందిస్తుంది. DNSలో, ఒక డొమైన్ యొక్క PTR రికార్డ్ ఆ డొమైన్ సర్వర్ IP చిరునామాను విలోమంగా మార్చి arpa రూపంలో నిల్వ చేస్తుంది. రివర్స్ క్వెరీ సమయంలో ఈ విలువ తిరిగి అందించబడుతుంది. సెక్యూరిటీ లాగ్‌లను నిర్వహించే సాఫ్ట్‌వేర్‌లు మరియు ఇమెయిల్ గేట్‌వేల వంటి భవిష్యత్తు సర్వీస్‌లు ఈ విధానాన్ని ఉపయోగిస్తాయి.

డైనమిక్ DNS / Dynamic DNS

డొమైన్‌కి చెందిన IP చిరునామా స్థిరంగా లేకుండా తరచుగా మారే పరిస్థితుల్లో, ఆ డొమైన్ IP చిరునామాను ఆటోమేటిక్గా నవీకరించడానికి ఈ విధానం ఉపయోగించబడుతుంది. Microsoft Active Directoryలో ఇది ముఖ్యమైన భాగం. డొమైన్ కన్ట్రోల్‌ర్ ఆ డొమైన్‌లో అందుబాటులో ఉన్న సేవలను DNSలో నమోదు చేస్తాడు. ఇతర కంప్యూటర్‌లు కూడా ఈ సమాచారాన్ని ఉపయోగిస్తాయి.
