డొమైన్ పేరు వ్యవస్థ ప్రశ్న పరిష్కార ప్రక్రియ / DNS Query Resolution Process

క్లయింట్ డొమైన్ పేరును అభ్యర్థించినప్పుడు, DNS ప్రశ్న సాధారణంగా ఈ ప్రక్రియను అనుసరిస్తుంది:

  1. క్లయింట్ కాన్ఫిగర్ చేసిన రిసాల్వర్‌కు రికర్సివ్ DNS ప్రశ్నను పంపుతుంది.
  2. సమాధానం ఇప్పటికే తెలుసా అని రిసాల్వర్ తన క్యాష్‌ను పరిశీలిస్తుంది.
  3. క్యాష్‌లో సమాధానం లేకపోతే, సరైన TLD సర్వర్‌ను కనుగొనడానికి రిసాల్వర్ రూట్ సర్వర్‌ను ప్రశ్నిస్తుంది.
  4. తరువాత రిసాల్వర్ నిర్దిష్ట డొమైన్‌కు సంబంధించిన అధీకృత నేమ్ సర్వర్‌ను ప్రశ్నిస్తుంది.
  5. అధీకృత సర్వర్ సంబంధిత DNS రికార్డులను తిరిగి పంపుతుంది.
  6. రిసాల్వర్ ప్రతిస్పందనను క్లయింట్‌కు పంపి, భవిష్యత్ ఉపయోగం కోసం దాన్ని క్యాష్ చేయవచ్చు.

ఈ ప్రక్రియ ద్వారా క్లయింట్ మనుషులు చదవగలిగే డొమైన్ పేరును సరైన IP చిరునామాగా పరిష్కరిస్తుంది.

Note
