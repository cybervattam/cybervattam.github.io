**സൈബർവട്ടത്തിലേക്ക് (Cybervattam)** സ്വാഗതം — എല്ലാവർക്കും സ്വന്തം മാതൃഭാഷയിൽ അടിസ്ഥാന സാങ്കേതിക ആശയങ്ങൾ പഠിക്കാൻ സാധിക്കുന്നതിനായി, ഇന്ത്യൻ ഭാഷകളിൽ സാങ്കേതികവിദ്യയും സൈബർ സുരക്ഷാ അറിവുകളും നിർമ്മിക്കാനും പങ്കുവെക്കാനുമുള്ള ഒരു തുറന്ന കൂട്ടായ്മ സംരംഭമാണിത്.

ഞങ്ങളുടെ ലൈബ്രറി നിലവിൽ **ഇംഗ്ലീഷ്, തമിഴ്, മലയാളം, തെലുങ്ക്, കന്നഡ, ഹിന്ദി** എന്നീ ഭാഷകളിൽ ലഭ്യമാണ്. കൂടുതൽ ഇന്ത്യൻ ഭാഷകളിലേക്ക് ഇത് വ്യാപിപ്പിക്കാൻ ഞങ്ങൾ സജീവമായി പ്രവർത്തിച്ചുവരുന്നു.

### വിവർത്തനവും പ്രാദേശികവൽക്കരണ സമീപനവും

ലേഖനങ്ങൾ പ്രധാനമായും ഇംഗ്ലീഷിലാണ് തയ്യാറാക്കുന്നത്; തുടർന്ന് പിന്തുണയ്ക്കുന്ന മറ്റ് ഭാഷകളിലേക്ക് പ്രാദേശികവൽക്കരിക്കുന്നു. **AI വിവർത്തന ടൂളുകളും (AI translation tools) കൂട്ടായ്മയുടെ പരിശോധനയും (community review) സംയോജിപ്പിച്ചാണ് സൈബർവട്ടം പ്രവർത്തിക്കുന്നത്.** യന്ത്ര വിവർത്തനത്തിൽ ചിലപ്പോൾ സന്ദർഭോചിതമായ അർത്ഥവ്യത്യാസങ്ങൾ ഉണ്ടാകാനിടയുള്ളതിനാൽ, മനുഷ്യ പരിശോധനയിലൂടെ ഞങ്ങൾ ഉള്ളടക്കം നിരന്തരം മെച്ചപ്പെടുത്തുന്നു. അസ്വാഭാവികമായ പദപ്രയോഗങ്ങൾ ശ്രദ്ധയിൽപ്പെട്ടോ? [GitHub-ൽ തിരുത്തൽ നിർദ്ദേശിക്കുക](https://github.com/cybervattam/cybervattam.github.io/issues/new) അല്ലെങ്കിൽ [ഞങ്ങളുടെ ഇന്ത്യൻ ഭാഷാ സാങ്കേതിക പദാവലി (Indic Tech Glossary) പരിശോധിക്കുക](https://github.com/cybervattam/cybervattam.github.io).

### നിങ്ങൾക്ക് എങ്ങനെ സംഭാവന ചെയ്യാം

നിങ്ങൾ ഒരു സാങ്കേതിക വിദഗ്ദ്ധനോ, അധ്യാപകനോ, വിവർത്തകനോ, മാതൃഭാഷാ സ്നേഹിയോ ആകട്ടെ, എല്ലാ ഇന്ത്യൻ ഭാഷകളിലും സാങ്കേതിക അറിവ് ലഭ്യമാക്കാൻ താഴെ പറയുന്ന വഴികളിലൂടെ സഹായിക്കാം:

- **വിവർത്തനം മെച്ചപ്പെടുത്തുക**: ഒരു [GitHub Pull Request](https://github.com/cybervattam/cybervattam.github.io/pulls) സമർപ്പിക്കുക, [തിരുത്തലിനായി ഒരു Issue തുറക്കുക](https://github.com/cybervattam/cybervattam.github.io/issues/new), അല്ലെങ്കിൽ ഞങ്ങളുടെ [ബന്ധപ്പെടുക](/ml/library/aboutus/contactus/contactus/) പേജ് വഴി നിങ്ങളുടെ അഭിപ്രായങ്ങൾ അറിയിക്കുക.
- **ലേഖനം എഴുതുക**: [സൈബർവട്ടം GitHub റിപ്പോസിറ്ററി](https://github.com/cybervattam/cybervattam.github.io) വഴി ഇംഗ്ലീഷിലോ നേരിട്ട് നിങ്ങളുടെ മാതൃഭാഷാ ലിപിയിലോ പുതിയൊരു ഗൈഡ് അല്ലെങ്കിൽ പാഠം തയ്യാറാക്കുക.
- **പ്രാദേശിക സാങ്കേതിക പദങ്ങൾ നിർദ്ദേശിക്കുക**: സൈബർ സുരക്ഷയിലെയും നൂതന സാങ്കേതികവിദ്യയിലെയും പദങ്ങൾക്ക് അനുയോജ്യവും കൃത്യവുമായ മാതൃഭാഷാ പദങ്ങൾ ഉറപ്പാക്കാൻ [പദാവലി നിർദ്ദേശം സമർപ്പിക്കുക](https://github.com/cybervattam/cybervattam.github.io/issues/new).
