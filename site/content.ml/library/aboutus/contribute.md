### സൈബർവത്തം സംഭാവക മാർഗ്ഗനിർദ്ദേശത്തിലേക്ക് സ്വാഗതം

സൈബർ സുരക്ഷ, ഇന്റർനെറ്റ് സുരക്ഷ, വളർന്നുവരുന്ന സാങ്കേതികവിദ്യകൾ എന്നിവയെക്കുറിച്ചുള്ള അറിവ് ഇന്ത്യൻ ഭാഷകളിൽ എല്ലാവരിലേക്കും എത്തിക്കുന്നതിനായി നിർമ്മിച്ച ഒരു തുറന്ന കമ്മ്യൂണിറ്റി ലൈബ്രറിയാണ് **സൈബർവത്തം (Cybervattam)**. പുതിയൊരു പാഠം എഴുതാനോ നിലവിലുള്ള വിവർത്തനം മെച്ചപ്പെടുത്താനോ സാങ്കേതിക പദങ്ങൾ നിർദ്ദേശിക്കാനോ ഈ മാർഗ്ഗനിർദ്ദേശം നിങ്ങളെ സഹായിക്കും.

---

### 1. നിങ്ങൾക്ക് എങ്ങനെ സംഭാവന ചെയ്യാം?

1. **വിവർത്തനങ്ങൾ പരിശോധിക്കുകയും തിരുത്തുകയും ചെയ്യുക**: മലയാളം, തമിഴ്, ഹിന്ദി, തെലുങ്ക് അല്ലെങ്കിൽ കന്നഡ ലേഖനങ്ങളിൽ അക്ഷരത്തെറ്റുകളോ അപൂർണ്ണമായ വിവർത്തനങ്ങളോ ശ്രദ്ധയിൽപ്പെട്ടാൽ GitHub വഴി തിരുത്തലുകൾ നിർദ്ദേശിക്കാം.
2. **നിലവിലുള്ള പാഠങ്ങൾ വിവർത്തനം ചെയ്യുക**: `site/content.en/` ഫോൾഡറിലെ ഏതെങ്കിലും ഇംഗ്ലീഷ് ലേഖനം തിരഞ്ഞെടുത്ത് നിങ്ങളുടെ മാതൃഭാഷയിലേക്ക് വിവർത്തനം ചെയ്യുക.
3. **പുതിയ പാഠങ്ങളോ ചിത്രങ്ങളോ തയ്യാറാക്കുക**: സൈബർ സുരക്ഷയെക്കുറിച്ച് പുതിയ ലേഖനങ്ങളോ പ്രാദേശിക ഭാഷയിലുള്ള SVG ഡയഗ്രമുകളോ നിർമ്മിക്കുക.
4. **"ആഴ്ചയിലെ സാങ്കേതിക പദം" നിർദ്ദേശിക്കുക**: `site/static/data/terms-of-the-week.json` ഫയലിൽ പുതിയ സാങ്കേതിക പദങ്ങളും യഥാർത്ഥ ജീവിത ഉദാഹരണങ്ങളും ചേർക്കുക.

### 2. ഉള്ളടക്ക ഡയറക്ടറി ഘടന (Content Directory Structure)

### 3. സാങ്കേതിക പദങ്ങളുടെ വിവർത്തന മാർഗ്ഗനിർദ്ദേശങ്ങൾ (Translation vs. Transliteration)

സാങ്കേതിക ആശയങ്ങൾ ഇന്ത്യൻ ഭാഷകളിലേക്ക് മാറ്റുമ്പോൾ **ആശയവ്യക്തതയും** **പ്രായോഗികതയും** ഒരുപോലെ പാലിക്കണം.

#### എ. പ്രധാന ആശയങ്ങൾക്ക് മാതൃഭാഷാ പദം + ആദ്യ തവണ ബ്രാക്കറ്റിൽ ഇംഗ്ലീഷ് പദം
ഒരു സാങ്കേതിക ആശയത്തിന് സ്വാഭാവികമായ മലയാളം പദം ഉള്ളപ്പോൾ ആദ്യം **മലയാളം പദവും** ബ്രാക്കറ്റിൽ **ഇംഗ്ലീഷ് പദവും** നൽകുക:

| ഇംഗ്ലീഷ് പദം | ശുപാർശ ചെയ്യുന്ന രീതി | ഉദാഹരണം (മലയാളം) |
| :--- | :--- | :--- |
| **Encryption** | മലയാളം പദം + `(Encryption)` | ഗൂഢലിപീകരണം (Encryption) |
| **Phishing** | അർത്ഥവത്തായ പദം + `(Phishing)` | ചൂണ്ടയിടൽ തട്ടിപ്പ് (Phishing) |
| **Multi-Factor Authentication** | മലയാളം പദം + `(MFA)` | ബഹുതല പ്രാമാണീകരണം (MFA) |
| **Zero Trust** | മലയാളം പദം + `(Zero Trust)` | പൂജ്യം വിശ്വാസം (Zero Trust) |
| **Digital Signature** | മലയാളം പദം + `(Digital Signature)` | ഡിജിറ്റൽ ഒപ്പ് (Digital Signature) |

#### ബി. ആഗോള ചുരുക്കപ്പേരുകളും (Acronyms) പ്രോട്ടോക്കോളുകളും അതുപോലെ നിലനിർത്തുക
പ്രോട്ടോക്കോളുകൾ, അൽഗോരിതങ്ങൾ, ഫയൽ ഫോർമാറ്റുകൾ എന്നിവയ്ക്ക് കൃത്രിമ വിവർത്തനങ്ങൾ നൽകരുത്:

- **ചുരുക്കപ്പേരുകളായി നിലനിർത്തുക**: `DNS`, `HTTPS`, `TLS`, `IPv6`, `OTP`, `UPI`, `SIM`, `USB`, `APK`, `SHA-256`, `AES`, `SAML`, `OIDC`.
- **സ്ഥാപനങ്ങളും മാനദണ്ഡങ്ങളും**: `ICANN`, `IANA`, `NIST`, `WhatsApp`, `Authy`.

#### സി. പദാനുപദ വിവർത്തനത്തിന് പകരം സ്വാഭാവിക ശൈലി ഉപയോഗിക്കുക
- *"Mouse"*, *"Worm"*, *"Patch"*, *"Pipeline"* തുടങ്ങിയ പദങ്ങൾ സാങ്കേതിക അർത്ഥത്തിൽ വിവർത്തനം ചെയ്യുക.
- **"ചെയ്യേണ്ടവ" & "ചെയ്യരുതാത്തവ" (Do's & Don'ts)**: സുരക്ഷാ നിർദ്ദേശങ്ങളിൽ **"ചെയ്യരുതാത്തവ"** എന്ന വിഭാഗത്തിന് കീഴിലുള്ള ഓരോ പോയിന്റും *"പങ്കിടരുത്"*, *"ക്ലിക്ക് ചെയ്യരുത്"* എന്നിങ്ങനെ വ്യക്തമായ നിഷേധ രൂപത്തിലായിരിക്കണം.
