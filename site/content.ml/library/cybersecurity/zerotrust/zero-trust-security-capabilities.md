### സീറോ ട്രസ്റ്റ് സുരക്ഷാ ശേഷികൾ

സീറോ ട്രസ്റ്റ് തിരിച്ചറിയൽ, ഉപകരണങ്ങൾ, നെറ്റ്‌വർക്കുകൾ, ആപ്ലിക്കേഷനുകൾ എന്നിവയിലുടനീളമുള്ള നിരവധി സുരക്ഷാ ശേഷികളെ ആശ്രയിക്കുന്നു.

### തൂണുകളും ശേഷികളും

#### തിരിച്ചറിയൽ
- IAM
- IGA
- PIM & PAM
- RBAC
- സീക്രട്ട്സ് മാനേജ്മെന്റ്
- തിരിച്ചറിയൽ ഫെഡറേഷൻ
- PBAC

#### ഉപകരണം
- ഉപകരണ ഇൻവെന്ററി
- ഉപകരണ ബേസ്ലൈൻ, ഹാർഡനിംഗ്
- ഉപകരണ ഓതന്റിക്കേഷനും ഓതറൈസേഷനും
- ഉപകരണ അനുസരണം
- ഉപകരണ എൻക്രിപ്ഷൻ
- ഉപകരണ സാൻഡ്‌ബോക്സിംഗ്

#### നെറ്റ്‌വർക്കുകളും ഇൻഫ്രാസ്ട്രക്ചറും
- SD-WAN
- നെറ്റ്‌വർക്ക് സെഗ്മെന്റേഷൻ
- DDoS സംരക്ഷണം
- SWG, ZTNA
- NAC
- IDS, IPS
- NGFW

#### ആപ്ലിക്കേഷൻ
- API സുരക്ഷ

### ലക്ഷ്യം

ഓരോ തൂണും ആക്സസ് തീരുമാനങ്ങളെ വ്യക്തവും അനുയോജ്യവും അപകടസാധ്യത ബോധമുള്ളതുമാക്കുന്നതിന് സംഭാവന ചെയ്യുന്നു.
