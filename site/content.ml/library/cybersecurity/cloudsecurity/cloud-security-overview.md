### ക്ലൗഡ് സുരക്ഷയുടെ അവലോകനം

ക്ലൗഡ് അധിഷ്ഠിത സിസ്റ്റങ്ങൾ, ഡാറ്റ, ആപ്ലിക്കേഷനുകൾ, തിരിച്ചറിയലുകൾ, വർക്ക്‌ലോഡുകൾ എന്നിവയെ ഭീഷണികളിൽനിന്നും ദുരുപയോഗത്തിൽനിന്നും സംരക്ഷിക്കുന്നതാണ് ക്ലൗഡ് സുരക്ഷ.

ക്ലൗഡ് ദാതാക്കൾ വലിയ സ്വകാര്യ നെറ്റ്‌വർക്കുകളും സമർപ്പിത ബാക്ക്‌ബോൺ കണക്റ്റിവിറ്റിയും വിപുലമായ അടിസ്ഥാനസൗകര്യവും പ്രവർത്തിപ്പിക്കുന്നു. എന്നിരുന്നാലും, സുരക്ഷ പല തലങ്ങളിലായി രൂപകൽപ്പന ചെയ്യണം. ദാതാവിന്റെ പരിസ്ഥിതി മാത്രമല്ല, സ്ഥാപനത്തിന്റെ സ്വന്തം വർക്ക്‌ലോഡുകൾ, തിരിച്ചറിയലുകൾ, ആപ്ലിക്കേഷനുകൾ, ഡാറ്റ എന്നിവയും സംരക്ഷിക്കേണ്ടതുണ്ട്.

### സുരക്ഷയുടെ പ്രധാന മേഖലകൾ

- ഭൗതിക അടിസ്ഥാനസൗകര്യ സുരക്ഷ
- വിർച്ച്വലൈസേഷനും ഹൈപ്പർവൈസർ സുരക്ഷയും
- നെറ്റ്‌വർക്ക് സുരക്ഷ
- തിരിച്ചറിയലും ആക്‌സസ് നിയന്ത്രണവും
- ഡാറ്റാ സംരക്ഷണവും എൻക്രിപ്ഷനും
- പാലനവും ഭരണവും
- ഭീഷണി കണ്ടെത്തലും പ്രതികരണവും

### ക്ലൗഡിന്റെ സുരക്ഷയും ക്ലൗഡിലെ സുരക്ഷയും

ക്ലൗഡ് സുരക്ഷയെ പരസ്പരം പൂരകമായ രണ്ട് കാഴ്ചപ്പാടുകളിൽ സമീപിക്കുന്നു.

#### ക്ലൗഡിന്റെ സുരക്ഷ (പ്ലാറ്റ്‌ഫോം സുരക്ഷ)
അടിസ്ഥാന പ്ലാറ്റ്‌ഫോം സംരക്ഷിക്കാൻ പ്രധാനമായും ക്ലൗഡ് സേവന ദാതാവ് പ്രവർത്തിപ്പിക്കുന്ന നിയന്ത്രണങ്ങൾ:

- പങ്കിട്ട ഉത്തരവാദിത്ത മാതൃക
- സൗകര്യങ്ങളും ഭൗതിക സുരക്ഷയും
- ഹാർഡ്‌വെയർ സുരക്ഷ
- വിർച്ച്വലൈസേഷൻ സുരക്ഷ
- ക്ലൗഡ് കോർ കണക്റ്റിവിറ്റി സുരക്ഷ
- ക്ലൗഡ് മാനേജ്മെന്റ് പ്ലെയിനും API സുരക്ഷയും
- ബിസിനസ് തുടർച്ചയും ദുരന്തനിവാരണവും

#### ക്ലൗഡിലെ സുരക്ഷ (സേവന സുരക്ഷ)
പ്ലാറ്റ്‌ഫോമിൽ നിർമ്മിക്കുകയും പ്രവർത്തിപ്പിക്കുകയും ചെയ്യുന്നവ സംരക്ഷിക്കാൻ ഉപഭോക്താക്കൾ പ്രയോഗിക്കുന്ന നിയന്ത്രണങ്ങൾ:

- ക്ലൗഡ് സുരക്ഷയുടെ അടിസ്ഥാന ഘടകങ്ങൾ
- ക്ലൗഡ് നേറ്റീവ് ആപ്ലിക്കേഷൻ പ്രൊട്ടക്ഷൻ പ്ലാറ്റ്‌ഫോം (CNAPP), ഇതിൽ CWPP, CSPM, SSPM എന്നിവ ഉൾപ്പെടുന്നു
- സെക്യൂർ ആക്‌സസ് സർവീസ് എഡ്ജ് (SASE), ഇതിൽ SWG, CASB, ZTNA എന്നിവ ഉൾപ്പെടുന്നു
- ക്ലൗഡ് തിരിച്ചറിയലും ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ എൻടൈറ്റിൽമെന്റ് മാനേജ്മെന്റും (CIEM)
- ക്ലൗഡ് ഡാറ്റാ സുരക്ഷ
