# ക്ലൗഡ് സുരക്ഷ

ഈ വിഭാഗം ക്ലൗഡ് സുരക്ഷാ മാതൃക, പ്ലാറ്റ്ഫോം സംരക്ഷണങ്ങൾ, തിരിച്ചറിയൽ നിയന്ത്രണങ്ങൾ, ഡാറ്റാ സംരക്ഷണം, ആധുനിക സീറോ ട്രസ്റ്റ്, SASE അധിഷ്ഠിത സുരക്ഷാ രീതികൾ എന്നിവ ഉൾക്കൊള്ളുന്നു.

- ക്ലൗഡ് സുരക്ഷയുടെ അവലോകനം
- പങ്കിട്ട ഉത്തരവാദിത്ത മാതൃക
- ഭൗതിക, ഹാർഡ്‌വെയർ സുരക്ഷ
- വിർച്ച്വലൈസേഷൻ സംരക്ഷണം
- ക്ലൗഡ് തിരിച്ചറിയലും അവകാശ മാനേജ്മെന്റും
- ഡാറ്റാ സുരക്ഷയും എൻക്രിപ്ഷനും
- SASE, SWG, CASB, ZTNA
- പബ്ലിക് ക്ലൗഡ് നേറ്റീവ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ
