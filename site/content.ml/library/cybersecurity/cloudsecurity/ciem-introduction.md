### ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ എൻടൈറ്റിൽമെന്റ് മാനേജ്മെന്റ് (CIEM)

ഏറ്റവും കുറഞ്ഞ അനുമതി എന്ന തത്വം (POLP) അനുസരിച്ച് തിരിച്ചറിയലുകളും ക്ലൗഡ് അനുമതികളും കൈകാര്യം ചെയ്യാൻ ഉപയോഗിക്കുന്ന ക്ലൗഡ് സുരക്ഷാ പരിഹാരമാണ് ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ എൻടൈറ്റിൽമെന്റ് മാനേജ്മെന്റ് (CIEM).

ഒന്നിലധികം ക്ലൗഡ് പരിസ്ഥിതികളിലെ അക്കൗണ്ട് അനുമതികളിലുള്ള അപാകതകൾ കണ്ടെത്താൻ CIEM മെഷീൻ ലേണിംഗും അനലിറ്റിക്സും ഉപയോഗിക്കുന്നു. ഇതുവഴി സ്ഥാപനങ്ങൾക്ക് വിവിധ ക്ലൗഡ് സേവനങ്ങളിലുടനീളം തിരിച്ചറിയലിന്റെയും ആക്‌സസ് മാനേജ്മെന്റിന്റെയും സ്ഥിരത ഉറപ്പാക്കാനും ഡാറ്റാ ലംഘനത്തിന്റെയും പുറത്തേക്ക് ഡാറ്റ ചോരുന്നതിന്റെയും അപകടസാധ്യത കുറയ്ക്കാനും കഴിയും.

### CIEM-ന്റെ സാധാരണ ഘടന

- നിയന്ത്രണ പ്ലെയിൻ
- ഡാറ്റാ പ്ലെയിൻ
- API സംയോജനം
- കണക്ടറുകൾ
- കണ്ടെത്തൽ, പരസ്പരബന്ധം, ഒപ്റ്റിമൈസേഷൻ എഞ്ചിൻ
- സുരക്ഷാ അവകാശ ഡാറ്റാബേസ്
- മാനേജ്മെന്റ് പോർട്ടൽ
- സ്ഥാപന നയങ്ങൾ
- ഡാഷ്‌ബോർഡും ദൃശ്യവൽക്കരണവും

### ലക്ഷ്യം

അമിതമായ അനുമതികൾ നീക്കം ചെയ്ത്, ഓരോ തിരിച്ചറിയലിനും ജോലി ചെയ്യാൻ ആവശ്യമായ ആക്‌സസ് മാത്രം ഉറപ്പാക്കുന്നതിലൂടെ ആക്രമണസാധ്യത കുറയ്ക്കാൻ CIEM സഹായിക്കുന്നു.
