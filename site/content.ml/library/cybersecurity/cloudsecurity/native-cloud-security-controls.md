### നേറ്റീവ് ക്ലൗഡ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ

വർക്ക്‌ലോഡുകൾ, തിരിച്ചറിയലുകൾ, നെറ്റ്‌വർക്കുകൾ, ആപ്ലിക്കേഷനുകൾ എന്നിവ സുരക്ഷിതമാക്കാൻ സഹായിക്കുന്ന നിരവധി നേറ്റീവ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ പൊതു ക്ലൗഡ് സേവന ദാതാക്കൾ നൽകുന്നു.

### ഉദാഹരണങ്ങൾ

#### AWS

- IAM, SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS, HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure

- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM, Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### ഉദ്ദേശ്യം

ദാതാവ് ഉൾപ്പെടുത്തിയിരിക്കുന്ന കഴിവുകളും പ്ലാറ്റ്‌ഫോമിന്റെ നേറ്റീവ് നിരീക്ഷണം, തിരിച്ചറിയൽ, എൻക്രിപ്ഷൻ, പാലന നിയന്ത്രണങ്ങൾ എന്നിവയും പ്രയോജനപ്പെടുത്തി ക്ലൗഡ് പ്രവർത്തനങ്ങൾ സുരക്ഷിതമാക്കാൻ ഈ നിയന്ത്രണങ്ങൾ സ്ഥാപനങ്ങളെ സഹായിക്കുന്നു.
