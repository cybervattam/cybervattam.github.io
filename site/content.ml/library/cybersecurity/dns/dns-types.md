### DNS തരങ്ങൾ

#### ആന്തരിക DNS
ഒരു സ്ഥാപനത്തിന്റെ സ്വകാര്യ നെറ്റ്‌വർക്കിനുള്ളിലെ സെർവറുകളെയും സേവനങ്ങളെയും ആന്തരിക IP വിലാസങ്ങളുമായി മാപ്പ് ചെയ്യാൻ ഉപയോഗിക്കുന്ന DNS ആണ് ആന്തരിക DNS.

#### ബാഹ്യ DNS
പൊതു ഇന്റർനെറ്റിൽ എത്തിച്ചേരാവുന്ന സെർവറുകളെയും സേവനങ്ങളെയും പൊതു IP വിലാസങ്ങളുമായി ബന്ധിപ്പിക്കാൻ ഉപയോഗിക്കുന്ന DNS ആണ് ബാഹ്യ DNS.

#### റിവേഴ്സ് DNS
ഒരു IP വിലാസത്തെ അതിന്റെ ഹോസ്റ്റ് നാമത്തിലേക്ക് പരിഹരിക്കുന്ന റിവേഴ്സ് ലുക്കപ്പാണ് റിവേഴ്സ് DNS. DNS-ൽ PTR റെക്കോർഡ് ഈ മാപ്പിംഗ് വിപരീത രൂപത്തിൽ in-addr.arpa അല്ലെങ്കിൽ ip6.arpa ഡൊമെയ്‌നിന് കീഴിൽ സൂക്ഷിക്കുന്നു.

സുരക്ഷാ സംവിധാനങ്ങളും ഇമെയിൽ ഗേറ്റ്‌വേകളും നെറ്റ്‌വർക്ക് നിരീക്ഷണ ഉപകരണങ്ങളും ഇത് സാധാരണയായി ഉപയോഗിക്കുന്നു.

#### ഡൈനാമിക് DNS
ഒരു ഡൊമെയ്‌നിന്റെ IP വിലാസം ഇടയ്ക്കിടെ മാറുകയും സ്വയമേവ അപ്ഡേറ്റ് ചെയ്യേണ്ടിവരുകയും ചെയ്യുന്ന സാഹചര്യത്തിലാണ് ഡൈനാമിക് DNS ഉപയോഗിക്കുന്നത്. Microsoft Active Directoryയിലും സമാന പരിസ്ഥിതികളിലും ഇത് പ്രധാനപ്പെട്ട ഘടകമാണ്.

സോൺ അഡ്മിനിസ്ട്രേറ്റർ ആ സോണിലെ DNS റെക്കോർഡുകൾ അപ്ഡേറ്റ് ചെയ്യുന്നു; മറ്റ് സിസ്റ്റങ്ങൾ സേവനങ്ങൾ കണ്ടെത്താൻ ഈ വിവരങ്ങൾ ഉപയോഗിക്കുന്നു.
