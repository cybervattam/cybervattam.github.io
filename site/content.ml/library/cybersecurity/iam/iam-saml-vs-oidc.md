### സിംഗിൾ സൈൻ-ഓൺ പ്രോട്ടോക്കോൾ താരതമ്യം (SSO Protocol Comparison)

| <img src="images/shared/logos/saml-logo.png" width=20%> | <img src="images/shared/logos/openid-connect-logo.jpg" width=20%> |

| __SAML__ | __OIDC__ |
| ----------------------- | -------------------------- |
| ദീർഘകാലമായി ഉപയോഗിക്കുന്ന ഓതന്റിക്കേഷൻ, ഓതറൈസേഷൻ, സിംഗിൾ സൈൻ-ഓൺ പ്രോട്ടോക്കോളാണ്. <br> വിവരങ്ങൾ കൈമാറാൻ XML ഉപയോഗിക്കുന്നു. SAML അസർഷനുകളും ടോക്കണുകളും വലുതായതിനാൽ പ്രോസസ്സ് ചെയ്യുന്നത് താരതമ്യേന ബുദ്ധിമുട്ടാണ്. <br> ഉപയോക്തൃ സമ്മതത്തെ സ്വാഭാവികമായി പിന്തുണയ്ക്കില്ല. <br> സർക്കാർ സ്ഥാപനങ്ങൾ ഉൾപ്പെടെ നിരവധി സ്ഥാപനങ്ങൾ ഇത് വിശ്വസിക്കുന്നു. <br> എന്റർപ്രൈസുകൾക്കും ബിസിനസ്-ടു-ബിസിനസ് വിവര കൈമാറ്റത്തിനും അനുയോജ്യം. | OAuth 2.0 അടിസ്ഥാനമാക്കിയുള്ള പുതിയ സിംഗിൾ സൈൻ-ഓൺ പ്രോട്ടോക്കോളാണ്. <br> ചെറുതും എളുപ്പത്തിൽ പ്രോസസ്സ് ചെയ്യാവുന്നതുമായ JSON Web Tokens (JWTs) ഉപയോഗിക്കുന്നു. <br> ഉപയോക്തൃ സമ്മതത്തെ സ്വാഭാവികമായി പിന്തുണയ്ക്കുന്നു. <br> SAML പിന്തുണയ്ക്കുന്ന സവിശേഷതകൾ OIDC-യും നൽകിത്തുടങ്ങിയിട്ടുണ്ട്. <br> ബിസിനസ്-ടു-കൺസ്യൂമർ സംവിധാനങ്ങൾക്കും SPA, മൊബൈൽ ആപ്ലിക്കേഷനുകൾ പോലുള്ള ആധുനിക ആപ്ലിക്കേഷനുകൾക്കും അനുയോജ്യം. |
