# IPv6

ഈ വിഭാഗം IPv6-ന്റെ അടിസ്ഥാന ആശയങ്ങൾ, അതിന്റെ ആവശ്യം, വിലാസ ഘടന, ഹെഡർ ഫോർമാറ്റ്, IPv4-ൽ നിന്നുള്ള വ്യത്യാസങ്ങൾ എന്നിവ ഉൾക്കൊള്ളുന്നു.

- പരിചയവും സവിശേഷതകളും
- IPv6 എന്തുകൊണ്ട് ആവശ്യമാണ്
- വിലാസ നിയമങ്ങളും ഘടനയും
- വിലാസ മോഡുകളും യൂണികാസ്റ്റ് തരങ്ങളും
- IPv6 ഹെഡർ ഫോർമാറ്റ്
- IPv4-ഉം IPv6-ഉം തമ്മിലുള്ള താരതമ്യം
