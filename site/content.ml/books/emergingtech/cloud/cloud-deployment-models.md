## __ക്ലൗഡ് വിന്യാസ മാതൃകകൾ__
<br>
<img src="images/en/emergingtech/cloud/cloud-deployment-models.png">

<br>
<br>

#### 1. പൊതു ക്ലൗഡ്
ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ പൊതുജനങ്ങൾക്കും വലിയ ബിസിനസ് സ്ഥാപനങ്ങൾക്കും നൽകുന്നു. ഈ ഇൻഫ്രാസ്ട്രക്ചർ ക്ലൗഡ് സേവനദാതാക്കളുടെ ഉടമസ്ഥതയിലാണ്.

ആർക്കും ക്ലൗഡ് സേവനങ്ങൾ നേടാം.

ഉദാഹരണങ്ങൾ:
* Amazon Web Services
* Microsoft Azure
* Google Cloud Platform


#### 2. സ്വകാര്യ ക്ലൗഡ്

ഈ തരത്തിലുള്ള ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ ഒരു സ്ഥാപനത്തിനായി മാത്രം പ്രവർത്തിപ്പിക്കുന്നു.

ഇത് സ്ഥാപനമോ മൂന്നാം കക്ഷിയോ നിയന്ത്രിക്കാം; സ്ഥാപന പരിസരത്തിനകത്തോ പുറത്തോ ആയിരിക്കാം.

ഉദാഹരണങ്ങൾ:
* Rackspace
* VMware vCloud
* Azure Stack
* IBM Cloud Private

#### 3. ഹൈബ്രിഡ് ക്ലൗഡ്

ഈ തരത്തിലുള്ള ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ സ്വകാര്യ, കമ്മ്യൂണിറ്റി, പൊതു ക്ലൗഡ് തുടങ്ങിയ രണ്ടോ അതിലധികമോ വിന്യാസ മാതൃകകളുടെ സംയോജനമാണ്; ഇത് ഒരു ഏക ഘടകമായി പ്രവർത്തിക്കുന്നു. ഡാറ്റയും ആപ്ലിക്കേഷൻ പോർട്ടബിലിറ്റിയും സാധ്യമാക്കാൻ പരിസ്ഥിതികൾ സ്റ്റാൻഡേർഡ് അല്ലെങ്കിൽ ഉടമസ്ഥാവകാശ സാങ്കേതികവിദ്യ ഉപയോഗിച്ച് ബന്ധിപ്പിക്കുന്നു. ക്ലൗഡ് സേവനദാതാവുമായി നേരിട്ട് ബന്ധിപ്പിച്ച നോൺ-ക്ലൗഡ് ഡാറ്റാ സെന്ററിനെയും ഹൈബ്രിഡ് ക്ലൗഡ് എന്ന് സാധാരണ വിളിക്കുന്നു.


#### 4. കമ്മ്യൂണിറ്റി ക്ലൗഡ്

സാങ്കേതികമായി, കമ്മ്യൂണിറ്റി ക്ലൗഡ് നിർദ്ദിഷ്ട ഉപഭോക്താക്കൾക്ക് മാത്രം ലഭ്യമാകുന്ന പങ്കിട്ട ക്ലൗഡ് പ്ലാറ്റ്ഫോമാണ്. നിർദ്ദിഷ്ട സ്ഥാപനങ്ങൾ മൾട്ടി-ടെനൻസി ഉപയോഗിച്ച് ക്ലൗഡ് ഇൻഫ്രാസ്ട്രക്ചർ പങ്കിടുന്നു. ദൗത്യം, സുരക്ഷാ ആവശ്യകതകൾ, നയം, അല്ലെങ്കിൽ അനുസരണ ആശങ്കകൾ പങ്കിടുന്ന ഒരു സമൂഹത്തെ ഇത് പിന്തുണയ്ക്കുന്നു. ഒരു സ്ഥാപനമോ മൂന്നാം കക്ഷിയോ ഇത് നിയന്ത്രിക്കാം; സ്ഥാപന പരിസരത്തിനകത്തോ പുറത്തോ ആയിരിക്കാം. സർക്കാർ ക്ലൗഡ് (GovCloud) ഒരു ഉദാഹരണമാണ്.
