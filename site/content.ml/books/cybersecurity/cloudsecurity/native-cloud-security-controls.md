### നേറ്റീവ് ക്ലൗഡ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ

പബ്ലിക് ക്ലൗഡ് സേവന ദാതാക്കൾ വർക്ക്‌ലോഡുകൾ, തിരിച്ചറിയലുകൾ, നെറ്റ്‌വർക്കുകൾ, ആപ്ലിക്കേഷനുകൾ എന്നിവ സുരക്ഷിതമാക്കാൻ സഹായിക്കുന്ന വിവിധ നേറ്റീവ് സുരക്ഷാ നിയന്ത്രണങ്ങൾ നൽകുന്നു.

### ഉദാഹരണങ്ങൾ

#### AWS
- IAM and SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS and HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM and Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### ഉദ്ദേശ്യം

ദാതാവിന്റെ ബിൽറ്റ്-ഇൻ കഴിവുകളും പ്ലാറ്റ്ഫോം നേറ്റീവ് നിരീക്ഷണം, തിരിച്ചറിയൽ, എൻക്രിപ്ഷൻ, അനുസരണ നിയന്ത്രണങ്ങളും ഉപയോഗിച്ച് ക്ലൗഡ് പ്രവർത്തനങ്ങൾ സുരക്ഷിതമാക്കാൻ ഈ നേറ്റീവ് നിയന്ത്രണങ്ങൾ സ്ഥാപനങ്ങളെ സഹായിക്കുന്നു.
