### ക്ലൗഡ് ആക്‌സസ് സെക്യൂരിറ്റി ബ്രോക്കർ (CASB)

Gartner അനുസരിച്ച്, ക്ലൗഡ് സേവന ഉപഭോക്താക്കൾക്കും ക്ലൗഡ് സേവന ദാതാക്കൾക്കും ഇടയിൽ സ്ഥാപിച്ചിരിക്കുന്ന സുരക്ഷാ നയ നിർവഹണ പോയിന്റാണ് ക്ലൗഡ് ആക്‌സസ് സെക്യൂരിറ്റി ബ്രോക്കർ.

CASBകൾ എന്റർപ്രൈസ് സുരക്ഷാ നയങ്ങൾ ഏകീകരിക്കുകയും ക്ലൗഡ് വിഭവങ്ങൾ ആക്‌സസ് ചെയ്യുമ്പോൾ അവ നടപ്പാക്കുകയും ചെയ്യുന്നു.

### സാധാരണ CASB സവിശേഷതകൾ

- ഓതന്റിക്കേഷനും സിംഗിൾ സൈൻ-ഓണും
- ഓതറൈസേഷനും ക്രെഡൻഷ്യൽ മാപ്പിംഗും
- ഉപകരണ പ്രൊഫൈലിംഗ്
- എൻക്രിപ്ഷനും ടോക്കണൈസേഷനും
- ലോഗിംഗും അലേർട്ടിംഗും
- മാൽവെയർ കണ്ടെത്തലും തടയലും
- ഡാറ്റാ നഷ്ടം തടയലും പ്രവർത്തന നിരീക്ഷണവും
- ഷാഡോ IT കണ്ടെത്തൽ

### പരിധി

ക്ലൗഡിലെ SaaS ആപ്ലിക്കേഷനുകൾ സംരക്ഷിക്കാനാണ് CASBകൾ പ്രധാനമായും ഉപയോഗിക്കുന്നത്. PaaS, IaaS എന്നിവയ്ക്കുള്ള അവയുടെ പിന്തുണ സാധാരണയായി കൂടുതൽ പരിമിതമാണ്.

### വിന്യാസ രീതികൾ

- പ്രോക്സി മോഡ്
- API മോഡ്

### ഉപയോഗ സാഹചര്യങ്ങൾ

- ഷാഡോ IT കണ്ടെത്തലും ഭരണനിർവഹണവും
- ഡാറ്റാ എക്സ്ഫിൽട്രേഷൻ തടയൽ
- ഭീഷണി കണ്ടെത്തലും ഫോറൻസിക് അന്വേഷണവും
- അനുസരണ പിന്തുണയും പ്രവർത്തന നിരീക്ഷണവും
