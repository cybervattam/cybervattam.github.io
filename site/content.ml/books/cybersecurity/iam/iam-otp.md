### __വൺ-ടൈം പാസ്‌വേഡ് (OTP)__

ഹാഷിംഗ് അൽഗോരിതങ്ങൾ ഉപയോഗിച്ചാണ് വൺ-ടൈം പാസ്‌വേഡുകൾ സൃഷ്ടിക്കുന്നത്. സീഡും മൂവിംഗ് ഫാക്ടറും എന്ന രണ്ട് ഇൻപുട്ടുകളാണ് ഇവ ഉപയോഗിക്കുന്നത്.

സീഡ് ഒരു സ്ഥിര മൂല്യം അഥവാ സീക്രട്ട് കീ ആണ്. ഓതന്റിക്കേഷൻ സെർവറിൽ പുതിയ അക്കൗണ്ട് രജിസ്റ്റർ ചെയ്യുമ്പോൾ ഈ കീ സൃഷ്ടിക്കുന്നു. മൂവിംഗ് ഫാക്ടറിനെ അടിസ്ഥാനമാക്കി HOTP, TOTP എന്നീ രണ്ട് തരത്തിലുള്ള വൺ-ടൈം പാസ്‌വേഡുകളുണ്ട്.

#### __HOTP__

HOTP എന്നത് Hash-based Message Authentication Code One-Time Password എന്നതിന്റെ ചുരുക്കപ്പേരാണ്.

HOTP ഇവന്റ് അടിസ്ഥാനമാക്കിയുള്ളതാണ്. വൺ-ടൈം പാസ്‌വേഡ് സൃഷ്ടിക്കാൻ ഇത് കൗണ്ടറിനെ മൂവിംഗ് ഫാക്ടറായി ഉപയോഗിക്കുന്നു. ഇവിടെ ഒരു ഇവന്റ് എന്നത് കൗണ്ടർ വർധിക്കുന്നതാണ്.

അടുത്ത വൺ-ടൈം പാസ്‌വേഡ് സൃഷ്ടിക്കുന്നതുവരെ മുമ്പത്തെ പാസ്‌വേഡ് സാധുവായിരിക്കും.

#### __TOTP__

TOTP എന്നത് Time-Based One-Time Password എന്നതിന്റെ ചുരുക്കപ്പേരാണ്.

TOTP അൽഗോരിതം കൗണ്ടറിന് പകരം സമയത്തെ മൂവിംഗ് ഫാക്ടറായി ഉപയോഗിക്കുന്നു.

ഓരോ പാസ്‌വേഡും സാധുവായിരിക്കുന്ന സമയദൈർഘ്യത്തെ ടൈം സ്റ്റെപ്പ് എന്ന് വിളിക്കുന്നു.
