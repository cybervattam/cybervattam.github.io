# സിമെട്രിക് കീ എൻക്രിപ്ഷൻ

### അൽഗോരിതങ്ങൾ
- Advanced Encryption Standard (AES)
- Data Encryption Standard (DES)
- TwoFish / BlowFish
- RC4, RC5, RC6

#### ഉപയോഗങ്ങൾ
- ഹാർഡ് ഡിസ്ക് (HDD) എൻക്രിപ്ഷൻ
- സോളിഡ്-സ്റ്റേറ്റ് ഡ്രൈവ് (SSD) എൻക്രിപ്ഷൻ
- ക്ലൗഡ് സ്റ്റോറേജ് എൻക്രിപ്ഷൻ
- വിർച്ച്വൽ സ്റ്റോറേജ് എൻക്രിപ്ഷൻ

## അസിമെട്രിക് കീ എൻക്രിപ്ഷൻ

### അൽഗോരിതങ്ങൾ
- Rivest Shamir Adleman (RSA)
- Diffie-Hellman
- Digital Signature Algorithm (DSA)
- Elliptic Curve Cryptography (ECC)

#### ഉപയോഗങ്ങൾ
- Transport Layer Security (TLS/SSL)
- ഡിജിറ്റൽ ഒപ്പുകൾ
- Virtual Private Networks (VPN)
- Secure Hypertext Transfer Protocol (HTTPS)

## ഹാഷിംഗ്

### അൽഗോരിതങ്ങൾ
- Message Digest (MD2, MD4, MD5)
- Secure Hash Algorithm (SHA-1, SHA-256, SHA-384, SHA-512)

#### ഉപയോഗങ്ങൾ
- പാസ്‌വേഡ് ഹാഷിംഗ്
- സോഫ്റ്റ്‌വെയർ സമഗ്രത പരിശോധന
- ഫയൽ സമഗ്രത പരിശോധന
- ബ്ലോക്ക്ചെയിൻ (Blockchain)
