### ಮೇಕಕ್ ಕಣಿಮೈ ಪಾತ್ತಿರಙ್ಕಳ್ / Cloud Computing Roles

* ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ / Cloud Provider
    - ಆರ್ವಮುಳ್ಳ ತರಪ್ಪಿನರುಕ್ಕು ಮೇಕಕ್ಕಣಿಮೈ ಸೇವೈಯೈ ಕಿಟೈಕ್ಕಸ್ ಸೆಯ್ಯುಮ್ ಪೊರುಪ್ಪೈ ಏರ್ಕುಮ್ ನಪರ್, ಅಮೈಪ್ಪು ಅಲ್ಲತು ನಿರುವನಮ್
<br>
* ಮೇಕಕ್ ಕಣಿಮೈ  ನುಕರ್ವೋರ್ / ವಾಟಿಕ್ಕೈಯಾಳರ್ / Cloud Consumer
    - ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರಿಟಮ್ ವಣಿಕ ಉರವೈಪ್ ಪರಾಮರಿಕ್ಕುಮ್ ಮರ್ರುಮ್ ಸೇವೈಯೈಪ್ ಪಯನ್ಪಟುತ್ತುಮ್ ಒರು ನಪರ್ ಅಲ್ಲತು ಅಮೈಪ್ಪು
<br>
* ಮೇಕಕ್ಕಣಿಮೈ ತರವುಕ್ಕಟತ್ತಿ /  Cloud Carrier
    - ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರಿಟಮಿರುನ್ತು ನುಕರ್ವೋರುಕ್ಕು ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಕಳಿನ್ ಇಣೈಪ್ಪು ಮರ್ರುಮ್ ಪೋಕ್ಕುವರತ್ತೈ ವಳಙ್ಕುಮ್ ಒರು ಇಟೈತ್ತರಕರ್
<br>
* ಮೇಕಕ್ಕಣಿಮೈ ತರಕರ್ಕಳ್ / Cloud Broker
    - ಮೇಕಕ್ಕಣಿಮೈ ಸೇವೈಕಳಿನ್ ಪಯನ್ಪಾಟು, ಸೆಯಲ್ತಿರನ್ ಮರ್ರುಮ್ ವಿನಿಯೋಕತ್ತೈ ನಿರ್ವಕಿಕ್ಕುಮ್ ಮರ್ರುಮ್ ಮೇಕಕ್ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ಕಳುಕ್ಕುಮ್ ನುಕರ್ವೋರುಕ್ಕುಮ್ ಇಟೈಯಿಲಾನ ಉರವು ಮೇಮ್ಪಾಟು ಪೇಸ್ಸುವಾರ್ತ್ತೈ ನಟತ್ತುಮ್ ಒರು ನಿರುವನಮ್
<br>
* ಮೇಕಕ್ಕಣಿಮೈ ಅಣುಕಲ್ ಪಾತುಕಾಪ್ಪು ತರಕರ್ಕಳ್ / Cloud Access Security Broker (CASB)
    - ಇವ್ವಕೈ ಮೆನ್ಪೊರುಳ್ ಮೇಕಕ್ ಕನಿಮೈಯೈ ನೋಕ್ಕಿ ಅನುಪ್ಪಪ್ಪಟುಮ್ ತಕವಲ್ತೊಟರ್ಪುಕಳೈ ಇಟೈಮರಿಕ್ಕವುಮ್ ಅಲ್ಲತು ಸೆಯಲ್ಪಾಟ್ಟೈ ಕಣ್ಕಾಣಿಕ್ಕವುಮ್, ಕೊಳ್ಕೈಕಳೈ ಸೆಯಲ್ಪಟುತ್ತವುಮ್, ಪಾತುಕಾಪ್ಪು ಸಿಕ್ಕಲ್ಕಳೈಕ್ ಕಣ್ಟರಿನ್ತು ತಟುಕ್ಕವುಮ್ ಪಯನ್ಪಾಟು ನಿರಲಾಕ್ಕ ಇಟೈಮುಕಮ್  ವಳಿಯಾಕವೋ ಅಲ್ಲತು ನೇರಟಿಯಾಕ ಸೇವೈಯಾಕ ನುಕರುಮ್ ಮೆನ್ಪೊರುಳುಟನ್ ಇಣೈಕ್ಕಿನ್ರನ. ಅವೈ ಪೊತುವಾಕ ಒರು ನಿರುವನತ್ತಿನ್ ಅನುಮತಿಕ್ಕಪ್ಪಟ್ಟ ಮರ್ರುಮ್ ಅನುಮತಿಕ್ಕಪ್ಪಟಾತ ಸೇವೈಕಳೈ (ಸೇವೈಯಾಕ ಮೆನ್ಪೊರುಳ್) ನಿರ್ವಕಿಕ್ಕ ಪಯನ್ಪಟುತ್ತಪ್ಪಟುಕಿನ್ರನ.
