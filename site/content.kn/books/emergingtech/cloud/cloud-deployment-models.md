## __ಮೇಕಕ್ ಕಣಿಮೈ ಪಣಿಯಮರ್ತ್ತಲ್ ಮುರೈಕಳ್ / Cloud Deployment Models__

<br>
<br>

#### 1. ಪೊತು ಮೇಕಕ್ ಕಣಿಮೈ / Public Cloud
ಮೇಕಕ್ಕಣಿಮೈ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ಪೊತು ಮಕ್ಕಳುಕ್ಕು ಅಲ್ಲತು ಪೆರಿಯ ತೊಳಿಲ್ ನಿರುವನಙ್ಕಳುಕ್ಕು ವಳಙ್ಕಪ್ಪಟುಕಿರತು. ಇನ್ತ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳುಕ್ಕು ಸೊನ್ತಮಾನತು.

ಮೇಕಕ್ಕಣಿಮೈ ಸೇವೈಕಳೈ ಯಾರ್ ವೇಣ್ಟುಮಾನಾಲುಮ್ ಪೆರಲಾಮ್ 

ಎಟುತ್ತುಕ್ಕಾಟ್ಟು
* ಅಮೇಸಾನ್ ವಲೈ ಸೇವೈಕಳ್ / Amazon Web Services
* ಮೈಕ್ರೋಸಾಃಪ್ಟ್ ಅಸೂರ್ / Microsoft Azure
* ಕೂಕುಳ್ ಮೇಕಕ್ಕಣಿಮೈ ತಳಮ್ / Google Cloud Platform


#### 2. ತನಿಯಾರ್ ಮೇಕಕ್ ಕಣಿಮೈ / Private Cloud

ಇವ್ವಕೈ ಮೇಕಕ್ಕಣಿಮೈ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ಒರು ನಿರುವನತ್ತಿರ್ಕಾಕ ಮಟ್ಟುಮೇ ಇಯಕ್ಕಪ್ಪಟುಕಿರತು. 

ಇತು ನಿರುವನತ್ತಾಲ್ ಅಲ್ಲತು ಮೂನ್ರಾಮ್ ತರಪ್ಪಿನರಾಲ್ ನಿರ್ವಕಿಕ್ಕಪ್ಪಟಲಾಮ್ ಮರ್ರುಮ್ ನಿರುವನ ವಳಾಕತ್ತಿನ್ ಉಳ್ಳೇ ಅಲ್ಲತು ನಿರುವನ ವಳಾಕತ್ತಿರ್ಕು ವೆಳಿಯೇ ಇರುಕ್ಕಲಾಮ್

ಎಟುತ್ತುಕ್ಕಾಟ್ಟು:
* Rackspace
* VMware vCloud
* Azure Stack
* IBM Cloud Private

#### 3. ಕಲಪ್ಪು ಮೇಕಕ್ ಕಣಿಮೈ / Hybrid Cloud

ಇವ್ವಕೈ ಮೇಕಕ್ಕಣಿಮೈ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ಎನ್ಪತು ಇರಣ್ಟು ಅಲ್ಲತು ಅತರ್ಕು ಮೇರ್ಪಟ್ಟ ಪಣಿಯಮರ್ತ್ತಲ್ ಮುರೈಕಳಿನ್ (ತನಿಯಾರ್, ಸಮೂಕಮ್ ಅಲ್ಲತು ಪೊತು) ಕಲವೈಯಾಕ. ಒರೇ ನಿರುವನತ್ತಾಲ್ ಇಯಕ್ಕಪ್ಪಟುಕಿರತು. ಇವೈ ತರನಿಲೈ ಅಲ್ಲತು ತನಿಯುರಿಮೈ ತೊಳಿಲ್ನುಟ್ಪತ್ತಾಲ್ ಪಿಣೈಕ್ಕಪ್ಪಟ್ಟು, ತರವು ಮರ್ರುಮ್ ಪಯನ್ಪಾಟ್ಟು ಪೆಯರ್ವುತ್ತಿರನೈ ಸೆಯಲ್ಪಟುತ್ತುಕಿನ್ರನ. ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರುಟನ್ ನೇರಟಿಯಾಕ ಇಣೈಕ್ಕಪ್ಪಟ್ಟ ಮೇಕಕ್ಕಣಿಮೈ ಅಲ್ಲಾತ ತರವು ಮೈಯತ್ತೈ ವಿವರಿಕ್ಕ ಕಲಪ್ಪು ಮೇಕಕ್ಕಣಿಮೈ ಪೊತುವಾಕಪ್ ಪಯನ್ಪಟುತ್ತಪ್ಪಟುಕಿರತು.


#### 4. ಸಮೂಕ ಮೇಕಕ್ ಕಣಿಮೈ / Community Cloud

ತೊಳಿಲ್ನುಟ್ಪ ಕಣ್ಣೋಟ್ಟತ್ತಿಲ್, ಸಮೂಕ ಮೇಕಕ್ಕಣಿಮೈ ಎನ್ಪತು ಕುರಿಪ್ಪಿಟ್ಟ ವಾಟಿಕ್ಕೈಯಾಳರ್ಕಳ್ ಮಟ್ಟುಮೇ ಅಣುಕಕ್ಕೂಟಿಯ ಪಕಿರಪ್ಪಟ್ಟ ಮೇಕಕ್ಕಣಿಮೈ ತಳಮಾಕುಮ್. ಮೇಕಕ್ಕಣಿಮೈ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ಕುರಿಪ್ಪಿಟ್ಟ ನಿರುವನಙ್ಕಳಾಲ್ ಪಲ್ಕುತ್ತಕೈತ್ ತನ್ಮೈಯುಟನ್ ಪಕಿರಪ್ಪಟುಕಿರತು. ಇವೈ ಪಣಿ, ಪಾತುಕಾಪ್ಪು ತೇವೈಕಳ್, ಕೊಳ್ಕೈ ಅಲ್ಲತು ಇಣಕ್ಕ ಕರುತ್ತುಕಳೈಪ್ ಪಕಿರ್ನ್ತುಕೊಳ್ಳುಮ್ ಒರು ಕುರಿಪ್ಪಿಟ್ಟ ಸಮೂಕತ್ತೈ ಆತರಿಕ್ಕಿರತು. ಇತು ಒರು ನಿರುವನತ್ತಾಲ್ ಅಲ್ಲತು ಮೂನ್ರಾಮ್ ತರಪ್ಪಿನರಾಲ್ ನಿರ್ವಕಿಕ್ಕಪ್ಪಟಲಾಮ್ ಮರ್ರುಮ್ ನಿರುವನ ವಳಾಕತ್ತಿನ್ ಉಳ್ಳೇ ಅಲ್ಲತು ನಿರುವನ ವಳಾಕತ್ತಿರ್ಕು ವೆಳಿಯೇ ಇರುಕ್ಕಲಾಮ್. ಎಟುತ್ತುಕ್ಕಾಟ್ಟು., ಅರಸು ಮೇಕಕ್ಕಣಿಮೈ (Gov Cloud)
