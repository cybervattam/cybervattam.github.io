## __ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈ ಮುರೈಕಳ್ / Cloud Service Models__

<br>
<img src="images/cloud-ta/cloud-service-model-ta.svg">
<br>
<br>

#### 1. ಸೇವೈಯಾಕ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು / Infrastructure as a Service (IaaS)
ಮೆಯ್ನಿಕರಾಕ್ಕಪ್ಪಟ್ಟ ಕಣಿಮೈ, ಪಿಣೈಯಮ್ ಅಲ್ಲತು ಸೇಮಿಪ್ಪಕಮ್ ಪೋನ್ರ ಅಟಿಪ್ಪಟೈ ಕಣಿನಿ ಉಳ್ಕಟ್ಟಮೈಪ್ಪಿನ್ ನಿರ್ವಕಿತ್ತು ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ವಳ ತಿರಳ್ವಿರ್ಕಾನ ಅಣುಕಲೈ ವಳಙ್ಕುಕಿನ್ರನರ್. ಕಕ್ ಕಣಿಮೈ ನುಕರ್ವೋರ್ ತಙ್ಕಳ್ ತೇವೈಕ್ಕೇರ್ಪ ಪಲ್ವೇರು ಇಯಙ್ಕುತಳಮ್ ಮರ್ರುಮ್ ಪಯನ್ಪಾಟುಕಳೈ ಅತನ್ ಮೇಲ್ ನಿರುವಲಾಮ್.


#### 2. ಸೇವೈಯಾಕ ಪಣಿತ್ತಳಮ್ / Platform as a service (PaaS)
ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ತರವುತ್ತಳಙ್ಕಳ್, ಪಯನ್ಪಾಟ್ಟು ತಳಙ್ಕಳ್, ನಿರಲಾಕ್ಕತ್ ತಳಙ್ಕಳ್, ಇಯಕ್ಕ ನೇರಸ್ ಸೂಳಲ್ ಪೋನ್ರ ತಳಙ್ಕಳೈ ಉರುವಿಲಾ ನಿಲೈಯಿಲ್ ಪಣಿತ್ತಳಮಾಕ ವಳಙ್ಕುಕಿನ್ರನರ್

ಎಟುತ್ತುಕ್ಕಾಟ್ಟು:
* ಪೈತ್ತಾನ್, PHP ಅಲ್ಲತು ಪಿರ ಮೂಲಕ್ಕುರಿಯೀಟ್ಟೈ ಇಯಕ್ಕುವತರ್ಕಾನ ಇಟಮ್ 
* ಸೇವೈಯಾಕ ತರವುತ್ತಳಮ್ (Database as a Service)
* ಸೇವೈಯಾಕ ತರವುಕಿಟಙ್ಕು (Datawarehousee as a Service)
* ಸೇವೈಯಾಕ ಸೇಮಿಪ್ಪಕಮ್ (Data Storage as a Service)
* ಸೇವೈಯಾಕ ಇಯನ್ತಿರ ಕರ್ರಲ್ (Machine Learing as a Service)

ಮುಕ್ಕಿಯ ವೇರುಪಾಟು ಎನ್ನವೆನ್ರಾಲ್, ನೀಙ್ಕಳ್ ಅಟಿಪ್ಪಟೈಯಿಲ್ ಉಳ್ಳ  ಸೇವೈಯಕಙ್ಕಳ್, ಪಿಣೈಯಙ್ಕಳ್ ಅಲ್ಲತು ಪಿರ ಉಳ್ಕಟ್ಟಮೈಪ್ಪೈ ನಿರ್ವಕಿಕ್ಕ ಮಾಟ್ಟೀರ್ಕಳ್.

#### 3. ಸೇವೈಯಾಕ ಮೆನ್ಪೊರುಳ್ / Software as a Service (SaaS)

ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ನಿರ್ವಕಿಕ್ಕಪ್ಪಟ್ಟು ವಳಙ್ಕಪ್ಪಟುಮ್ ಮುಳು ಪಯನ್ಪಾಟು. ಇಣೈಯ ಉಲಾವಿ, ಮೊಪೈಲ್ ಪಯನ್ಪಾಟು ಅಲ್ಲತು ಇಲಕುರಕ ಕಿಳೈಯನ್ ಪಯನ್ಪಾಟು ಮೂಲಮ್ ನುಕರ್ವೋರ್ ಇತೈ ಅಣುಕಲಾಮ್. 

ತನಿಪ್ಪಯನಾಕ್ಕಮ್ / ಉಳ್ಳಮೈವು ಕಿಟೈಕ್ಕಕ್ಕೂಟುಮ್. ಅಮ್ಸಙ್ಕಳ್ ಅಲ್ಲತು ತಿರನ್ಕಳೈ ಮಾರ್ರ ಮುಟಿಯಾತು.

ಎಟುತ್ತುಕ್ಕಾಟ್ಟು: 
* ನೆಟ್ಃಪಿಕ್ಸ್,
* ಪಿರೈಮ್ ವೀಟಿಯೋ
* ಜಿಮೆಯಿಲ್
* ಯೂಟಿಯೂಪ್ 
* ಜೂಮ್
* ಮೈಕ್ರೋಸಾಪ್ಟ್ 365 ಪೋನ್ರ ಸೇವೈಕಳ್
