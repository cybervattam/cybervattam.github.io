## __ಮೇಕಕ್ ಕಣಿಮೈಯಿನ್ ಅತ್ತಿಯಾವಸಿಯ ಪಣ್ಪುಕಳ್ / Cloud Computing Essential Characteristics__

#### 1. ಪರನ್ತ ಪಿಣೈಯ ಅಣುಕಲ್ / Broad Network Access

ಅನೈತ್ತು ಮೇಕಕ್ ಕಣಿಮೈ ವಳಙ್ಕಳುಮ್ ನೇರಟಿ ಅಣುಕಲ್ ತೇವೈ ಇಲ್ಲಾಮಲ್ ನಿರ್ವಕಿಕ್ಕ ಮರ್ರುಮ್ ಪಯನ್ಪಟುತ್ತ ಒರು ಪಿಣೈಯತ್ತಿನ್ ವಳಿಯೇ ಕಿಟೈಕ್ಕುಮ್. ಇನ್ತ ಪಿಣೈಯಮ್ ಸೇವೈಯಿನ್ ಒರು ಪಕುತಿಯಾಕ ಇರುಕ್ಕ ವೇಣ್ಟಿಯ ಅವಸಿಯಮಿಲ್ಲೈ. ಮೇಕಕ್ ಕಣಿಮೈ ವಳಙ್ಕಳ್ ಎಙ್ಕಿರುನ್ತುಮ್ ಅಣುಕಕ್ಕೂಟಿಯತಾಕ ಇರುಕ್ಕ ವೇಣ್ಟುಮ್, ಆನಾಲ್ ಅಣುಕಲ್ ಕೊಳ್ಕೈಕಳಾಲ್ ಅವೈ ಕಟ್ಟುಪ್ಪಟುತ್ತಪ್ಪಟಲಾಮ್. ಇತು ತವಿರ, ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ಪಲ್ವೇರು ಪಕುತಿಕಳಿಲ್ ಉಳ್ಳ ತಙ್ಕಳ್ ವಳಙ್ಕಳುಕ್ಕು ಇಟೈಯೇ ಪಾತುಕಾಪ್ಪಾನ ಪಿಣೈಯ ಇಣೈಪ್ಪೈ ಕೊಣ್ಟಿರುಕ್ಕ ವೇಣ್ಟುಮ್.

#### 2. ವಿರೈವಾನ ಮೀಳ್ಮೈ / Rapid Elasticity

* ನುಕರ್ವೋರ್, ವಳ ತಿರಳ್ವಿಲ್ ಇರುನ್ತು ಪಯನ್ಪಟುತ್ತುಮ್ ವಳಙ್ಕಳೈ ಅಳವೈ ಅತಿಕರಿಕ್ಕ ಅಲ್ಲತು ಕುರೈಕ್ಕ ಅನುಮತಿಕ್ಕಿರತು. 
* ಅಳವೈ ಮಾರ್ರುಮ್ಪೋತು ವಳಙ್ಕುತಲ್ / ನೀಕ್ಕುತಲ್ ಪೆರುಮ್ಪಾಲುಮ್ ತಾನಿಯಕ್ಕಮಾಕ ನಿಕಳುಮ್. 
* ಇತು ವಾಟಿಕ್ಕೈಯಾಳರ್ಕಳ್ ತೇವೈಯುಟನ್ ವಳ ನುಕರ್ವೈ ಮಿಕವುಮ್ ನೆರುಕ್ಕಮಾಕ ಪೊರುತ್ತ ಅನುಮತಿಕ್ಕಿರತು. 
* ವಿರೈವಾನ ಮೀಳ್ಮೈ ಎನ್ಪತು ಇರಣ್ಟು ತಾನಿಯಕ್ಕ ಅಳವುಮಾರ್ರತ್ತೈ ಆತರಿಕ್ಕ ವೇಣ್ಟುಮ್
  - ಸೆಙ್ಕುತ್ತಾನ ಅಳವುಮಾರ್ರಮ್
  - ಕಿಟೈಮಟ್ಟ ಅಳವುಮಾರ್ರಮ್

* ಸೆಙ್ಕುತ್ತಾನ ಅಳವುಮಾರ್ರಮ್: ತರ್ಪೋತು ಇರುಕ್ಕುಮ್ ಅಮೈಪ್ಪಿಲ್ ವಳಙ್ಕಳಿನ್ ಅಳವೈ ಮಾರ್ರುತಲ್. 
* ಕಿಟೈಮಟ್ಟ ಅಳವುಮಾರ್ರಮ್: ಪುತಿಯ ವಳಙ್ಕಳೈ ಸೇರ್ಪ್ಪತನ್ ಮೂಲಮ್ ಅಳವೈ ಮಾರ್ರುತಲ್. ಪುತಿಯ ವಳಙ್ಕಳ್ ಅತೇ ಇಟತ್ತಿಲೋ ಅಲ್ಲತು ಪುತಿಯ ಇಟತ್ತಿಲೋ ಇರುಕ್ಕಲಾಮ್.


#### 3. ಅಳವಿಟಪ್ಪಟ್ಟ ಸೇವೈ / Measured Service

ನುಕರ್ವೋರ್ ತಙ್ಕಳುಕ್ಕು ಒತುಕ್ಕಪ್ಪಟ್ಟ ವಳಙ್ಕಳೈ ಮಟ್ಟುಮೇ ಪಯನ್ಪಟುತ್ತುವತೈ ಉರುತಿ ಸೆಯ್ಯ ವೇಣ್ಟುಮ್, ತೇವೈಪ್ಪಟ್ಟಾಲ್, ಅತರ್ಕಾನ ಕಟ್ಟಣತ್ತೈ ವಸೂಲಿಕ್ಕ ವೇಣ್ಟುಮ್. ಮೇಕಕ್ ಕಣಿಮೈ ವಳಙ್ಕಳ್ ನೀರ್ ಮರ್ರುಮ್ ಮಿನ್ಸಾರಮ್ ಪೋನ್ರ ನುಕರಪ್ಪಟುವತಾಲ್ ಇತು ಪಯನ್ಪಾಟ್ಟು ಕಣಿಮೈ ಎನ್ರುಮ್ ಅಳೈಕ್ಕಪ್ಪಟುಕಿರತು (ಪಯನ್ಪಾಟ್ಟುಕೇರ್ರ ಕಟ್ಟಣಮ್). ಮೇಕಕ್ ಕಣಿಮೈ ವಳಙ್ಕಳಿನ್ ಅಳವೀಟ್ಟು ಅಲಕು ತೆಳಿವಾಕ ವರೈಯರುಕ್ಕಪ್ಪಟ ವೇಣ್ಟುಮ್ ಮರ್ರುಮ್ ಒರು ಕುರಿಪ್ಪಿಟ್ಟ ಕಟ್ಟಣ ಕಾಲತ್ತಿರ್ಕು ಆಕಕ್ಕೂಟಿಯ ಪಯನ್ಪಾಟ್ಟುಸ್ ಸೆಲವು (ಸಾತ್ತಿಯಮಾನ / ತೋರಾಯಮಾನ) ಮೇಲಾಣ್ಮೈ ತಳತ್ತಿಲ್ ಕಾಟ್ಟಪ್ಪಟ ವೇಣ್ಟುಮ್.


#### 4. ತೇವೈಕ್ಕೇರ್ಪ ಸುಯ ಸೇವೈ / On-Demand Self Service
ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರಿನ್ ವಾಟಿಕ್ಕೈಯಾಳರ್ ಸೇವೈ ನಿರ್ವಾಕಿಕಳುಟನ್ ಪೇಸುಮ್ ತೇವೈಯಿನ್ರಿ, ಮೇಕಕ್ ಕಣಿಮೈ ನುಕರ್ವೋರ್ ತಙ್ಕಳ್ ವಳಙ್ಕಳೈ ತಾಙ್ಕಳೇ ನಿರ್ವಕಿಕ್ಕ ವಳಿವಕುಕ್ಕಮ್ ಸುಯ ಸೇವೈ ಅಮೈಪ್ಪೈ ಕೊಣ್ಟಿರುಕ್ಕ ವೇಣ್ಟುಮ್. ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ವಳಙ್ಕಳೈ ಅಣುಕವುಮ್ ನಿರ್ವಕಿಕ್ಕವುಮ್ ಮೇಲಾಣ್ಮೈತ್ತಳಮ್ (Management Plane) ವಳಿಯಾಕ ಇನ್ತ ಸುಯ ಸೇವೈ ಅಮ್ಸತ್ತೈ  ವಳಙ್ಕುಕಿನ್ರನರ್.

ಮೇಲಾಣ್ಮೈತತ್ತಳ ಅಣುಕಲ್ ಮುರೈಕಳ್
    * ಇಣೈಯ ವಳಿ ಕಟ್ಟುಪ್ಪಾಟ್ಟು ಮುನೈಯಮ್ (Web Console)
    * ಪಯನ್ಪಾಟ್ಟು ನಿರಲಾಕ್ಕ ಇಟೈಮುಕಮ್ (API)
    * ಮೆನ್ಪೊರುಳ್ ಉರುವಾಕ್ಕ ಕರುವಿಪ್ಪೆಟ್ಟಿ (SDK)


#### 5. ವಳ ತಿರಳ್ವು / Resource Pooling

ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ವನ್ಪೊರುಳ್ ಉಳ್ಕಟ್ಟಮೈಪ್ಪಿಲಿರುನ್ತು ವಳ ತಿರಳ್ವು ಸೆಯ್ತು ಅತನೈ ಉರುವಿಲಾ ನಿಲೈಯಿಲ್(abstracted format) ವಳಙ್ಕುಕಿನ್ರನರ್. ಉರುವಿಲಾ ನಿಲೈ ಮೆಯ್ನಿಕರಾಕ್ಕತ್ತಾಲ್ ಸೆಯಲ್ಪಟುತ್ತಪ್ಪಟುಕಿರತು. ನುಕರ್ವೋರ್ ತೇವೈಕ್ಕೇರ್ಪ ವಳ ತಿರಳ್ವಿಲಿರುನ್ತು ವಳಙ್ಕಳೈ ಒತುಕ್ಕ ಮರ್ರುಮ್ ವಳಙ್ಕ ತಾನಿಯಕ್ಕ ಒರುಙ್ಕಿಣೈನ್ತ ತಿಟ್ಟಮಿಟಲೈ (automated orchestration) ಪಯನ್ಪಟುತ್ತುಕಿರಾರ್ಕಳ್


#### 6. ಪಲ್ಕುತ್ತಕೈತ್ ತನ್ಮೈ / Multitenancy

ಮೇಕ್ಕ ಕಣಿಮೈ ಇಯರ್ಕೈಯಾಕವೇ ಪಲ್ಕುತ್ತಕೈತ್ತನ್ಮೈ ಕೊಣ್ಟುಳ್ಳತು. ಪಲ ವೆವ್ವೇರು ನುಕರ್ವೋರ್ ಒರೇ ವಳ ತಿರಳ್ವೈ ಪಕಿರ್ನ್ತು ಕೊಳ್ಕಿರಾರ್ಕಳ್, ಆನಾಲ್ ಒವ್ವೊರು ನುಕರ್ವೋರುಮ್ ಪಿರಿಕ್ಕಪ್ಪಟ್ಟು ತನಿಮೈಪ್ ಪಟುತ್ತಪ್ಪಟುಕಿರಾರ್ಕಳ್. ಪಿರಿತ್ತಲ್ ಮೇಕಕ್ ಕಣಿಮೈ ಸೇವೈಯಾಳರ್ಕಳ್ ವೆವ್ವೇರು ಕುಳುಕ್ಕಳುಕ್ಕು ವಳ ತಿರಳ್ವಿಲಿರುನ್ತು ವಳಙ್ಕಳೈಪ್ ಪಿರಿತ್ತು ಪಕಿರ್ನ್ತು ಕೊಳ್ಳ ಅನುಮತಿಕ್ಕಿರತು. ತನಿಮೈಪ್ಪಟುತ್ತುತಲ್ ಒರು ನುಕರ್ವೋರ್ ಮರ್ರೋರ್ ವಳಙ್ಕಳೈ ಪಾರ್ಕ್ಕವೋ, ಮಾರ್ರವೋ ಮುಟಿಯಾತು ಎನ್ಪತೈ ಉರುತಿ ಸೆಯ್ಕಿರತು. ಪಲ್ಕುತ್ತಕೈತ್ತನ್ಮೈ ಒರು ವಣಿಕಮ್ ಅಲ್ಲತು ನಿರುವನತ್ತಿರ್ಕುಳ್ ವೆವ್ವೇರು ತುರೈಕಳುಕ್ಕು ಇಟೈಯಿಲ್ ಅಲ್ಲತು ವೆವ್ವೇರು ನಿರುವನಙ್ಕಳುಕ್ಕು ಇಟೈಯಿಲ್ ವಳಙ್ಕಳೈಪ್ ಪಿರಿಕ್ಕವುಮ್ ಪಕಿರ್ನ್ತು ಕೊಳ್ಳವುಮ್ ಪಯನ್ಪಟುತ್ತಪ್ಪಟುಕಿರತು.
