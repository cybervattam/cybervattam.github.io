# IPv6

ಈ ವಿಭಾಗವು IPv6ನ ಮೂಲ ಪರಿಕಲ್ಪನೆಗಳು, ಅದರ ಅಗತ್ಯತೆ, ವಿಳಾಸ ರಚನೆ, ಹೆಡರ್ ಸ್ವರೂಪ ಮತ್ತು IPv4ಗಿಂತ ಅದರ ವ್ಯತ್ಯಾಸಗಳನ್ನು ಒಳಗೊಂಡಿದೆ.

- ಪರಿಚಯ ಮತ್ತು ವೈಶಿಷ್ಟ್ಯಗಳು
- IPv6 ಏಕೆ ಅಗತ್ಯವಿದೆ
- ವಿಳಾಸ ನಿಯಮಗಳು ಮತ್ತು ರಚನೆ
- ವಿಳಾಸ ಮೋಡ್‌ಗಳು ಮತ್ತು ಯುನಿಕಾಸ್ಟ್ ವಿಧಗಳು
- IPv6 ಹೆಡರ್ ಸ್ವರೂಪ
- IPv4 ಮತ್ತು IPv6 ಹೋಲಿಕೆ
