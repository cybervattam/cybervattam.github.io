### ಕೋಡ್ ಸಹಿ / Code Signing

ಕುರಿಯೀಟು ಒಪ್ಪಮಿಟಲ್ ಎನ್ಪತು ಮೆನ್ಪೊರುಳ್ (ಇಯಕ್ಕಕ್ಕೂಟಿಯ ಕೋಪ್ಪುಕಳ್ ಮರ್ರುಮ್ ಮೂಲ ಕುರಿಯೀಟು) ಪತಿಪ್ಪಾಳರೈ ಅಟೈಯಾಳಪ್ಪಟುತ್ತ ಇಲಕ್ಕಮುರೈ ಮುರೈಯಿಲ್ ಒಪ್ಪಮಿಟುವತು.​ ಮೇಲುಮ್, ಇತು ಒಪ್ಪಮಿಟಪ್ಪಟ್ಟ ನೇರತ್ತಿಲಿರುನ್ತು ಮೆನ್ಪೊರುಳ್ ಮಾರ್ರಪ್ಪಟವಿಲ್ಲೈ ಅಲ್ಲತು ಸಿತೈಕ್ಕಪ್ಪಟವಿಲ್ಲೈ ಎನ್ಪತರ್ಕು ಉತ್ತರವಾತಮ್ ಅಳಿಕ್ಕಿರತು. ಇತನೈ ಸರಿಪಾರ್ಕ್ಕ ಕುರುಕ್ಕ ಮತಿಪ್ಪುಕಳೈ ಪಯನ್ಪಟುತ್ತುಕಿರತು. ​ಕುರಿಯೀಟು ಒಪ್ಪಮಿಟಲ್ ವಳಿಯಾಕ ಮೆನ್ಪೊರುಳ್ ಅಟೈಯಾಳಮ್ / ಸಾನ್ರುರುತಿ ಅಳಿಕ್ಕುಮ್ ಇಮ್ಮುರೈಯಿನ್ ಪಾತುಕಾಪ್ಪು,  ಒಪ್ಪಮಿಟುಮ್ ತಿರವಿಕಳಿನ್ ಪಾತುಕಾಪ್ಪೈಪ್ ಪೊರುತ್ತತು. ಇನ್ತ ಅಮೈಪ್ಪಿನ್ ನಮ್ಪಕತ್ತನ್ಮೈ ಮೆನ್ಪೊರುಳ್ ವೆಳಿಯೀಟ್ಟಾಳರ್ಕಳ್ ತಙ್ಕಳ್ ತನಿತ್ ತಿರವಿಕಳೈ ಪಾತುಕಾಪ್ಪತೈ ನಮ್ಪಿಯುಳ್ಳತು​. ಎನವೇ, ಪಾತುಕಾಪ್ಪಾನ, ಸೇತಮಟೈಯಾತ, ಮರೈಪ್ಪಿಯಲ್ ವನ್ಪೊರುಳ್ ಸಾತನಙ್ಕಳಿಲ್ ತಿರವಿಕಳೈ ಸೇಮಿಪ್ಪತು ಮಿಕವುಮ್ ಪಾತುಕಾಪ್ಪಾನತು ಮರ್ರುಮ್ ಸಿರನ್ತ ನಟೈಮುರೈಯಾಕ ಕರುತಪ್ಪಟುಕಿರತು.​ ಇವ್ವಕೈ ಸಾತನಙ್ಕಳ್ ವನ್ಪೊರುಳ್ ಪಾತುಕಾಪ್ಪು ತೊಕುತಿಕಳ್ (Hardware Security Module – HSM) ಎನ ಅಳೈಕ್ಕಪ್ಪಟುಮ್.​

### ಕುರಿಯೀಟು ಒಪ್ಪಮಿಟಲ್ ಸಾನ್ರಿತಳ್ ವಕೈಕಳ್ / Code Signing Certificate Types 
<br>

#### ನಿಲೈಯಾನ ಕುರಿಯೀಟು ಒಪ್ಪಮಿಟಲ್ ಸಾನ್ರಿತಳ್ಕಳ್ / Standard Code Signing Certificates
ಅತಿಕ ಪತಿವಿರಕ್ಕಙ್ಕಳ್ ಮರ್ರುಮ್ ಕುರೈನ್ತಪಟ್ಸ ಪಿಳೈ ಅರಿಕ್ಕೈಕಳ್ ಆಕಿಯವರ್ರಿನ್ ಅಟಿಪ್ಪಟೈಯಿಲ್ ವೆಳಿಯೀಟ್ಟಾಳರ್ ಒರು ನರ್ಪೆಯರೈ ಉರುವಾಕ್ಕುಮ್ ವರೈ ಮೈಕ್ರೋಸಾಃಪ್ಟ್ ಸ್ಮಾರ್ಟ್ಸ್ಕಿರೀನ್ ಎಸ್ಸರಿಕ್ಕೈಕಳ್ ಅನ್ತ ವೆಳಿಯೀಟ್ಟಾಳರಿನ್ ಕುರಿಯೀಟುಕಳ್ / ಸೆಯಲಿಕಳುಕ್ಕು ತೊಟರ್ನ್ತು ಕಾಣ್ಪಿಕ್ಕಪ್ಪಟುಮ್. ಕುರಿಯೀಟ್ಟೈ ನಮ್ಪಲಾಮ್ ಎನ್ರ ಉರುತಿಪ್ಪಾಟ್ಟೈ ಇತು ಅಳಿಕ್ಕಾತು. ಮೂಲಕ್ ಕುರಿಯೀಟು ಒರು ಕುರಿಪ್ಪಿಟ್ಟ ತನಿತ್ ತಿರವಿಯಾಲ್ ಒಪ್ಪಮಿಟಪ್ಪಟ್ಟತು ಎನ್ಪತೈ ಪೊತುತ್ ತಿರವಿ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ವಳಿಯಾಕ ಉರುತಿಸೆಯ್ಕಿರತು. 
ಕುರಿಯೀಟು ಒಪ್ಪತ್ತೈ ಅಙ್ಕೀಕರಿಕ್ಕಪ್ ಪಯನ್ಪಟುತ್ತಪ್ಪಟುಮ್ ಪೊತುತ್ ತಿರವಿ / ಸಾನ್ರಿತಳ್, ನಮ್ಪಕಮಾನ ವೇರ್ ಸಾನ್ರಿತಳ್ ಆಣೈಯತ್ತೋಟು ಇಣೈನ್ತಿರುಕ್ಕ ವೇಣ್ಟುಮ್. ಇತನೈ ನಮ್ಪಿಕ್ಕೈಸ್ ಸಙ್ಕಿಲಿ ಮೂಲಮ್ ಸರಿಪಾರ್ಕ್ಕಲಾಮ್.

#### ವಿರಿವಾಕ್ಕಪ್ಪಟ್ಟ ಸರಿಪಾರ್ತ್ತಲ್ ಕುರಿಯೀಟು ಒಪ್ಪಮಿಟಲ್ ಸಾನ್ರಿತಳ್ಕಳ್ / Extended Validated Code Signing Certificates

ನೀಟ್ಟಿಕ್ಕಪ್ಪಟ್ಟ ಸರಿಪಾರ್ಪ್ಪುಕ್ ಕುರಿಯೀಟು ಕೈಯೊಪ್ಪಮಿಟಲ್ ಸಾನ್ರಿತಳ್ಕಳ್, ವೆಳಿಯೀಟ್ಟಾಳರಿನ್ ಅಟೈಯಾಳತ್ತೈ ಮುಳುಮೈಯಾಕ ಸರಿಪಾರ್ತ್ತ ಪಿನ್ನರ್ ವಳಙ್ಕಪ್ಪಟುಕಿರತು. ವಿರಿವಾಕ್ಕಪ್ಪಟ್ಟ ಸರಿಪಾರ್ತ್ತಲ್ ಕುರಿಯೀಟು ಸಾನ್ರಿತಳಾಲ್ ಒಪ್ಪಮಿಟಪ್ಪಟ್ಟ ಮೆನ್ಪೊರುಳೈ / ಕುರಿಯೀಟ್ಟೈ ಸ್ಮಾರ್ಟ್ಸ್ಕಿರೀನ್ ಸರಿಪಾರ್ಕ್ಕುಮ್ ಪೋತು ಅನ್ತ ವೆಳಿಯೀಟ್ಟಾಳರುಕ್ಕು ಎನ್ತ ಮುನ್ ನರ್ಪೆಯರ್ ಇಲ್ಲಾವಿಟ್ಟಾಲುಮ್ ಉಟನಟಿಯಾಕ ನರ್ಪೆಯರೈ ನಿರುವ ಮುಟಿಯುಮ್. ಕುರಿಯೀಟ್ಟೈ ನಮ್ಪಲಾಮ್ ಎನ್ರ ಉರುತಿಪ್ಪಾಟ್ಟೈ ಇತು ಅಳಿಕ್ಕಾತು. ಮೂಲಕ್ ಕುರಿಯೀಟು ಒರು ಕುರಿಪ್ಪಿಟ್ಟ ತನಿತ್ ತಿರವಿಯಾಲ್ ಒಪ್ಪಮಿಟಪ್ಪಟ್ಟತು ಎನ್ಪತೈ ಪೊತುತ್ ತಿರವಿ ಉಳ್ಕಟ್ಟಮೈಪ್ಪು ವಳಿಯಾಕ ಉರುತಿಸೆಯ್ಕಿರತು.
