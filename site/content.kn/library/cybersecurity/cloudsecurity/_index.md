ಈ ವಿಭಾಗವು ಕ್ಲೌಡ್‌ನ ಭದ್ರತೆ ಮತ್ತು ಕ್ಲೌಡ್‌ನಲ್ಲಿನ ಭದ್ರತೆಯನ್ನು ಒಳಗೊಂಡಿದೆ.

### ಕ್ಲೌಡ್‌ನ ಭದ್ರತೆ (ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಭದ್ರತೆ)
- ಕ್ಲೌಡ್ ಭದ್ರತಾ ಅವಲೋಕನ
- ಹಂಚಿಕೆಯ ಜವಾಬ್ದಾರಿ ಮಾದರಿ
- ಸೌಲಭ್ಯಗಳು ಮತ್ತು ಭೌತಿಕ ಭದ್ರತೆ
- ಹಾರ್ಡ್‌ವೇರ್ ಭದ್ರತೆ
- ವರ್ಚುವಲೈಸೇಶನ್ ಭದ್ರತೆ
- ಕ್ಲೌಡ್ ಕೋರ್ ಸಂಪರ್ಕ ಭದ್ರತೆ
- ಕ್ಲೌಡ್ ನಿರ್ವಹಣಾ ಪ್ಲೇನ್ ಮತ್ತು API ಭದ್ರತೆ
- ವ್ಯವಹಾರ ನಿರಂತರತೆ ಮತ್ತು ವಿಪತ್ತು ಮರುಪಡೆಯುವಿಕೆ

### ಕ್ಲೌಡ್‌ನಲ್ಲಿನ ಭದ್ರತೆ (ಸೇವಾ ಭದ್ರತೆ)
- ಕ್ಲೌಡ್ ಭದ್ರತೆಯ ಮೂಲಸ್ತಂಭಗಳು
- ಕ್ಲೌಡ್-ನೇಟಿವ್ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರೊಟೆಕ್ಷನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ (CNAPP)
    - ಕ್ಲೌಡ್ ವರ್ಕ್‌ಲೋಡ್ ಪ್ರೊಟೆಕ್ಷನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ (CWPP)
    - ಕ್ಲೌಡ್ ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CSPM)
    - SaaS ಸೆಕ್ಯುರಿಟಿ ಪೋಸ್ಚರ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (SSPM)
- ಸುರಕ್ಷಿತ ಪ್ರವೇಶ ಸೇವಾ ಅಂಚು (SASE)
    - ಸುರಕ್ಷಿತ ವೆಬ್ ಗೇಟ್‌ವೇ (SWG)
    - ಕ್ಲೌಡ್ ಆಕ್ಸೆಸ್ ಸೆಕ್ಯುರಿಟಿ ಬ್ರೋಕರ್ (CASB)
    - ಝೀರೋ ಟ್ರಸ್ಟ್ ನೆಟ್‌ವರ್ಕ್ ಆಕ್ಸೆಸ್ (ZTNA)
- ಕ್ಲೌಡ್ ಗುರುತು
- ಕ್ಲೌಡ್ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಎಂಟೈಟಲ್‌ಮೆಂಟ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CIEM)
- ಕ್ಲೌಡ್ ಡೇಟಾ ಭದ್ರತೆ
