# ಕ್ಲೌಡ್ ಭದ್ರತೆ

ಈ ವಿಭಾಗವು ಕ್ಲೌಡ್ ಭದ್ರತಾ ಮಾದರಿ, ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ರಕ್ಷಣೆಗಳು, ಗುರುತು ನಿಯಂತ್ರಣಗಳು, ಡೇಟಾ ರಕ್ಷಣೆ ಮತ್ತು ಆಧುನಿಕ ಝೀರೋ ಟ್ರಸ್ಟ್ ಹಾಗೂ SASE ಆಧಾರಿತ ಭದ್ರತಾ ಮಾದರಿಗಳನ್ನು ಒಳಗೊಂಡಿದೆ.

- ಕ್ಲೌಡ್ ಭದ್ರತಾ ಅವಲೋಕನ
- ಹಂಚಿಕೆಯ ಜವಾಬ್ದಾರಿ ಮಾದರಿ
- ಭೌತಿಕ ಮತ್ತು ಹಾರ್ಡ್‌ವೇರ್ ಭದ್ರತೆ
- ವರ್ಚುವಲೈಸೇಶನ್ ರಕ್ಷಣೆ
- ಕ್ಲೌಡ್ ಗುರುತು ಮತ್ತು ಅರ್ಹತಾ ನಿರ್ವಹಣೆ
- ಡೇಟಾ ಭದ್ರತೆ ಮತ್ತು ಎನ್‌ಕ್ರಿಪ್ಶನ್
- SASE, SWG, CASB ಮತ್ತು ZTNA
- ಸಾರ್ವಜನಿಕ ಕ್ಲೌಡ್ ನೆಟಿವ್ ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳು
