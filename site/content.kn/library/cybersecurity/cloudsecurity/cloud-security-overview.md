### ಕ್ಲೌಡ್ ಭದ್ರತಾ ಅವಲೋಕನ

ಕ್ಲೌಡ್ ಭದ್ರತೆಯು ಕ್ಲೌಡ್ ಆಧಾರಿತ ವ್ಯವಸ್ಥೆಗಳು, ಡೇಟಾ, ಅಪ್ಲಿಕೇಶನ್‌ಗಳು, ಗುರುತುಗಳು ಮತ್ತು ವರ್ಕ್‌ಲೋಡ್‌ಗಳನ್ನು ಬೆದರಿಕೆಗಳು ಹಾಗೂ ದುರುಪಯೋಗದಿಂದ ರಕ್ಷಿಸುವುದಾಗಿದೆ.

ಕ್ಲೌಡ್ ಪೂರೈಕೆದಾರರು ದೊಡ್ಡ ಖಾಸಗಿ ನೆಟ್‌ವರ್ಕ್‌ಗಳು, ಸಮರ್ಪಿತ ಬ್ಯಾಕ್‌ಬೋನ್ ಸಂಪರ್ಕ ಮತ್ತು ದೊಡ್ಡ ಪ್ರಮಾಣದ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಅನ್ನು ನಿರ್ವಹಿಸುತ್ತಾರೆ. ಆದರೂ ಭದ್ರತೆಯನ್ನು ಪದರಗಳಲ್ಲಿ ವಿನ್ಯಾಸಗೊಳಿಸಬೇಕು. ಸಂಸ್ಥೆಗಳು ಪೂರೈಕೆದಾರರ ಪರಿಸರವನ್ನು ಮಾತ್ರವಲ್ಲದೆ ತಮ್ಮ ವರ್ಕ್‌ಲೋಡ್‌ಗಳು, ಗುರುತುಗಳು, ಅಪ್ಲಿಕೇಶನ್‌ಗಳು ಮತ್ತು ಡೇಟಾವನ್ನೂ ರಕ್ಷಿಸಬೇಕು.

### ಪ್ರಮುಖ ಭದ್ರತಾ ಕ್ಷೇತ್ರಗಳು

- ಭೌತಿಕ ಮೂಲಸೌಕರ್ಯ ಭದ್ರತೆ
- ವರ್ಚುವಲೈಸೇಶನ್ ಮತ್ತು ಹೈಪರ್‌ವೈಸರ್ ಭದ್ರತೆ
- ನೆಟ್‌ವರ್ಕ್ ಭದ್ರತೆ
- ಗುರುತು ಮತ್ತು ಪ್ರವೇಶ ನಿಯಂತ್ರಣ
- ಡೇಟಾ ರಕ್ಷಣೆ ಮತ್ತು ಎನ್‌ಕ್ರಿಪ್ಶನ್
- ಅನುಸರಣೆ ಮತ್ತು ಆಡಳಿತ
- ಬೆದರಿಕೆ ಪತ್ತೆ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆ

### ಕ್ಲೌಡ್‌ನ ಭದ್ರತೆ ಮತ್ತು ಕ್ಲೌಡ್‌ನಲ್ಲಿನ ಭದ್ರತೆ

ಕ್ಲೌಡ್ ಭದ್ರತೆಯನ್ನು ಪರಸ್ಪರ ಪೂರಕವಾದ ಎರಡು ದೃಷ್ಟಿಕೋನಗಳಿಂದ ನೋಡಲಾಗುತ್ತದೆ.

#### ಕ್ಲೌಡ್‌ನ ಭದ್ರತೆ (ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಭದ್ರತೆ)
ಮೂಲ ವೇದಿಕೆಯನ್ನು ರಕ್ಷಿಸಲು ಮುಖ್ಯವಾಗಿ ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರು ನಿರ್ವಹಿಸುವ ನಿಯಂತ್ರಣಗಳು:
- ಹಂಚಿಕೆಯ ಜವಾಬ್ದಾರಿ ಮಾದರಿ
- ಸೌಲಭ್ಯಗಳು ಮತ್ತು ಭೌತಿಕ ಭದ್ರತೆ
- ಹಾರ್ಡ್‌ವೇರ್ ಭದ್ರತೆ
- ವರ್ಚುವಲೈಸೇಶನ್ ಭದ್ರತೆ
- ಕ್ಲೌಡ್ ಕೋರ್ ಸಂಪರ್ಕ ಭದ್ರತೆ
- ಕ್ಲೌಡ್ ನಿರ್ವಹಣಾ ಪ್ಲೇನ್ ಮತ್ತು API ಭದ್ರತೆ
- ವ್ಯವಹಾರ ನಿರಂತರತೆ ಮತ್ತು ವಿಪತ್ತು ಮರುಪಡೆಯುವಿಕೆ

#### ಕ್ಲೌಡ್‌ನಲ್ಲಿನ ಭದ್ರತೆ (ಸೇವಾ ಭದ್ರತೆ)
ವೇದಿಕೆಯಲ್ಲಿ ತಾವು ನಿರ್ಮಿಸಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವುದನ್ನು ರಕ್ಷಿಸಲು ಗ್ರಾಹಕರು ಅನ್ವಯಿಸುವ ನಿಯಂತ್ರಣಗಳು:
- ಕ್ಲೌಡ್ ಭದ್ರತೆಯ ಮೂಲಸ್ತಂಭಗಳು
- ಕ್ಲೌಡ್-ನೇಟಿವ್ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರೊಟೆಕ್ಷನ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ (CNAPP), ಇದರಲ್ಲಿ CWPP, CSPM ಮತ್ತು SSPM ಸೇರಿವೆ
- ಸುರಕ್ಷಿತ ಪ್ರವೇಶ ಸೇವಾ ಅಂಚು (SASE), ಇದರಲ್ಲಿ SWG, CASB ಮತ್ತು ZTNA ಸೇರಿವೆ
- ಕ್ಲೌಡ್ ಗುರುತು ಮತ್ತು ಕ್ಲೌಡ್ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಎಂಟೈಟಲ್‌ಮೆಂಟ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ (CIEM)
- ಕ್ಲೌಡ್ ಡೇಟಾ ಭದ್ರತೆ
