### ನೆಟಿವ್ ಕ್ಲೌಡ್ ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳು

ಸಾರ್ವಜನಿಕ ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರು ವರ್ಕ್‌ಲೋಡ್‌ಗಳು, ಗುರುತುಗಳು, ನೆಟ್‌ವರ್ಕ್‌ಗಳು ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಸುರಕ್ಷಿತಗೊಳಿಸಲು ಸಹಾಯ ಮಾಡುವ ವಿವಿಧ ನೆಟಿವ್ ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳನ್ನು ಒದಗಿಸುತ್ತಾರೆ.

### ಉದಾಹರಣೆಗಳು

#### AWS
- IAM and SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS and HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM and Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### ಉದ್ದೇಶ

ಈ ನೆಟಿವ್ ನಿಯಂತ್ರಣಗಳು ಪೂರೈಕೆದಾರರ ಅಂತರ್ನಿರ್ಮಿತ ಸಾಮರ್ಥ್ಯಗಳು ಮತ್ತು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್-ನೆಟಿವ್ ಮೇಲ್ವಿಚಾರಣೆ, ಗುರುತು, ಎನ್‌ಕ್ರಿಪ್ಶನ್ ಹಾಗೂ ಅನುಸರಣೆ ನಿಯಂತ್ರಣಗಳ ಮೂಲಕ ಸಂಸ್ಥೆಗಳು ತಮ್ಮ ಕ್ಲೌಡ್ ಕಾರ್ಯಾಚರಣೆಗಳನ್ನು ಸುರಕ್ಷಿತಗೊಳಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತವೆ.
