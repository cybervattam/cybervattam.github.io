### ಕ್ಲೌಡ್ ಭದ್ರತೆಯ ಹಂಚಿಕೆಯ ಜವಾಬ್ದಾರಿ ಮಾದರಿ

ಕ್ಲೌಡ್ ಭದ್ರತಾ ಮಾದರಿಯನ್ನು ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರ ಮತ್ತು ಗ್ರಾಹಕರ ನಡುವೆ ಹಂಚಿಕೊಳ್ಳಲಾಗುತ್ತದೆ.

ಭೌತಿಕ ಸೌಲಭ್ಯಗಳು, ನೆಟ್‌ವರ್ಕ್ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್, ವರ್ಚುವಲೈಸೇಶನ್ ಪದರಗಳು ಮತ್ತು ಕೆಲವು ಪ್ರಮುಖ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ನಿಯಂತ್ರಣಗಳನ್ನು ಒಳಗೊಂಡಂತೆ ಗ್ರಾಹಕರ ವರ್ಕ್‌ಲೋಡ್‌ನ ಕೆಳಗಿರುವ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ ಅನ್ನು ಸುರಕ್ಷಿತಗೊಳಿಸುವುದು ಪೂರೈಕೆದಾರರ ಜವಾಬ್ದಾರಿಯಾಗಿದೆ. ಗುರುತು ಮತ್ತು ಪ್ರವೇಶ, ಅಪ್ಲಿಕೇಶನ್ ಭದ್ರತೆ, ಡೇಟಾ ರಕ್ಷಣೆ, ಕಾನ್ಫಿಗರೇಶನ್ ಸ್ವಚ್ಛತೆ ಮತ್ತು ಆಡಳಿತ ಸೇರಿದಂತೆ ಕ್ಲೌಡ್‌ನಲ್ಲಿನ ಭದ್ರತೆ ಗ್ರಾಹಕರ ಜವಾಬ್ದಾರಿಯಾಗಿದೆ.

### ಹಂಚಿಕೆಯ ಜವಾಬ್ದಾರಿಗಳ ಉದಾಹರಣೆಗಳು

| ಪದರ | ಪೂರೈಕೆದಾರರ ಜವಾಬ್ದಾರಿ | ಗ್ರಾಹಕರ ಜವಾಬ್ದಾರಿ |
|---|---|---|
| ಭೌತಿಕ ಭದ್ರತೆ | ಡೇಟಾ ಸೆಂಟರ್ ಭದ್ರತೆ | ಯಾವುದೂ ಇಲ್ಲ |
| ನೆಟ್‌ವರ್ಕ್ | ಪ್ರಮುಖ ನೆಟ್‌ವರ್ಕ್ ಮತ್ತು ಸಂಪರ್ಕ | ಭದ್ರತಾ ಗುಂಪುಗಳು, ರೂಟಿಂಗ್, ಫೈರ್‌ವಾಲ್ ಕಾನ್ಫಿಗರೇಶನ್ |
| ವರ್ಚುವಲೈಸೇಶನ್ | ಹೈಪರ್‌ವೈಸರ್ ಇನ್‌ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ | VM ಹಾರ್ಡನಿಂಗ್ ಮತ್ತು ವರ್ಕ್‌ಲೋಡ್ ರಕ್ಷಣೆ |
| ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಮ್ | ನಿರ್ವಹಿತ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಸೇವೆಗಳು | OS ಪ್ಯಾಚಿಂಗ್, ಪ್ರವೇಶ ನಿಯಂತ್ರಣ |
| ಅಪ್ಲಿಕೇಶನ್ | ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಸೇವೆಗಳು | ಅಪ್ಲಿಕೇಶನ್ ಲಾಜಿಕ್ ಮತ್ತು ಸುರಕ್ಷಿತ ಅಭಿವೃದ್ಧಿ |
| ಡೇಟಾ | ಸ್ಟೋರೇಜ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ರಕ್ಷಣೆ | ವರ್ಗೀಕರಣ, ಎನ್‌ಕ್ರಿಪ್ಶನ್, ಉಳಿಕೆ |
| ಗುರುತು ಮತ್ತು ಪ್ರವೇಶ | IAM ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ | ಬಳಕೆದಾರ ಪ್ರೊವಿಷನಿಂಗ್, ನೀತಿಗಳು, ಕನಿಷ್ಠ ಸವಲತ್ತು |

### ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳು

ಸಂಸ್ಥೆಗಳು ಗುರುತು, ಆಡಳಿತ, ಕಾನ್ಫಿಗರೇಶನ್, ಮೇಲ್ವಿಚಾರಣೆ ಮತ್ತು ಆಡಿಟಿಂಗ್ ಅಭ್ಯಾಸಗಳನ್ನು ಕ್ಲೌಡ್ ಪೂರೈಕೆದಾರರ ಮಾದರಿಯೊಂದಿಗೆ ಹೊಂದಿಸಬೇಕು ಎಂದು ಈ ಮಾದರಿ ಅಗತ್ಯಪಡಿಸುತ್ತದೆ.
