### ಕ್ಲೌಡ್ ಆಕ್ಸೆಸ್ ಸೆಕ್ಯುರಿಟಿ ಬ್ರೋಕರ್ (CASB)

Gartner ಪ್ರಕಾರ, ಕ್ಲೌಡ್ ಆಕ್ಸೆಸ್ ಸೆಕ್ಯುರಿಟಿ ಬ್ರೋಕರ್ ಎನ್ನುವುದು ಕ್ಲೌಡ್ ಸೇವಾ ಗ್ರಾಹಕರು ಮತ್ತು ಕ್ಲೌಡ್ ಸೇವಾ ಪೂರೈಕೆದಾರರ ನಡುವೆ ಇರಿಸಲಾದ ಭದ್ರತಾ ನೀತಿ ಜಾರಿ ಬಿಂದುವಾಗಿದೆ.

CASBಗಳು ಎಂಟರ್‌ಪ್ರೈಸ್ ಭದ್ರತಾ ನೀತಿಗಳನ್ನು ಒಟ್ಟುಗೂಡಿಸಿ, ಕ್ಲೌಡ್ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಪ್ರವೇಶಿಸುವಾಗ ಅವುಗಳನ್ನು ಜಾರಿಗೊಳಿಸುತ್ತವೆ.

### ಸಾಮಾನ್ಯ CASB ವೈಶಿಷ್ಟ್ಯಗಳು

- ದೃಢೀಕರಣ ಮತ್ತು ಸಿಂಗಲ್ ಸೈನ್-ಆನ್
- ಅನುಮೋದನೆ ಮತ್ತು ಕ್ರೆಡೆನ್ಶಿಯಲ್ ಮ್ಯಾಪಿಂಗ್
- ಸಾಧನ ಪ್ರೊಫೈಲಿಂಗ್
- ಎನ್‌ಕ್ರಿಪ್ಶನ್ ಮತ್ತು ಟೋಕನೈಸೇಶನ್
- ಲಾಗಿಂಗ್ ಮತ್ತು ಎಚ್ಚರಿಕೆ
- ಮಾಲ್‌ವೇರ್ ಪತ್ತೆ ಮತ್ತು ತಡೆ
- ಡೇಟಾ ನಷ್ಟ ತಡೆ ಮತ್ತು ಚಟುವಟಿಕೆ ಮೇಲ್ವಿಚಾರಣೆ
- ಶ್ಯಾಡೋ IT ಪತ್ತೆ

### ವ್ಯಾಪ್ತಿ

CASBಗಳನ್ನು ಮುಖ್ಯವಾಗಿ ಕ್ಲೌಡ್‌ನಲ್ಲಿರುವ SaaS ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ರಕ್ಷಿಸಲು ಬಳಸಲಾಗುತ್ತದೆ. PaaS ಮತ್ತು IaaSಗೆ ಅವುಗಳ ಬೆಂಬಲ ಸಾಮಾನ್ಯವಾಗಿ ಹೆಚ್ಚು ಸೀಮಿತವಾಗಿರುತ್ತದೆ.

### ನಿಯೋಜನೆ ವಿಧಾನಗಳು

- ಪ್ರಾಕ್ಸಿ ವಿಧಾನ
- API ವಿಧಾನ

### ಬಳಕೆಯ ಸಂದರ್ಭಗಳು

- ಶ್ಯಾಡೋ IT ಪತ್ತೆ ಮತ್ತು ಆಡಳಿತ
- ಡೇಟಾ ಹೊರತೆಗೆತ ತಡೆ
- ಬೆದರಿಕೆ ಪತ್ತೆ ಮತ್ತು ಫೊರೆನ್ಸಿಕ್ ತನಿಖೆ
- ಅನುಸರಣೆ ಬೆಂಬಲ ಮತ್ತು ಚಟುವಟಿಕೆ ಮೇಲ್ವಿಚಾರಣೆ
