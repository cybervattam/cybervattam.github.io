### DNS ವಿಧಗಳು / DNS Types

#### ಆಂತರಿಕ DNS / Internal DNS
ಸಂಸ್ಥೆಯ ಖಾಸಗಿ ನೆಟ್‌ವರ್ಕ್‌ನಲ್ಲಿರುವ ಸರ್ವರ್‌ಗಳು ಮತ್ತು ಅವುಗಳ IP ವಿಳಾಸಗಳ ನಡುವಿನ ಸಂಬಂಧವನ್ನು ನಿರ್ವಹಿಸುವ ಆಂತರಿಕ DNS ವ್ಯವಸ್ಥೆ.

#### ಬಾಹ್ಯ DNS / External DNS
ಇಂಟರ್ನೆಟ್ ಅಥವಾ ಸಾರ್ವಜನಿಕ ನೆಟ್‌ವರ್ಕ್ ಮೂಲಕ ಸಂಪರ್ಕಿಸಬಹುದಾದ ಸರ್ವರ್‌ಗಳು ಮತ್ತು ಅವುಗಳ IP ವಿಳಾಸಗಳ ನಡುವಿನ ಸಂಬಂಧವನ್ನು ನಿರ್ವಹಿಸುವ ಬಾಹ್ಯ DNS ವ್ಯವಸ್ಥೆ.

#### ರಿವರ್ಸ್ DNS / Reverse DNS
ಇದು ಒಂದು ರಿವರ್ಸ್ ಪ್ರಶ್ನೆಯಾಗಿದೆ. ನಿರ್ದಿಷ್ಟ IP ವಿಳಾಸವನ್ನು ಹೊಂದಿರುವ ಸರ್ವರ್‌ನ ಹೆಸರನ್ನು ಇದು ನೀಡುತ್ತದೆ. DNS ನಲ್ಲಿ, ಒಂದು ಡೊಮೇನ್‌ನ PTR ದಾಖಲೆಯು ಆ ಡೊಮೇನ್‌ನ ಸರ್ವರ್ IP ವಿಳಾಸವನ್ನು ಹಿಮ್ಮುಖವಾಗಿ ಬದಲಿಸಿ arpa ರೂಪದಲ್ಲಿ ಸಂಗ್ರಹಿಸುತ್ತದೆ. ರಿವರ್ಸ್ ಪ್ರಶ್ನೆಯ ಸಂದರ್ಭದಲ್ಲಿ ಈ ಮೌಲ್ಯವನ್ನು ಉತ್ತರವಾಗಿ ನೀಡಲಾಗುತ್ತದೆ. ಭದ್ರತಾ ಘಟನೆಗಳನ್ನು ದಾಖಲಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್ ಮತ್ತು ಇಮೇಲ್ ಗೇಟ್‌ವೇಗಳು ಈ ವಿಧಾನವನ್ನು ಬಳಸುತ್ತವೆ.

#### ಡೈನಾಮಿಕ್ DNS / Dynamic DNS
ಡೊಮೇನ್‌ನ IP ವಿಳಾಸ ಸ್ಥಿರವಾಗಿರದೆ ಆಗಾಗ ಬದಲಾಗುವ ಪರಿಸ್ಥಿತಿಯಲ್ಲಿ, ಆ IP ವಿಳಾಸವನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನವೀಕರಿಸಲು ಡೈನಾಮಿಕ್ DNS ಬಳಸಲಾಗುತ್ತದೆ. Microsoft Active Directory ಯಲ್ಲಿ ಇದು ಪ್ರಮುಖ ಘಟಕವಾಗಿದೆ. ಡೊಮೇನ್ ನಿರ್ವಾಹಕರು ಆ ಡೊಮೇನ್‌ನಲ್ಲಿ ಲಭ್ಯವಿರುವ ಸೇವೆಗಳನ್ನು DNS ನಲ್ಲಿ ದಾಖಲಿಸುತ್ತಾರೆ. ಇತರ ಕಂಪ್ಯೂಟರ್‌ಗಳು ಈ ದಾಖಲೆಗಳನ್ನು ಬಳಸುತ್ತವೆ.
