#### ಅಜ್ಞಾತ DNS / Oblivious DNS (ODoH)

ಮರಕ್ಕುಮ್ ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ಎನ್ಪತು IETF-ಆಲ್ ಉರುವಾಕ್ಕಪ್ಪಟ್ಟು ವರುಮ್ ಒರು ವಳರ್ನ್ತು ವರುಮ್ ನೆರಿಮುರೈ ಆಕುಮ್. ಇತು ಪೊತುತ್ ತಿರವಿ ಮರೈಪ್ಪಿಯಲ್, ಪಿಣೈಯ ಪತಿಲಿ, ಇಲಕ್ಕು ತೀರ್ವಿ ಆಕಿಯವರ್ರೈ ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ವಿನವಲ್ ತೀರ್ವು ಮುರೈಯಿಲ್ ಸೇರ್ಕ್ಕಿರತು. ಇತು ಪಯನರ್ಕಳುಕ್ಕುಮ್ ಸುಳಲ್ನಿಲೈ ತೀರ್ವಿಕಳುಕ್ಕು ಇಟೈಯಿಲ್ ಒರು ಪಾತುಕಾಪ್ಪು ಅರಣಾಕ ಸೆಯಲ್ಪಟುಕಿರತು. ಒರು ಪಯನರ್ ಅವರವರ್ ವಿರುಪ್ಪಪ್ಪಟಿ ಒರು ಪತಿಲಿ ಮರ್ರುಮ್ ಇಲಕ್ಕೈ ತೇರ್ವು ಸೆಯ್ಯಲಾಮ್. ಇನ್ತ ಇರಣ್ಟು ಕೂರುಕಳ್ ಸೇರ್ಕ್ಕಪ್ಪಟುವತಾಲ್, ಎಪ್ಪೋತುಮ್ ಪಯನರ್ ಮಟ್ಟುಮೇ ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ವಿನವಲ್ ತೀರ್ವು ಮರ್ರುಮ್ ಅವರ್ ಸೊನ್ತ ಇ.ನೆರಿ ಮುಕವರಿ ಇರಣ್ಟೈಯುಮ್ ಕಾಣ ಮುಟಿಯುಮ್ ಎನ್ರು ಉತ್ತರವಾತಮ್ ಅಳಿಕ್ಕಿರತು. ಇನ್ತ ನೆರಿಮುರೈಯಿನ್ ನೋಕ್ಕಮ್ ಇರುತಿ ಪಯನರ್ ತನಿಯುರಿಮೈಯೈಪ್ ಪಾತುಕಾಪ್ಪತು, ಇಣೈಯ ಸೇವೈ ವಳಙ್ಕುನರ್ಕಳ್ ಅಲ್ಲತು ಕಳಪ್ಪೆಯರ್ ಮುರೈಮೈ ವಿನವಲ್ ತೀರ್ಪ್ಪಾಳರ್ಕಳ್ ಅವರ್ಕಳಿನ್ ವಾಟಿಕ್ಕೈಯಾಳರ್ಕಳಾಲ್ ಕೋರಪ್ಪಟ್ಟ / ಪಾರ್ವೈಯಿಟಪ್ಪಟ್ಟ ವಲೈತ್ತಳತ್ತೈಪ್ ಕಾಣ ಮುಟಿಯುಮ್ ಎನ್ಪತೈತ್ ತಟುಪ್ಪತು.
ಅಜ್ಞಾತ DNS (ODoH) ಎಂಬುದು IETF ಅಭಿವೃದ್ಧಿಪಡಿಸುತ್ತಿರುವ ಪ್ರೋಟೋಕಾಲ್ ಆಗಿದೆ. ಇದು ಸಾರ್ವಜನಿಕ ಕೀಲಿ ಗೂಢಲಿಪಿಶಾಸ್ತ್ರ, ನೆಟ್‌ವರ್ಕ್ ಪ್ರಾಕ್ಸಿ ಮತ್ತು ಗುರಿ ರಿಸಾಲ್ವರ್‌ಗಳನ್ನು DNS ಪ್ರಶ್ನೆ ಪರಿಹಾರ ಪ್ರಕ್ರಿಯೆಯಲ್ಲಿ ಸಂಯೋಜಿಸುತ್ತದೆ. ಇದು ಬಳಕೆದಾರ ಮತ್ತು ರಿಕರ್ಸಿವ್ ರಿಸಾಲ್ವರ್ ನಡುವೆ ಭದ್ರತಾ ಗೋಡೆಯಂತೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಬಳಕೆದಾರರು ತಮ್ಮ ಇಚ್ಛೆಯಂತೆ ಪ್ರಾಕ್ಸಿ ಮತ್ತು ಗುರಿ ರಿಸಾಲ್ವರ್‌ಗಳನ್ನು ಆಯ್ಕೆ ಮಾಡಬಹುದು. ಈ ಎರಡು ಘಟಕಗಳನ್ನು ಬೇರ್ಪಡಿಸುವುದರಿಂದ ಬಳಕೆದಾರರು ಮಾಡಿದ DNS ಪ್ರಶ್ನೆ ಮತ್ತು ಅವರ ಸ್ವಂತ IP ವಿಳಾಸ ಎರಡನ್ನೂ ಒಂದೇ ವೇಳೆ ಯಾರೂ ನೋಡಲು ಸಾಧ್ಯವಾಗುವುದಿಲ್ಲ. ಅಂತಿಮ ಬಳಕೆದಾರರ ಗೌಪ್ಯತೆಯನ್ನು ರಕ್ಷಿಸುವುದು ಮತ್ತು ಸೇವಾ ಪೂರೈಕೆದಾರರು ಅಥವಾ DNS ರಿಸಾಲ್ವರ್‌ಗಳು ಗ್ರಾಹಕರು ಕೇಳಿದ ಅಥವಾ ವೀಕ್ಷಿಸಿದ ವೆಬ್‌ಸೈಟ್‌ಗಳನ್ನು ತಿಳಿಯದಂತೆ ತಡೆಯುವುದು ಇದರ ಉದ್ದೇಶವಾಗಿದೆ.
