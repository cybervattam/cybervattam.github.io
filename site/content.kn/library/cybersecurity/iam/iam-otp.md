### __ಓರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ / One time password (OTP)__
ಕುರುಕ್ಕ ತೀರ್ವುನೆರಿಕಳ್ ಒರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ಲೈ ಉರುವಾಕ್ಕ ಪಯನ್ಪಟುತ್ತಪ್ಪಟುಕಿನ್ರನ. ಇತರ್ಕು ತೀರ್ವುನೆರಿಕಳ್ ಇರಣ್ಟು ಉಳ್ಳೀಟುಕಳೈಪ್ ಪಯನ್ಪಟುತ್ತುಕಿನ್ರನ: ವಿತೈ ಮರ್ರುಮ್ ನಕರುಮ್ ಕಾರಣಿ.

ವಿತೈ ಎನ್ಪತು ಒರು ನಿಲೈಯಾನ ಮತಿಪ್ಪು (ಇರಕಸಿಯತ್ ತಿರವಿ). ಇನ್ತ ಇರಕಸಿಯತ್ ತಿರವಿ ನೀಙ್ಕಳ್ ಸಾನ್ರುರುತಿ ಸೇವೈಯಕತ್ತಿಲ್ ಪುತಿಯ ಕಣಕ್ಕೈ ನಿರುವುಮ್ ಪೋತು ಉರುವಾಕ್ಕಪ್ಪಟುಮ್. ನಕರುಮ್ ಕಾರಣಿಯಿನ್ ಅಟಿಪ್ಪಟೈಯಿಲ್, HOTP & TOTP ಎನ ಇರಣ್ಟು ವಕೈಯಾನ ಒರು ಮುರೈ ಕಟವುಸ್ಸೊರ್ಕಳ್ ಕಿಟೈಕ್ಕಿನ್ರನ.

#### __HOTP__

Hash-based Message Authentication Code OTP (HOTP) ಎನುಮ್ ಕುರುಕ್ಕಮ್ ಸಾರ್ನ್ತ ಸೆಯ್ತಿ ನಮ್ಪತ್ತಕುಮೈಕ್ ಕುರಿಯೀಟ್ಟು ಒರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ಲೈ ಕುರಿಕ್ಕಿರತು.
 
HOTP ತೀರ್ವುನೆರಿ ಒರು ನಿಕಳ್ವೈ ಅಟಿಪ್ಪಟೈಯಾಕ ಕೊಣ್ಟತು. ಒರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ಲೈ ಉರುವಾಕ್ಕ ನಕರುಮ್ ಕಾರಣಿಯಾಕ ಒರು ಎಣ್ಣಿಯೈ (counter) ಪಯನ್ಪಟುತ್ತುಕಿರತು. ಇಙ್ಕೇ ನಿಕಳ್ವು ಎನ್ಪತು ಎಣ್ಣಿಯಿನ್ ಇಲಕ್ಕ ನಕರ್ವಾಕುಮ್.

ಅಟುತ್ತ ಒರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ಲೈ ನೀಙ್ಕಳ್ ಉರುವಾಕ್ಕುಮ್ ವರೈ ಮುನ್ನರ್ ಉರುವಾಕ್ಕಪ್ಪಟ್ಟ ಒರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ ಸೆಲ್ಲುಪಟಿಯಾಕುಮ್.

#### __TOTP__

(TOTP) ಎನ್ಪತು time-based OTP ಎನುಮ್ ನೇರಮ್ ಸಾರ್ನ್ತ ಒರು ಮುರೈ ಕಟವುಸ್ಸೊಲ್ಲೈ ಕುರಿಕ್ಕಿರತು. 

TOTP ತೀರ್ವುನೆರಿ ನಕರುಮ್ ಕಾರಣಿಯಾಕ ಎಣ್ಣಿಕ್ಕು ಪತಿಲಾಕ ನೇರತ್ತೈ ಅಟಿಪ್ಪಟೈಯಾಕಕ್ ಕೊಣ್ಟತು. 

ಒವ್ವೊರು ಕಟವುಸ್ಸೊಲ್ಲುಮ್ ಸೆಲ್ಲುಪಟಿಯಾಕುಮ್ ನೇರತ್ತಿನ್ ಅಳವು ಕಾಲಅಳವು (timestep) ಎನ್ರು ಅಳೈಕ್ಕಪ್ಪಟುಕಿರತು.
