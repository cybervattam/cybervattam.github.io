### ಇಂಟರ್ನೆಟ್ ಅಸೈನ್‌ಡ್ ನಂಬರ್ಸ್ ಅಥಾರಿಟಿ (Internet Assigned Numbers Authority)

<img src="images/shared/logos/iana-logo.svg" width=20%>

IANA ಜಾಗತಿಕ ಡೊಮೇನ್ ಹೆಸರುಗಳು, ಸಂಖ್ಯೆ ಸಂಪನ್ಮೂಲಗಳು ಮತ್ತು ಪ್ರೋಟೋಕಾಲ್ ನಿಯೋಜನೆಗಳನ್ನು ಮೇಲ್ವಿಚಾರಣೆ ಮಾಡುವ ಮಾನದಂಡ ಸಂಸ್ಥೆಯಾಗಿದೆ. ಹಿಂದೆ ಇದು ಅಮೆರಿಕ ಸರ್ಕಾರದ ಮೇಲ್ವಿಚಾರಣೆಯಲ್ಲಿತ್ತು. ಈಗ IANA ಅನ್ನು Internet Corporation for Assigned Names and Numbers (ICANN) ಎಂಬ ಅಂತರರಾಷ್ಟ್ರೀಯ, ಲಾಭರಹಿತ ಸಾರ್ವಜನಿಕ ಹಿತಾಸಕ್ತಿ ಸಂಸ್ಥೆ ನಿರ್ವಹಿಸುತ್ತದೆ.

#### 1. __ಡೊಮೇನ್ ಹೆಸರು ಸೇವೆಗಳು / Domain Name Service__

* __DNS ರೂಟ್ ವಲಯ ನಿರ್ವಹಣೆ ಮತ್ತು ಕೀಲಿ ಸಹಿ ಸಮಾರಂಭ__
  * DNS ಮರದ ಮೇಲ್ಭಾಗದಲ್ಲಿರುವ ರೂಟ್ ವಲಯದ ಡೇಟಾವನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ.
  * TLD ರಿಜಿಸ್ಟ್ರಾರ್‌ಗಳು, ರೂಟ್ ಸರ್ವರ್ ಸಂಸ್ಥೆಗಳು ಮತ್ತು ICANN ನೀತಿ ತಂಡದೊಂದಿಗೆ ಸಮನ್ವಯ ಮಾಡುತ್ತದೆ.
  * DNSSEC ಗಾಗಿ ಕೀಲಿ ಸಹಿ ಸಮಾರಂಭಗಳನ್ನು ನಡೆಸುತ್ತದೆ.
  * Anycast IP ವಿಳಾಸಗಳನ್ನು ಬಳಸುವ 13 ರೂಟ್ ಸರ್ವರ್ ವ್ಯವಸ್ಥೆಗಳಿವೆ.
  * ರೂಟ್ ಸರ್ವರ್ ನಿರ್ವಾಹಕರು ಪರಸ್ಪರ ಮತ್ತು ICANN ಜೊತೆಗೆ ಸಹಕರಿಸುತ್ತಾರೆ. https://root-servers.org/

* __ಉನ್ನತ ಮಟ್ಟದ ಡೊಮೇನ್‌ಗಳ ಡೇಟಾಬೇಸ್ / Database of Top Level Domains__
  * .com ನಂತಹ gTLD ಮತ್ತು .uk ನಂತಹ ccTLD ಸೇರಿದಂತೆ ಉನ್ನತ ಮಟ್ಟದ ವಲಯಗಳ ನಿಯೋಜನೆ ವಿವರಗಳನ್ನು ದಾಖಲಿಸುತ್ತದೆ.
  * ನಿಗದಿತ ನೀತಿಗಳು ಮತ್ತು ಪ್ರಕ್ರಿಯೆಗಳ ಪ್ರಕಾರ ಈ ನಿಯೋಜನೆಗಳನ್ನು ಸಂಯೋಜಿಸುವುದು IANA ಯ ಜವಾಬ್ದಾರಿಯಾಗಿದೆ.

* __.int ರಿಜಿಸ್ಟ್ರಿ__
  * .int TLD ಅನ್ನು ಅಂತರರಾಷ್ಟ್ರೀಯ ಸಂಸ್ಥೆಗಳು ಮತ್ತು ಅಂತರರಾಷ್ಟ್ರೀಯ ಒಪ್ಪಂದಗಳಿಗಾಗಿ ಬಳಸಲಾಗುತ್ತದೆ. ಉದಾಹರಣೆಗೆ, ವಿಶ್ವ ಆರೋಗ್ಯ ಸಂಸ್ಥೆ who.int ಡೊಮೇನ್ ಬಳಸುತ್ತದೆ.

* __.arpa ರಿಜಿಸ್ಟ್ರಿ__
  * .arpa ವಲಯವನ್ನು IP ವಿಳಾಸಗಳ ರಿವರ್ಸ್ ಮ್ಯಾಪಿಂಗ್ ಮತ್ತು ENUM ದೂರವಾಣಿ ಸಂಖ್ಯೆ ಮ್ಯಾಪಿಂಗ್‌ನಂತಹ ಇಂಟರ್ನೆಟ್ ಪ್ರೋಟೋಕಾಲ್ ಕಾರ್ಯಗಳಿಗೆ ಬಳಸಲಾಗುತ್ತದೆ.

#### 2. __ಸಂಖ್ಯೆ ಸಂಪನ್ಮೂಲಗಳು / Number Resources__

* ಇಂಟರ್ನೆಟ್ ಪ್ರೋಟೋಕಾಲ್ ವಿಳಾಸಗಳು (IP Addresses)
* ಸ್ವಾಯತ್ತ ವ್ಯವಸ್ಥೆ ಸಂಖ್ಯೆ (Autonomous System Number)

#### 3. __ಪ್ರೋಟೋಕಾಲ್ ನಿಯೋಜನೆಗಳು / Protocol Assignments__

* ವಿವಿಧ ಇಂಟರ್ನೆಟ್ ಪ್ರೋಟೋಕಾಲ್‌ಗಳ ಕೋಡ್‌ಗಳು ಮತ್ತು ಸಂಖ್ಯೆಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಜವಾಬ್ದಾರಿ IANA ಯದು. ಈ ಸೇವೆಯನ್ನು Internet Engineering Task Force (IETF) ಜೊತೆಗೆ ಒದಗಿಸಲಾಗುತ್ತದೆ.
* IANA ನಿರ್ವಹಿಸುವ ಪ್ರೋಟೋಕಾಲ್‌ಗಳ ಪಟ್ಟಿ https://www.iana.org/protocols ನಲ್ಲಿ ಲಭ್ಯವಿದೆ.
* ಪೋರ್ಟ್ ಸಂಖ್ಯೆಗಳ ಶ್ರೇಣಿಗಳು:
  * ಪ್ರಸಿದ್ಧ ಪೋರ್ಟ್ ಸಂಖ್ಯೆಗಳು (0 ರಿಂದ 1023)
  * ನೋಂದಾಯಿತ ಪೋರ್ಟ್ ಸಂಖ್ಯೆಗಳು (1024 ರಿಂದ 49151)
  * ಖಾಸಗಿ ಅಥವಾ ಡೈನಾಮಿಕ್ ಪೋರ್ಟ್ ಸಂಖ್ಯೆಗಳು (49152 ರಿಂದ 65535)

* __ಸಮಯ ವಲಯ ಡೇಟಾಬೇಸ್ / Time Zone Database__
  * tz ಅಥವಾ zoneinfo ಎಂದೂ ಕರೆಯಲಾಗುವ ಈ ಡೇಟಾಬೇಸ್ ವಿಶ್ವದ ವಿವಿಧ ಸ್ಥಳಗಳ ಸ್ಥಳೀಯ ಸಮಯದ ಇತಿಹಾಸವನ್ನು ದಾಖಲಿಸುತ್ತದೆ.
  * ಸಮಯ ವಲಯ ಗಡಿಗಳು, UTC ಆಫ್‌ಸೆಟ್‌ಗಳು ಅಥವಾ ಡೇಲೈಟ್ ಸೇವಿಂಗ್ ನಿಯಮಗಳು ಬದಲಾಗುವಾಗ ಇದನ್ನು ನವೀಕರಿಸಲಾಗುತ್ತದೆ.
  * ಅಧಿಕೃತ ಸಮಯ ವಲಯಗಳ ಪಟ್ಟಿ https://www.iana.org/time-zones ನಲ್ಲಿ ಲಭ್ಯವಿದೆ.
