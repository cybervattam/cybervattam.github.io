**ಸೈಬರ್‌ವಟ್ಟಂ (Cybervattam)** ಜಾಲತಾಣಕ್ಕೆ ಸ್ವಾಗತ — ಪ್ರತಿಯೊಬ್ಬರೂ ತಮ್ಮ ಮಾತೃಭಾಷೆಯಲ್ಲೇ ಮೂಲಭೂತ ತಾಂತ್ರಿಕ ಪರಿಕಲ್ಪನೆಗಳನ್ನು ಕಲಿಯಲು ಸಾಧ್ಯವಾಗುವಂತೆ, ಭಾರತೀಯ ಭಾಷೆಗಳಲ್ಲಿ ತಂತ್ರಜ್ಞಾನ ಮತ್ತು ಸೈಬರ್ ಸುರಕ್ಷತೆಯ ಜ್ಞಾನವನ್ನು ರಚಿಸಲು ಹಾಗೂ ಹಂಚಿಕೊಳ್ಳಲು ರೂಪಿಸಲಾದ ಮುಕ್ತ ಸಮುದಾಯದ ಉಪಕ್ರಮವಿದು.

ನಮ್ಮ ಗ್ರಂಥಾಲಯವು ಪ್ರಸ್ತುತ **ಇಂಗ್ಲಿಷ್, ತಮಿಳು, ಮಲಯಾಳಂ, ತೆಲುಗು, ಕನ್ನಡ ಮತ್ತು ಹಿಂದಿ** ಭಾಷೆಗಳಲ್ಲಿ ಲಭ್ಯವಿದ್ದು, ಇದನ್ನು ಇನ್ನಷ್ಟು ಭಾರತೀಯ ಭಾಷೆಗಳಿಗೆ ವಿಸ್ತರಿಸಲು ನಾವು ಸಕ್ರಿಯವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದ್ದೇವೆ.

### ಅನುವಾದ ಮತ್ತು ಸ್ಥಳೀಯೀಕರಣ ವಿಧಾನ

ಲೇಖನಗಳನ್ನು ಪ್ರಾಥಮಿಕವಾಗಿ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ರಚಿಸಿ, ಬೆಂಬಲಿತ ಭಾಷೆಗಳಿಗೆ ಅನುವಾದಿಸಲಾಗುತ್ತದೆ. **ಸೈಬರ್‌ವಟ್ಟಂ AI ಅನುವಾದ ಪರಿಕರಗಳ (AI translation tools) ಜೊತೆಗೆ ಸಮುದಾಯದ ಪರಿಶೀಲನೆಯನ್ನು (community review) ಬಳಸಿಕೊಳ್ಳುತ್ತದೆ.** ಸ್ವಯಂಚಾಲಿತ ಅನುವಾದವು ಕೆಲವೊಮ್ಮೆ ಸಂದರ್ಭ ಅಥವಾ ಸೂಕ್ಷ್ಮತೆಯನ್ನು ತಪ್ಪಿಸಬಹುದಾದ್ದರಿಂದ, ಮಾನವ ಪರಿಶೀಲನೆಯ ಮೂಲಕ ನಾವು ವಿಷಯವನ್ನು ನಿರಂತರವಾಗಿ ಸುಧಾರಿಸುತ್ತೇವೆ. ಎಲ್ಲಾದರೂ ಅಸಹಜ ಪದ ಅಥವಾ ವಾಕ್ಯ ಕಂಡುಬಂದಿದೆಯೇ? [GitHub ನಲ್ಲಿ ತಿದ್ದುಪಡಿಯನ್ನು ಸೂಚಿಸಿ](https://github.com/cybervattam/cybervattam.github.io/issues/new) ಅಥವಾ [ನಮ್ಮ ಭಾರತೀಯ ತಾಂತ್ರಿಕ ಪದಕೋಶವನ್ನು (Indic Tech Glossary) ಪರಿಶೀಲಿಸಿ](https://github.com/cybervattam/cybervattam.github.io).

### ನೀವು ಹೇಗೆ ಕೊಡುಗೆ ನೀಡಬಹುದು

ನೀವು ತಂತ್ರಜ್ಞರು, ಶಿಕ್ಷಕರು, ಅನುವಾದಕರು ಅಥವಾ ಮಾತೃಭಾಷಾ ಆಸಕ್ತರಾಗಿರಲಿ, ಪ್ರತಿಯೊಂದು ಭಾರತೀಯ ಭಾಷೆಯಲ್ಲೂ ತಾಂತ್ರಿಕ ಜ್ಞಾನವನ್ನು ತಲುಪಿಸಲು ಈ ಕೆಳಗಿನಂತೆ ನೆರವಾಗಬಹುದು:

- **ಅನುವಾದವನ್ನು ಸರಿಪಡಿಸಿ**: [GitHub Pull Request](https://github.com/cybervattam/cybervattam.github.io/pulls) ಸಲ್ಲಿಸಿ, [ತ್ವರಿತ ತಿದ್ದುಪಡಿಗಾಗಿ Issue ತೆರೆಯಿರಿ](https://github.com/cybervattam/cybervattam.github.io/issues/new), ಅಥವಾ ನಮ್ಮ [ನಮ್ಮನ್ನು ಸಂಪರ್ಕಿಸಿ](/kn/library/aboutus/contactus/contactus/) ಪುಟದ ಮೂಲಕ ನಿಮ್ಮ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಕಳುಹಿಸಿ.
- **ಹೊಸ ಲೇಖನವನ್ನು ಬರೆಯಿರಿ**: [ಸೈಬರ್‌ವಟ್ಟಂ GitHub ರೆಪೊಸಿಟರಿ](https://github.com/cybervattam/cybervattam.github.io) ಮೂಲಕ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲಿ ಅಥವಾ ನೇರವಾಗಿ ನಿಮ್ಮ ಮಾತೃಭಾಷೆಯ ಲಿಪಿಯಲ್ಲಿ ಹೊಸ ಕೈಪಿಡಿ ಅಥವಾ ಪಾಠವನ್ನು ರಚಿಸಿ.
