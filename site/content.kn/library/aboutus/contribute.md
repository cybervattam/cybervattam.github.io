### ಸೈಬರ್ವತ್ತಂ ಕೊಡುಗೆದಾರರ ಕೈಪಿಡಿಗೆ ಸ್ವಾಗತ

**ಸೈಬರ್ವತ್ತಂ (Cybervattam)** ಎಂಬುದು ಸೈಬರ್ ಸುರಕ್ಷತೆ, ಇಂಟರ್ನೆಟ್ ಜಾಗೃತಿ ಮತ್ತು ಉದಯೋನ್ಮುಖ ತಂತ್ರಜ್ಞಾನದ ಜ್ಞಾನವನ್ನು ಭಾರತೀಯ ಭಾಷೆಗಳಲ್ಲಿ ಎಲ್ಲರಿಗೂ ತಲುಪಿಸಲು ನಿರ್ಮಿಸಲಾದ ಮುಕ್ತ ಸಮುದಾಯ ಗ್ರಂಥಾಲಯವಾಗಿದೆ. ನೀವು ಹೊಸ ಪಾಠವನ್ನು ಬರೆಯಲು, ಅನುವಾದವನ್ನು ಸುಧಾರಿಸಲು ಅಥವಾ ಉತ್ತಮ ಕನ್ನಡ ತಾಂತ್ರಿಕ ಪದಗಳನ್ನು ಸೂಚಿಸಲು ಬಯಸಿದರೆ ಈ ಮಾರ್ಗದರ್ಶಿ ನಿಮಗೆ ಸಹಾಯ ಮಾಡುತ್ತದೆ.

---

### 1. ನೀವು ಹೇಗೆ ಕೊಡುಗೆ ನೀಡಬಹುದು?

1. **ಅನುವಾದಗಳನ್ನು ಪರಿಶೀಲಿಸಿ ಮತ್ತು ತಿದ್ದಿರಿ**: ಕನ್ನಡ, ತಮಿಳು, ಹಿಂದಿ, ಮಲಯಾಳಂ ಅಥವಾ ತೆಲುಗು ಲೇಖನಗಳಲ್ಲಿ ಕಾಗುಣಿತ ದೋಷಗಳು ಅಥವಾ ಅಸಹಜ ಅನುವಾದಗಳು ಕಂಡುಬಂದರೆ GitHub ಮೂಲಕ ತಿದ್ದುಪಡಿಗಳನ್ನು ಸೂಚಿಸಿ.
2. **ಇರುವ ಪಾಠವನ್ನು ಅನುವಾದಿಸಿ**: `site/content.en/` ಫೋಲ್ಡರ್‌ನಿಂದ ಯಾವುದೇ ಇಂಗ್ಲಿಷ್ ಲೇಖನವನ್ನು ಆರಿಸಿ ನಿಮ್ಮ ಮಾತೃಭಾಷೆಗೆ ಅನುವಾದಿಸಿ.
3. **ಹೊಸ ಪಾಠ ಅಥವಾ ರೇಖಾಚಿತ್ರವನ್ನು ರಚಿಸಿ**: ಸೈಬರ್ ಸುರಕ್ಷತೆ ಅಥವಾ ಹೊಸ ತಂತ್ರಜ್ಞಾನದ ಕುರಿತು ಮಾರ್ಗದರ್ಶಿ ಬರೆಯಿರಿ ಅಥವಾ ಭಾರತೀಯ ಭಾಷೆಗಳಲ್ಲಿ SVG ಚಿತ್ರಗಳನ್ನು ರಚಿಸಿ.
4. **"ವಾರದ ತಾಂತ್ರಿಕ ಪದ" ಸೂಚಿಸಿ**: `site/static/data/terms-of-the-week.json` ಫೈಲ್‌ನಲ್ಲಿ ಸೂಕ್ತ ತಾಂತ್ರಿಕ ಪದಗಳು ಮತ್ತು ನೈಜ ಜೀವನದ ಉದಾಹರಣೆಗಳನ್ನು ಸೇರಿಸಿ.

### 2. ರೆಪೊಸಿಟರಿ ಮತ್ತು ವಿಷಯ ಡೈರೆಕ್ಟರಿ ರಚನೆ (Directory Structure)

ಎಲ್ಲಾ ಪಾಠಗಳನ್ನು **Markdown (`.md`)** ಸ್ವರೂಪದಲ್ಲಿ `site/` ಡೈರೆಕ್ಟರಿಯೊಳಗೆ ಭಾಷಾವಾರು ಜೋಡಿಸಲಾಗಿದೆ. ಪ್ರತಿಯೊಂದು ಭಾಷಾ ಫೋಲ್ಡರ್ `content.en/` ನಲ್ಲಿರುವ ಅದೇ ಫೈಲ್ ಹೆಸರುಗಳು ಮತ್ತು ಮಾರ್ಗಗಳನ್ನು ಹೊಂದಿರುವುದರಿಂದ Hugo ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅನುವಾದಗಳನ್ನು ಜೋಡಿಸುತ್ತದೆ:

```text
cybervattam.github.io/
└── site/
    ├── content.en/                  # ಇಂಗ್ಲಿಷ್ (ಮೂಲ ವಿಷಯ)
    │   ├── _index.md                # ಮುಖಪುಟ ಪರಿಚಯ
    │   ├── events/                  # ಸಮುದಾಯ ಕಾರ್ಯಕ್ರಮಗಳು ಮತ್ತು ಕಾರ್ಯಾಗಾರಗಳು
    │   └── library/                 # ಮುಖ್ಯ ಜ್ಞಾನ ಗ್ರಂಥಾಲಯ
    │       ├── cyberawareness/      # ವಿಭಾಗ 1: ಸೈಬರ್ ಜಾಗೃತಿ
    │       │   ├── cyberhygine/     #   ಸಾಧನ, ಪಾಸ್‌ವರ್ಡ್ ಮತ್ತು ಇಂಟರ್ನೆಟ್ ಸುರಕ್ಷತೆ
    │       │   ├── familysafety/    #   ವಯೋಮಾನದ ಪ್ರಕಾರ ಕುಟುಂಬ ಸುರಕ್ಷತೆ
    │       │   └── topscamsfrauds/  #   ಫಿಶಿಂಗ್, OTP, UPI ಮತ್ತು AI ವಂಚನೆಗಳು
    │       ├── cybersecurity/       # ವಿಭಾಗ 2: ಸೈಬರ್ ಸುರಕ್ಷತೆ
    │       │   ├── cloudsecurity/   #   ಕ್ಲೌಡ್ ಸುರಕ್ಷತೆ, CSPM, CNAPP, ZTNA
    │       │   ├── cryptography/    #   ಗೂಢಲಿಪೀಕರಣ, ಹ್ಯಾಶಿಂಗ್ ಮತ್ತು ಡಿಜಿಟಲ್ ಸಹಿ
    │       │   ├── dns/             #   DNS ರಚನೆ, ದಾಖಲೆಗಳು, DNSSEC, DoH/DoT
    │       │   ├── iam/             #   ಗುರುತು ಮತ್ತು ಪ್ರವೇಶ ನಿರ್ವಹಣೆ (IAM, MFA)
    │       │   ├── icann-iana/      #   ಇಂಟರ್ನೆಟ್ ಆಡಳಿತ (ICANN & IANA)
    │       │   ├── pki/             #   ಪಬ್ಲಿಕ್ ಕೀ ಇನ್ಫ್ರಾಸ್ಟ್ರಕ್ಚರ್ (PKI) & TLS
    │       │   └── zerotrust/       #   ಶೂನ್ಯ ನಂಬಿಕೆ (Zero Trust) ತತ್ವಗಳು
    │       ├── emergingtech/        # ವಿಭಾಗ 3: ಉದಯೋನ್ಮುಖ ತಂತ್ರಜ್ಞಾನಗಳು
    │       │   ├── blockchain/      #   ಬ್ಲಾಕ್‌ಚೈನ್ ಮತ್ತು ಒಮ್ಮತದ ವಿಧಾನಗಳು
    │       │   ├── cloud/           #   ಕ್ಲೌಡ್ ಸೇವಾ ಮಾದರಿಗಳು
    │       │   ├── digitalassets/   #   ಕ್ರಿಪ್ಟೋ ವಾಲೆಟ್‌ಗಳು ಮತ್ತು ಡಿಜಿಟಲ್ ಆಸ್ತಿಗಳು
    │       │   └── ipv6/            #   IPv6 ವಿಳಾಸ ರಚನೆ
    │       └── aboutus/             # ನಮ್ಮ ಬಗ್ಗೆ, ಕೊಡುಗೆ ನೀಡಿ, ಕೊಡುಗೆದಾರರು, ನಮ್ಮ ತಂಡ
    │
    ├── content.ta/                  # ತಮಿಳು (தமிழ்)
    ├── content.hi/                  # ಹಿಂದಿ (हिन्दी)
    ├── content.ml/                  # ಮಲಯಾಳಂ (മലയാളം)
    ├── content.te/                  # ತೆಲುಗು (తెలుగు)
    ├── content.kn/                  # ಕನ್ನಡ — content.en/ ರಚನೆಯನ್ನು ಅನುಸರಿಸುತ್ತದೆ
    │
    ├── i18n/                        # UI ಅನುವಾದ ಫೈಲ್‌ಗಳು (en.toml, kn.toml, ಇತ್ಯಾದಿ)
    └── static/
        ├── data/
        │   └── terms-of-the-week.json  # ಮುಖಪುಟದ ತಾಂತ್ರಿಕ ಪದ ಜೋಡಿಗಳು
        └── images/                  # ರೇಖಾಚಿತ್ರಗಳು ಮತ್ತು ಚಿತ್ರಗಳು (en/, ta/, shared/)
```

```yaml
### ಗೂಢಲಿಪಿಶಾಸ್ತ್ರ ಪರಿಚಯ

ನಿಮ್ಮ ಪಾಠದ ವಿಷಯವನ್ನು ಸರಳ ಕನ್ನಡದಲ್ಲಿ ಇಲ್ಲಿ ಬರೆಯಿರಿ.
```

> **ಮುಖ್ಯ ನಿಯಮ**: ಫೈಲ್ ಹೆಸರನ್ನು (ಉದಾಹರಣೆಗೆ `cryptography-introduction.md`) ಎಲ್ಲಾ ಭಾಷಾ ಫೋಲ್ಡರ್‌ಗಳಲ್ಲಿ ಇಂಗ್ಲಿಷ್‌ನಲ್ಲೇ ಇರಿಸಿ. ಆಗ ಮಾತ್ರ ಭಾಷಾ ಬದಲಾವಣೆ (Language Switcher) ಸರಿಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

### 3. ತಾಂತ್ರಿಕ ಪದಗಳ ಅನುವಾದ ಮಾರ್ಗಸೂಚಿಗಳು (Translation vs. Transliteration)

ತಾಂತ್ರಿಕ ವಿಷಯಗಳನ್ನು ಭಾರತೀಯ ಭಾಷೆಗಳಿಗೆ ಅನುವಾದಿಸುವಾಗ **ಪರಿಕಲ್ಪನೆಯ ಸ್ಪಷ್ಟತೆ** ಮತ್ತು **ಪ್ರಾಯೋಗಿಕ ಬಳಕೆಯ** ನಡುವೆ ಸಮತೋಲನವಿರಬೇಕು.

#### ಎ. ಪ್ರಮುಖ ಪರಿಕಲ್ಪನೆಗಳಿಗೆ ಸಹಜ ಕನ್ನಡ ಪದ + ಮೊದಲ ಬಾರಿ ಆವರಣದಲ್ಲಿ ಇಂಗ್ಲಿಷ್ ಪದ
ಒಂದು ತಾಂತ್ರಿಕ ಪರಿಕಲ್ಪನೆಗೆ ಸೂಕ್ತವಾದ ಕನ್ನಡ ಪದವಿದ್ದಾಗ, ಮೊದಲು **ಕನ್ನಡ ಪದವನ್ನು** ಬಳಸಿ ಮತ್ತು ಮೊದಲ ಬಾರಿ ಉಲ್ಲೇಖಿಸುವಾಗ ಆವರಣದಲ್ಲಿ **ಇಂಗ್ಲಿಷ್ ಪದವನ್ನು** ಸೇರಿಸಿ:

| ಇಂಗ್ಲಿಷ್ ಪದ | ಶಿಫಾರಸು ಮಾಡಿದ ವಿಧಾನ | ಉದಾಹರಣೆ (ಕನ್ನಡ) |
| :--- | :--- | :--- |
| **Encryption** | ಕನ್ನಡ ಪದ + `(Encryption)` | ಗೂಢಲಿಪೀಕರಣ (Encryption) |
| **Phishing** | ಅರ್ಥಪೂರ್ಣ ಪದ + `(Phishing)` | ಗಾಳ ಹಾಕುವ ವಂಚನೆ / ಫಿಶಿಂಗ್ (Phishing) |
| **Multi-Factor Authentication** | ಕನ್ನಡ ಪದ + `(MFA)` | ಬಹು-ಅಂಶ ದೃಢೀಕರಣ (MFA) |
| **Zero Trust** | ಕನ್ನಡ ಪದ + `(Zero Trust)` | ಶೂನ್ಯ ನಂಬಿಕೆ (Zero Trust) |
| **Digital Signature** | ಕನ್ನಡ ಪದ + `(Digital Signature)` | ಡಿಜಿಟಲ್ ಸಹಿ (Digital Signature) |

#### ಬಿ. ಜಾಗತಿಕ ಸಂಕ್ಷಿಪ್ತ ಪದಗಳು (Acronyms) ಮತ್ತು ಪ್ರೊಟೊಕಾಲ್ ಹೆಸರುಗಳನ್ನು ಹಾಗೆಯೇ ಉಳಿಸಿ
ಪ್ರೊಟೊಕಾಲ್ ಹೆಸರುಗಳು, ಫೈಲ್ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು ಅಥವಾ ಅಲ್ಗಾರಿದಮ್‌ಗಳಿಗೆ ಕೃತಕ ಅನುವಾದಗಳನ್ನು ರಚಿಸಬೇಡಿ:

- **ಸಂಕ್ಷಿಪ್ತ ರೂಪದಲ್ಲೇ ಇರಿಸಿ**: `DNS`, `HTTPS`, `TLS`, `IPv6`, `OTP`, `UPI`, `SIM`, `USB`, `APK`, `SHA-256`, `AES`, `SAML`, `OIDC`.
- **ಸಂಸ್ಥೆಗಳು ಮತ್ತು ಮಾನದಂಡಗಳು**: `ICANN`, `IANA`, `NIST`, `WhatsApp`, `Authy`.

#### ಸಿ. ಯಾಂತ್ರಿಕ ಪದಶಃ ಅನುವಾದಕ್ಕಿಂತ ಸಹಜ ಭಾವಾರ್ಥಕ್ಕೆ ಆದ್ಯತೆ ನೀಡಿ
- *"Mouse"*, *"Worm"*, *"Patch"*, *"Pipeline"* ಮುಂತಾದ ಪದಗಳನ್ನು ಅವುಗಳ ತಾಂತ್ರಿಕ ಅರ್ಥದಲ್ಲಿ ಅನುವಾದಿಸಿ.
- **"ಮಾಡಬೇಕಾದವು" ಮತ್ತು "ಮಾಡಬಾರದವು" (Do's & Don'ts)**: ಸುರಕ್ಷತಾ ಪಟ್ಟಿಗಳಲ್ಲಿ **"ಮಾಡಬಾರದವು"** ಅಡಿಯಲ್ಲಿರುವ ಪ್ರತಿಯೊಂದು ಅಂಶವು *"...ಹಂಚಿಕೊಳ್ಳಬೇಡಿ"*, *"...ಕ್ಲಿಕ್ ಮಾಡಬೇಡಿ"* ಎಂದು ಸ್ಪಷ್ಟ ನಿಷೇಧಾತ್ಮಕ ವಾಕ್ಯವಾಗಿರುವುದನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.

### 4. ಕೊಡುಗೆದಾರರ ಪರವಾನಗಿ ಮತ್ತು ಮನ್ನಣೆ (`CC-BY-NC-SA 4.0`)

ಸೈಬರ್ವತ್ತಂನಲ್ಲಿರುವ ಎಲ್ಲಾ ವಿಷಯಗಳನ್ನು **[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC-BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/)** ಪರವಾನಗಿಯ ಅಡಿಯಲ್ಲಿ ಪ್ರಕಟಿಸಲಾಗುತ್ತದೆ.

| ಪರವಾನಗಿ ತತ್ವ | ಇದರ ಅರ್ಥವೇನು? |
| :--- | :--- |
| **ಮನ್ನಣೆ (`BY` - Attribution)** | **ನಿಮ್ಮ ಕೊಡುಗೆಗೆ ಸೂಕ್ತ ಮನ್ನಣೆ ಸಿಗುತ್ತದೆ.** ಕೊಡುಗೆದಾರರ ಹೆಸರುಗಳನ್ನು Git ಇತಿಹಾಸದಲ್ಲಿ ಮತ್ತು ನಮ್ಮ [ಕೊಡುಗೆದಾರರು](/kn/library/aboutus/contributors/contributors/) ಪುಟದಲ್ಲಿ ದಾಖಲಿಸಲಾಗುತ್ತದೆ. ವಿಷಯವನ್ನು ಮರುಬಳಕೆ ಮಾಡುವ ಪ್ರತಿಯೊಬ್ಬರೂ ಸೈಬರ್ವತ್ತಂ ಮತ್ತು ಕೊಡುಗೆದಾರರಿಗೆ ಮನ್ನಣೆ ನೀಡಬೇಕು. |
| **ವಾಣಿಜ್ಯೇತರ ಬಳಕೆ (`NC` - NonCommercial)** | **ಶಿಕ್ಷಣಕ್ಕೆ ಉಚಿತ, ಮಾರಾಟಕ್ಕಲ್ಲ.** ಶಿಕ್ಷಕರು, ವಿದ್ಯಾರ್ಥಿಗಳು ಮತ್ತು ಸಮುದಾಯಗಳು ಈ ಮಾರ್ಗದರ್ಶಿಗಳನ್ನು ಉಚಿತವಾಗಿ ಬಳಸಬಹುದು; ಆದರೆ ವಾಣಿಜ್ಯ ಲಾಭಕ್ಕಾಗಿ ಮಾರಾಟ ಮಾಡುವಂತಿಲ್ಲ. |
| **ಸಮಾನ ಹಂಚಿಕೆ (`SA` - ShareAlike)** | **ಮುಕ್ತ ಜ್ಞಾನ ಯಾವಾಗಲೂ ಮುಕ್ತವಾಗಿರುತ್ತದೆ.** ಈ ಪಾಠಗಳನ್ನು ಅನುವಾದಿಸುವ ಅಥವಾ ಮಾರ್ಪಡಿಸುವ ಯಾರಾದರೂ ತಮ್ಮ ಹೊಸ ಆವೃತ್ತಿಯನ್ನೂ ಇದೇ `CC-BY-NC-SA 4.0` ಪರವಾನಗಿಯ ಅಡಿಯಲ್ಲಿ ಹಂಚಿಕೊಳ್ಳಬೇಕು. |
