### नेटिव क्लाउड सुरक्षा नियंत्रण

सार्वजनिक क्लाउड सेवा प्रदाता कई नेटिव सुरक्षा नियंत्रण प्रदान करते हैं, जो वर्कलोड, पहचानों, नेटवर्क और एप्लिकेशन को सुरक्षित रखने में मदद करते हैं।

### उदाहरण

#### AWS
- IAM and SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS and HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM and Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### उद्देश्य

ये नेटिव नियंत्रण संगठनों को प्रदाता की अंतर्निहित क्षमताओं तथा प्लेटफॉर्म-नेटिव मॉनिटरिंग, पहचान, एन्क्रिप्शन और अनुपालन नियंत्रणों के माध्यम से अपने क्लाउड संचालन को सुरक्षित करने में मदद करते हैं।
