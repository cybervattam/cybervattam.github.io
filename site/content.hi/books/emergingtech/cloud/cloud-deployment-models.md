## __क्लाउड कंप्यूटिंग परिनियोजन मॉडल / Cloud Deployment Models__
<br>
<img src="images/cloud-ta/cloud-deployment-model-ta.svg">

<br>
<br>

#### 1. सार्वजनिक क्लाउड / Public Cloud
क्लाउड इन्फ्रास्ट्रक्चर आम जनता या बड़े व्यवसायों के लिए उपलब्ध कराया जाता है। यह इन्फ्रास्ट्रक्चर क्लाउड सेवा प्रदाताओं के स्वामित्व में होता है।

क्लाउड सेवाएँ कोई भी प्राप्त कर सकता है।

उदाहरण:
* Amazon Web Services
* Microsoft Azure
* Google Cloud Platform


#### 2. निजी क्लाउड / Private Cloud

इस प्रकार का क्लाउड इन्फ्रास्ट्रक्चर केवल एक संस्था के लिए संचालित किया जाता है।

इसे संस्था या किसी तीसरे पक्ष द्वारा प्रबंधित किया जा सकता है और यह संस्था के परिसर के अंदर या बाहर स्थित हो सकता है।

उदाहरण:
* Rackspace
* VMware vCloud
* Azure Stack
* IBM Cloud Private

#### 3. हाइब्रिड क्लाउड / Hybrid Cloud

इस प्रकार का क्लाउड इन्फ्रास्ट्रक्चर दो या अधिक परिनियोजन मॉडलों (निजी, सामुदायिक या सार्वजनिक) का संयोजन होता है और एक ही संस्था द्वारा संचालित किया जाता है। ये मॉडल मानक या स्वामित्व वाली तकनीक से जुड़े होते हैं और डेटा तथा एप्लिकेशन पोर्टेबिलिटी को सक्षम करते हैं। हाइब्रिड क्लाउड शब्द का उपयोग अक्सर क्लाउड सेवा प्रदाता से सीधे जुड़े गैर-क्लाउड डेटा सेंटर का वर्णन करने के लिए किया जाता है।


#### 4. सामुदायिक क्लाउड / Community Cloud

तकनीकी दृष्टि से सामुदायिक क्लाउड एक साझा क्लाउड प्लेटफ़ॉर्म है, जिसे केवल विशिष्ट ग्राहक ही एक्सेस कर सकते हैं। क्लाउड इन्फ्रास्ट्रक्चर को कुछ संस्थाएँ मल्टीटेनेंसी के साथ साझा करती हैं। यह ऐसे विशिष्ट समुदाय का समर्थन करता है जो मिशन, सुरक्षा आवश्यकताओं, नीति या अनुपालन संबंधी चिंताओं को साझा करता है। इसे संस्था या तीसरे पक्ष द्वारा प्रबंधित किया जा सकता है और यह संस्था के परिसर के अंदर या बाहर स्थित हो सकता है। उदाहरण: सरकारी क्लाउड (Gov Cloud)।
