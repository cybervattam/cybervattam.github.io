# IPv6

यह अनुभाग IPv6 की मूल अवधारणाओं, इसकी आवश्यकता, एड्रेसिंग संरचना, हेडर फॉर्मेट और IPv4 से इसके अंतर को शामिल करता है।

- परिचय और विशेषताएं
- IPv6 की आवश्यकता क्यों है
- एड्रेसिंग नियम और संरचना
- एड्रेस मोड और यूनिकास्ट प्रकार
- IPv6 हेडर फॉर्मेट
- IPv4 बनाम IPv6 तुलना
