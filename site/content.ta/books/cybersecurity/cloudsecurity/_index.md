# கிளவுட் பாதுகாப்பு

இந்தப் பிரிவு கிளவுட் பாதுகாப்பு மாதிரி, தளப் பாதுகாப்புகள், அடையாளக் கட்டுப்பாடுகள், தரவுப் பாதுகாப்பு மற்றும் நவீன ஜீரோ டிரஸ்ட், SASE அடிப்படையிலான பாதுகாப்பு முறைகளை உள்ளடக்கியது.

- கிளவுட் பாதுகாப்பு மேலோட்டம்
- பகிரப்பட்ட பொறுப்பு மாதிரி
- இயற்பியல் மற்றும் வன்பொருள் பாதுகாப்பு
- மெய்நிகராக்கப் பாதுகாப்பு
- கிளவுட் அடையாளம் மற்றும் உரிமை மேலாண்மை
- தரவுப் பாதுகாப்பு மற்றும் குறியாக்கம்
- SASE, SWG, CASB மற்றும் ZTNA
- பொது கிளவுட் நேட்டிவ் பாதுகாப்புக் கட்டுப்பாடுகள்
