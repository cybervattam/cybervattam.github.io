### சைபர்வட்டம் பங்களிப்பாளர் வழிகாட்டிக்கு வரவேற்கிறோம்

**சைபர்வட்டம் (Cybervattam)** என்பது இணையப் பாதுகாப்பு, இணைய விழிப்புணர்வு மற்றும் நவீனத் தொழில்நுட்ப அறிவை இந்திய மொழிகளில் அனைவருக்கும் எளிமையாகக் கொண்டு சேர்க்கும் திறந்தநிலை சமூக முயற்சியாகும். புதிய பாடங்களை எழுதவும், மொழிபெயர்ப்புகளை மேம்படுத்தவும், அல்லது தகுந்த தமிழ்க் கலைச்சொற்களைப் பரிந்துரைக்கவும் இந்த வழிகாட்டி உங்களுக்கு உதவும்.

---

### 1. நீங்கள் எவ்வாறு பங்களிக்கலாம்?

1. **மொழிபெயர்ப்பைச் சரிபார்த்தல் மற்றும் திருத்துதல்**: தமிழ், இந்தி, மலையாளம், தெலுங்கு அல்லது கன்னடப் பக்கங்களில் எழுத்துப் பிழைகள் அல்லது கடினமான மொழிபெயர்ப்புகளைக் கண்டால் GitHub வழியாகத் திருத்தங்களைப் பரிந்துரைக்கலாம்.
2. **புதிய பாடங்களை மொழிபெயர்த்தல்**: `site/content.en/` கோப்புறையில் உள்ள ஆங்கிலப் பாடங்களை உங்கள் தாய்மொழியில் மொழிபெயர்க்கலாம்.
3. **புதிய கட்டுரைகள் மற்றும் விளக்கப்படங்களை உருவாக்குதல்**: இணையப் பாதுகாப்பு மற்றும் நவீனத் தொழில்நுட்பங்கள் குறித்த புதிய பாடங்கள் அல்லது தமிழ் SVG விளக்கப்படங்களை உருவாக்கிப் பங்களிக்கலாம்.
4. **"வாரத்தின் கலைச்சொல்" பரிந்துரைத்தல்**: `site/static/data/terms-of-the-week.json` கோப்பில் புதிய தொழில்நுட்பக் கலைச்சொற்கள் மற்றும் நடைமுறை எடுத்துக்காட்டுகளைச் சேர்க்கலாம்.

### 2. களஞ்சியக் கட்டமைப்பு (Content Directory Structure)

அனைத்துப் பாடங்களும் **Markdown (`.md`)** வடிவத்தில் `site/` கோப்புறைக்குள் மொழிவாரியாக அமைக்கப்பட்டுள்ளன. ஒவ்வொரு மொழிக் கோப்புறையும் `content.en/`-இல் உள்ள அதே கோப்புப் பெயர்களையும் பாதைகளையும் கொண்டிருப்பதால், Hugo தானாகவே மொழிகளுக்கு இடையிலான இணைப்புகளை உருவாக்குகிறது:

    │   ├── _index.md                # முகப்புப் பக்க அறிமுகம்
    │   ├── events/                  # நிகழ்வுகள் மற்றும் பயிலரங்குகள்
    │   └── library/                 # முதன்மை அறிவுசார் நூலகம்
    │       ├── cyberawareness/      # பிரிவு 1: இணைய விழிப்புணர்வு
    │       │   ├── cyberhygine/     #   கருவிகள், கடவுச்சொல் & இணையப் பாதுகாப்பு
    │       │   ├── familysafety/    #   வயது வாரியான குடும்பப் பாதுகாப்பு வழிகாட்டிகள்
    │       │   └── topscamsfrauds/  #   தூண்டில் மோசடி (Phishing), OTP, UPI & AI மோசடிகள்
    │       ├── cybersecurity/       # பிரிவு 2: இணையப் பாதுகாப்பு
    │       │   ├── cloudsecurity/   #   மேகக் கணிமைப் பாதுகாப்பு, CSPM, CNAPP, ZTNA
    │       │   ├── cryptography/    #   மறையீட்டியல், மறையாக்கம் & இலக்கமுறைக் குறியொப்பம்
    │       │   ├── dns/             #   களப்பெயர் முறைமை (DNS), DNSSEC, DoH/DoT
    │       │   ├── iam/             #   அடையாள மற்றும் அணுகல் மேலாண்மை (IAM, MFA, OIDC)

    │       │   └── zerotrust/       #   பூஜ்ஜிய நம்பிக்கை (Zero Trust) கட்டமைப்பு
    │       ├── emergingtech/        # பிரிவு 3: நவீனத் தொழில்நுட்பங்கள்
    │       │   ├── blockchain/      #   தொடர் блоக் (Blockchain) & ஒருமித்த கருத்து
    │       │   ├── cloud/           #   மேகக் கணிமைச் சேவை மற்றும் வகைகள்

    │
    ├── content.ta/                  # தமிழ் — content.en/ கட்டமைப்பைப் பிரதிபலிக்கிறது

    ├── i18n/                        # பயனர் இடைமுகச் சொற்கள் (en.toml, ta.toml, முதலியன)

        └── images/                  # விளக்கப்படங்கள் (en/, ta/, shared/)

### மறையீட்டியல் அறிமுகம்

இங்கு உங்கள் பாட உள்ளடக்கத்தை எளிய தமிழில் எழுதலாம்.

> **முக்கிய விதி**: கோப்பின் பெயரை (எ.கா. `cryptography-introduction.md`) அனைத்து மொழிக் கோப்புறைகளிலும் ஆங்கிலத்திலேயே வைத்திருக்கவும். அப்போதுதான் கட்டுரைகளுக்கு இடையே மொழி மாற்றம் (Language Switcher) சரியாகச் செயல்படும்.

### 3. தொழில்நுட்பக் கலைச்சொல் மொழிபெயர்ப்பு வழிகாட்டுதல்கள் (Translation vs. Transliteration)

தொழில்நுட்பக் கருத்துகளை இந்திய மொழிகளில் மொழிபெயர்க்கும்போது **கருத்துத் தெளிவும்** **நடைமுறைப் பயன்பாடும்** சமநிலையில் இருக்க வேண்டும்.

#### அ. முதன்மைக் கருத்துகளுக்குத் தமிழ்க் கலைச்சொல் + அடைப்புக்குறிக்குள் ஆங்கிலச் சொல்
ஒரு தொழில்நுட்பக் கருத்துக்குத் தெளிவான தமிழ்ச் சொல் இருக்கும்போது, முதலில் **தமிழ்க் கலைச்சொல்லைப்** பயன்படுத்தி, முதல் முறை குறிப்பிடும்போது மட்டும் அடைப்புக்குறிக்குள் **ஆங்கிலச் சொல்லை** இடவும்:

| ஆங்கிலக் கலைச்சொல் | பரிந்துரைக்கப்படும் முறை | எடுத்துக்காட்டு (தமிழ்) |
| :--- | :--- | :--- |
| **Encryption** | தமிழ்க் கலைச்சொல் + `(Encryption)` | மறையாக்கம் (Encryption) |
| **Phishing** | பொருள் விளக்கும் தமிழ்ச் சொல் + `(Phishing)` | தூண்டில் மோசடி (Phishing) |
| **Multi-Factor Authentication** | தமிழ்க் கலைச்சொல் + `(MFA)` | பல்காரணி சான்றுறுதி (MFA) |
| **Zero Trust** | தமிழ்க் கலைச்சொல் + `(Zero Trust)` | பூஜ்ஜிய நம்பிக்கை (Zero Trust) |
| **Brute-Force Attack** | பொருள் அடிப்படையிலான மொழிபெயர்ப்பு | தொடர் முயற்சித் தாக்குதல் (Brute-force attack) |

#### ஆ. உலகளாவிய சுருக்கெழுத்துகள் மற்றும் நெறிமுறைப் பெயர்களை அப்படியே வைத்திருத்தல்
நெறிமுறைகள் (Protocols), கோப்பு வடிவங்கள் மற்றும் குறியீட்டு முறைகளின் பெயர்களை ஆங்கிலச் சுருக்கெழுத்துகளாகவே வைத்திருக்கவும். அவற்றோடு தமிழ் வேற்றுமை உருபுகளைச் சேர்க்கும்போது இடைக்கோடு (`-`) பயன்படுத்தவும் (எ.கா. `OTP-ஐ`, `DNS-இன்`, `URL-கள்`).

- **சுருக்கெழுத்துகளாகவே வைக்க வேண்டியவை**: `DNS`, `HTTPS`, `TLS`, `IPv6`, `OTP`, `UPI`, `SIM`, `USB`, `APK`, `SHA-256`, `AES`, `SAML`, `OIDC`.
- **தனிப்பெயர்கள் மற்றும் தரநிலைகள்**: `ICANN`, `IANA`, `NIST`, `WhatsApp`, `Authy`.

#### இ. இயந்திர மொழிபெயர்ப்புப் பிழைகளைத் தவிர்த்தல்
- *"Mouse"* என்பதை *"எலி"* என்றோ, *"Security patch"* என்பதை *"பாதுகாப்பு இணைப்பு"* என்றோ, *"DevOps pipeline"* என்பதை *"குழாய்"* என்றோ நேர்பொருளில் மொழிபெயர்க்காமல், தொழில்நுட்பப் பொருளுக்கு ஏற்ப *சுட்டி (Mouse)*, *பாதுகாப்புத் திருத்தம் (Security patch)*, *பணித்தொடர் (Pipeline)* என மொழிபெயர்க்கவும்.
- **செய்ய வேண்டியவை / செய்யக் கூடாதவை (Do's & Don'ts)**: *"செய்யக் கூடாதவை"* பிரிவின் கீழ் வரும் அனைத்துக் குறிப்புகளும் `...பகிர வேண்டாம்`, `...கிளிக் செய்ய வேண்டாம்` எனத் தெளிவான எதிர்மறைக் கட்டளை வாக்கியங்களாக இருப்பதை உறுதிசெய்யவும்.

### 4. பங்களிப்பாளர் உரிமம் மற்றும் பெயர் குறிப்பிடுதல் (`CC-BY-NC-SA 4.0`)

சைபர்வட்டத்தின் அனைத்து உள்ளடக்கங்களும் **[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC-BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/)** உரிமத்தின் கீழ் பகிரப்படுகின்றன.

| உரிமக் கூறு | இதன் பொருள் என்ன? |
| :--- | :--- |
| **பெயர் குறிப்பிடுதல் (`BY` - Attribution)** | **உங்கள் பங்களிப்பிற்கு உரிய அங்கீகாரம்.** பங்களிப்பாளர்களின் பெயர்கள் Git வரலாற்றிலும் எமது [பங்களிப்பாளர்கள்](/ta/library/aboutus/contributors/contributors/) பக்கத்திலும் இடம்பெறும். இத்தளத்தின் உள்ளடக்கத்தைப் பயன்படுத்துபவர்கள் சைபர்வட்டத்திற்கும் பங்களிப்பாளர்களுக்கும் உரிய நன்றியைக் குறிப்பிட வேண்டும். |
| **வணிக நோக்கமற்றது (`NC` - NonCommercial)** | **கல்விக்கு இலவசம்; விற்பனைக்கு அல்ல.** மாணவர்கள், ஆசிரியர்கள் மற்றும் சமூக அமைப்புகள் இப்பாடங்களை இலவசமாகப் பயன்படுத்தலாம்; ஆனால் வணிக இலாபத்திற்காக விற்கக் கூடாது. |
| **இதே உரிமத்தில் பகிர்தல் (`SA` - ShareAlike)** | **திறந்த அறிவு எப்போதும் திறந்தே இருக்கும்.** இப்பாடங்களைத் தழுவி உருவாக்கப்படும் புதிய படைப்புகளும் இதே `CC-BY-NC-SA 4.0` உரிமத்தின் கீழ் பகிரப்பட வேண்டும். |
