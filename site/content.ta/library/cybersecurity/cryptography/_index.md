இந்தப் பிரிவு இலக்கமுறைத் தகவல்களைப் பாதுகாக்கப் பயன்படும் மறையாக்கம் (Encryption), குறுக்கம் (Hashing), பொதுத் திறவி அமைப்புகள் (Public-key systems) மற்றும் பாதுகாப்புக் கோட்பாடுகள் உள்ளிட்ட மறைப்பியலின் (Cryptography) அடிப்படைக் கருத்துகளை அறிமுகப்படுத்துகிறது.

* ஒற்றைத் திறவி மறைப்பியல் (Symmetric key cryptography)
* இரட்டைத் திறவி மறைப்பியல் (Asymmetric key cryptography)
* குறுக்கம் மற்றும் செய்தி ஒருமைப்பாடு (Hashing and message integrity)
* தகவல் பாதுகாப்பின் தூண்கள் மற்றும் நடைமுறைப் பயன்பாடுகள் (Security pillars and real-world use cases)
* பொதுத் திறவி மறைப்பியல் பண்புகள் மற்றும் மறைப்பியல் முறைகளின் ஒப்பீடு (Public key properties and comparison of cryptographic mechanisms)
