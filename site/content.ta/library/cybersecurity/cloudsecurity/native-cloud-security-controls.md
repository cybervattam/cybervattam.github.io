### மேகக் கணிமையின் சொந்தப் பாதுகாப்புக் கருவிகள்

பணிச்சுமைகள், அடையாளங்கள், பிணையங்கள், பயன்பாடுகளைப் பாதுகாக்க உதவும் பல்வேறு சொந்தப் பாதுகாப்புக் கருவிகளைப் பொதுமேகச் சேவை வழங்குநர்கள் வழங்குகின்றனர்.

### எடுத்துக்காட்டுகள்

#### AWS
- IAM மற்றும் SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS மற்றும் HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM மற்றும் Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### நோக்கம்

உள்ளமைக்கப்பட்ட வழங்குநர் திறன்களையும் தளத்திலேயே உள்ள கண்காணிப்பு, அடையாள, குறியாக்க, இணக்கக் கட்டுப்பாடுகளையும் பயன்படுத்தி மேகச் செயல்பாடுகளைப் பாதுகாக்க இந்தச் சொந்தக் கட்டுப்பாடுகள் நிறுவனங்களுக்கு உதவுகின்றன.
