### நேட்டிவ் மேகக் கணிமை பாதுகாப்புக் கட்டுப்பாடுகள்

பொது மேகக் கணிமை சேவை வழங்குநர்கள் பணிச்சுமைகள், அடையாளங்கள், நெட்வொர்க்குகள் மற்றும் பயன்பாடுகளைப் பாதுகாக்க உதவும் பல்வேறு நேட்டிவ் பாதுகாப்புக் கட்டுப்பாடுகளை வழங்குகின்றனர்.

### எடுத்துக்காட்டுகள்

#### AWS
- IAM and SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS and HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM and Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### நோக்கம்

இந்த நேட்டிவ் கட்டுப்பாடுகள், வழங்குநரின் உள்ளமைந்த திறன்கள் மற்றும் தள நேட்டிவ் கண்காணிப்பு, அடையாளம், குறியாக்கம், இணக்கநிலைக் கட்டுப்பாடுகள் மூலம் நிறுவனங்கள் தங்கள் மேகக் கணிமை செயல்பாடுகளைப் பாதுகாக்க உதவுகின்றன.
