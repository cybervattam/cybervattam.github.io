### மேகக் கணிமை பாதுகாப்பு பகிரப்பட்ட பொறுப்பு மாதிரி

மேகக் கணிமை பாதுகாப்பு மாதிரி மேகக் கணிமை சேவை வழங்குநருக்கும் வாடிக்கையாளருக்கும் இடையில் பகிரப்படுகிறது.

வாடிக்கையாளரின் பணிச்சுமைக்கு அடியில் உள்ள இயற்பியல் வசதிகள், நெட்வொர்க் உள்கட்டமைப்பு, மெய்நிகராக்க அடுக்குகள் மற்றும் சில முக்கிய தளக் கட்டுப்பாடுகள் உள்ளிட்ட உள்கட்டமைப்பைப் பாதுகாப்பது வழங்குநரின் பொறுப்பாகும். அடையாளம் மற்றும் அணுகல், பயன்பாட்டுப் பாதுகாப்பு, தரவுப் பாதுகாப்பு, உள்ளமைவு சீர்மை மற்றும் நிர்வாகம் உள்ளிட்ட மேகக் கணிமைடில் உள்ள பாதுகாப்பு வாடிக்கையாளரின் பொறுப்பாகும்.

### பகிரப்பட்ட பொறுப்புகளின் எடுத்துக்காட்டுகள்

| அடுக்கு | வழங்குநரின் பொறுப்பு | வாடிக்கையாளரின் பொறுப்பு |
|---|---|---|
| இயற்பியல் பாதுகாப்பு | தரவு மையப் பாதுகாப்பு | எதுவுமில்லை |
| நெட்வொர்க் | முக்கிய நெட்வொர்க் மற்றும் இணைப்பு | பாதுகாப்புக் குழுக்கள், ரூட்டிங், ஃபயர்வால் உள்ளமைவு |
| மெய்நிகராக்கம் | ஹைப்பர்வைசர் உள்கட்டமைப்பு | VM கடினப்படுத்தல் மற்றும் பணிச்சுமைப் பாதுகாப்பு |
| இயக்க முறைமை | நிர்வகிக்கப்படும் தளச் சேவைகள் | OS பேட்ச் செய்தல், அணுகல் கட்டுப்பாடு |
| பயன்பாடு | தளச் சேவைகள் | பயன்பாட்டு தர்க்கம் மற்றும் பாதுகாப்பான மேம்பாடு |
| தரவு | சேமிப்பகத் தளப் பாதுகாப்பு | வகைப்படுத்தல், குறியாக்கம், தக்கவைப்பு |
| அடையாளம் மற்றும் அணுகல் | IAM தளம் | பயனர் வழங்கல், கொள்கைகள், குறைந்தபட்சச் சலுகை |

### பாதுகாப்புக் கட்டுப்பாடுகள்

நிறுவனங்கள் அடையாளம், நிர்வாகம், உள்ளமைவு, கண்காணிப்பு மற்றும் தணிக்கை நடைமுறைகளை மேகக் கணிமை வழங்குநரின் மாதிரியுடன் ஒத்திசைக்க வேண்டும் என்று இந்த மாதிரி வலியுறுத்துகிறது.
