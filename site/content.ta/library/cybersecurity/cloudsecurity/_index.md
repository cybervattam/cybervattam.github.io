# மேகக் கணிமை பாதுகாப்பு

இந்தப் பிரிவு மேகக் கணிமை பாதுகாப்பு மாதிரி, தளப் பாதுகாப்புகள், அடையாளக் கட்டுப்பாடுகள், தரவுப் பாதுகாப்பு மற்றும் நவீன நம்பாமை, SASE அடிப்படையிலான பாதுகாப்பு முறைகளை உள்ளடக்கியது.

- மேகக் கணிமை பாதுகாப்பு மேலோட்டம்
- பகிரப்பட்ட பொறுப்பு மாதிரி
- இயற்பியல் மற்றும் வன்பொருள் பாதுகாப்பு
- மெய்நிகராக்கப் பாதுகாப்பு
- மேகக் கணிமை அடையாளம் மற்றும் உரிமை மேலாண்மை
- தரவுப் பாதுகாப்பு மற்றும் குறியாக்கம்
- SASE, SWG, CASB மற்றும் ZTNA
- பொது மேகக் கணிமை நேட்டிவ் பாதுகாப்புக் கட்டுப்பாடுகள்
