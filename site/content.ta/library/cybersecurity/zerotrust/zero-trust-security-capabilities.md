### நம்பாமை பாதுகாப்புத் திறன்கள்

நம்பாமை அடையாளம், சாதனங்கள், நெட்வொர்க்குகள் மற்றும் பயன்பாடுகள் முழுவதும் உள்ள பல பாதுகாப்புத் திறன்களைச் சார்ந்துள்ளது.

### தூண்கள் மற்றும் திறன்கள்

#### அடையாளம்
- IAM
- IGA
- PIM & PAM
- RBAC
- சீக்ரெட்ஸ் மேலாண்மை
- அடையாளக் கூட்டமைப்பு
- PBAC

#### சாதனம்
- சாதன இருப்புப் பட்டியல்
- சாதன அடிப்படை நிலை மற்றும் கடினப்படுத்தல்
- சாதன அங்கீகாரம் மற்றும் அனுமதியளித்தல்
- சாதன இணக்கநிலை
- சாதனக் குறியாக்கம்
- சாதன சாண்ட்பாக்சிங்

#### நெட்வொர்க்குகள் மற்றும் உள்கட்டமைப்பு
- SD-WAN
- நெட்வொர்க் பிரிவாக்கம்
- DDoS பாதுகாப்பு
- SWG மற்றும் ZTNA
- NAC
- IDS மற்றும் IPS
- NGFW

#### பயன்பாடு
- API பாதுகாப்பு

### குறிக்கோள்

ஒவ்வொரு தூணும் அணுகல் முடிவுகளை வெளிப்படையானதாகவும், மாற்றத்திற்கேற்ப அமைவதாகவும், அபாயத்தை உணர்ந்ததாகவும் மாற்ற உதவுகிறது.
