### Cloud Native Application Protection Platform (CNAPP)

A cloud native application protection platform (CNAPP) unifies multiple cloud security capabilities in a single platform that protects applications from build to runtime. It reduces tool sprawl by correlating risk signals across workloads, configurations, and data.

### CNAPP Components

- **Cloud workload protection platform (CWPP):** protects workloads such as virtual machines, containers, and serverless functions
- **Cloud security posture management (CSPM):** detects misconfigurations and compliance gaps in cloud infrastructure
- **SaaS security posture management (SSPM):** secures configuration and access in SaaS applications

### Value of a Unified Approach

- Shift-left security integrated into CI/CD pipelines
- Single view of risk across code, workloads, and configuration
- Consistent policies across multi-cloud environments
- Faster prioritization and remediation of real risks
