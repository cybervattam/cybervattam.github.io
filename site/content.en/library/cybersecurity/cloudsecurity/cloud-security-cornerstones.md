### Cloud Security Cornerstones

Security in the cloud is built on a set of solution cornerstones. Each cornerstone answers a common customer need and maps to a cloud security service and a technology landscape.

<img src="/images/en/cybersecurity/cloudsecurity/cloud-security-cornerstones.png">

### Cornerstones and Services

- **Modern workplace:** security for the digital workplace, using native controls
- **SaaS visibility and control:** cloud access security broker (CASB)
- **Data center in the cloud:** cloud workload protection platform (CWPP)
- **Native controls:** native cloud security services from the cloud provider
- **Control of data and keys:** cloud data security
- **Right access for the right people:** cloud IAM and entitlement management
- **Secure DevOps pipeline:** cloud application security
- **Risk and compliance:** cloud and SaaS security posture management (CSPM and SSPM)

### How to Use This Model

Start with the business need, choose the matching service, and then select tools that integrate with the cloud providers and applications in use.
