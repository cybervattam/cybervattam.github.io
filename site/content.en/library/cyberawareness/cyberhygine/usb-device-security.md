USB devices are convenient for transferring data, but their portability can introduce data theft, data leakage, and malware risks. Examples include flash drives, portable hard drives, memory cards, cameras, mobile phones, and USB keyboards or mice.

## Safe practices

- Scan every USB device with antivirus or endpoint protection before using it.
- Disable Autorun and Autoplay on computers when using USB devices.
- Avoid connecting unknown or untrusted USB devices.
- Disable or remove USB devices when they are not needed.
