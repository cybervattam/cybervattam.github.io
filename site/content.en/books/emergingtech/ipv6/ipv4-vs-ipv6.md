### IPv4 vs IPv6 Comparison

| Feature | IPv4 | IPv6 |
|---|---|---|
| Address length | 32 bits | 128 bits |
| Address count | 4,294,967,296 | Approximately 3.4 × 10^38 |
| Address format | Decimal octets | Hexadecimal groups |
| Example | 127.168.1.24 | 2001:db8::8a2e:370:7334 |
| End-to-end connectivity | Limited | Better supported |
| Flow identification | Not available | Available through Flow Label |

### Key Takeaway

IPv6 is designed for the modern Internet, with a much larger address space and better support for routing, mobility, and end-to-end communication.
