### Native Cloud Security Controls

Public cloud service providers offer a range of native security controls that help secure workloads, identities, networks, and applications.

### Examples

#### AWS
- IAM and SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS and HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM and Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### Purpose

These native controls help organizations secure their cloud operations with built-in provider capabilities and platform-native monitoring, identity, encryption, and compliance controls.
