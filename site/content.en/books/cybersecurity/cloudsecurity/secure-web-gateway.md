### Secure Web Gateway (SWG)

A secure web gateway is a security solution that prevents unsecured internet traffic from entering an organization’s internal network.

It helps protect users from malicious websites and supports regulatory compliance.

### Core Functionality

- URL filtering
- Malicious code detection and filtering
- Application control for popular SaaS services
- Blocking access to malicious websites and links
- Enforcing web use policies
- Filtering traffic at the application level

### Difference from Firewalls and Proxies

- Firewalls inspect network-layer packets and compare them against known signatures.
- Proxies filter outbound or inbound connections based on policy.
- SWGs operate at the application layer and can evaluate web traffic more granularly.

### Architecture Summary

SWGs sit between users and the internet, protecting good traffic while blocking malicious content and enforcing organizational policy.
