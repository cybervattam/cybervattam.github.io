### Cloud Security Overview

Cloud security is the protection of cloud-based systems, data, applications, identities, and workloads from threats and misuse.

Cloud providers operate large private networks, dedicated backbone connectivity, and high-scale infrastructure, but security must still be designed in layers. Organizations must protect not only the provider environment but also their own workloads, identities, applications, and data.

### Core Security Areas

- Physical infrastructure security
- Virtualization and hypervisor security
- Network security
- Identity and access control
- Data protection and encryption
- Compliance and governance
- Threat detection and response
