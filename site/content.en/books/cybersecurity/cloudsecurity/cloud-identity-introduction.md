### What is a Cloud Identity?

A cloud identity is any entity with access to cloud services or cloud resources.

### Types of Cloud Identities

#### Human Identity
Examples include users, administrators, and developers.

#### Non-Human Identity
Examples include devices, software-defined infrastructure, AI workloads, and automated services.

### Cloud Entitlements

An organization can grant both identity types specific cloud entitlements. Cloud entitlements determine which tasks an identity can perform and which cloud resources it can access.

### Examples of Entitlements

- Cloud resources such as files, virtual machines, servers, and containers
- Cloud services such as databases, storage buckets, applications, and networking services
