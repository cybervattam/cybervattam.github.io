### క్లౌడ్ కంప్యూటింగ్ పాత్రలు / Cloud Computing Roles

* క్లౌడ్ ప్రొవైడర్ / Cloud Provider
    - ఆసక్తిగల పక్షాలకు క్లౌడ్ కంప్యూటింగ్ సేవలను అందుబాటులో ఉంచే బాధ్యత కలిగిన ఒక వ్యక్తి, సంస్థ లేదా కంపెనీ.
<br>
* క్లౌడ్ కన్స్యూమర్ / కస్టమర్ / Cloud Consumer
    - క్లౌడ్ ప్రొవైడర్‌తో వ్యాపార సంబంధాన్ని కొనసాగిస్తూ, ఆ సేవను ఉపయోగించుకునే ఒక వ్యక్తి లేదా సంస్థ.
<br>
* క్లౌడ్ క్యారియర్ /  Cloud Carrier
    - క్లౌడ్ ప్రొవైడర్ మరియు వినియోగదారుడి మధ్య క్లౌడ్ కంప్యూటింగ్ సేవల కోసం కనెక్టివిటీ మరియు రవాణాను అందించే ఒక మధ్యవర్తి.
<br>
* క్లౌడ్ బ్రోకర్ / Cloud Broker
    క్లౌడ్ సేవల వినియోగం, పనితీరు మరియు డెలివరీని నిర్వహించే మరియు క్లౌడ్ ప్రొవైడర్లు మరియు వినియోగదారుల మధ్య సంబంధాలను మధ్యవర్తిత్వం చేసే ఒక సంస్థ.
<br>
* క్లౌడ్ యాక్సెస్ సెక్యూరిటీ బ్రోకర్  / Cloud Access Security Broker (CASB)
    - ఈ రకమైన సాఫ్ట్‌వేర్, అప్లికేషన్ ప్రోగ్రామింగ్ ఇంటర్‌ఫేస్‌ల (APIలు) ద్వారా గానీ లేదా నేరుగా సేవతో గానీ కనెక్ట్ అవుతుంది. ఇది కమ్యూనికేషన్‌లను అడ్డగించడం, కార్యకలాపాలను పర్యవేక్షించడం, పాలసీలను అమలు చేయడం, మరియు క్లౌడ్ కంప్యూటింగ్‌కు సంబంధించిన భద్రతా సమస్యలను గుర్తించి నివారించడం వంటివి చేస్తుంది. ఇవి సాధారణంగా ఒక సంస్థ యొక్క అధీకృత మరియు అనధికార సేవలను (సాఫ్ట్‌వేర్ యాజ్ ఎ సర్వీస్ వంటివి) నిర్వహించడానికి ఉపయోగించబడతాయి.
