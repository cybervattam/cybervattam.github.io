### డొమైన్ పేరు వ్యవస్థ శ్రేణి/హైరార్కీ / DNS Hierarchy

#### రూట్ నేమ్ సర్వర్లు / Root Name Servers
ప్రస్తుతం 13 రూట్ నేమ్ సర్వర్లు 13 స్వతంత్ర సంస్థలచే Anycast Routing Protocol పై నిర్వహించబడుతున్నాయి. ఇవి ICANN సంస్థచే నిర్వహించబడతాయి. ఒక రూట్ సర్వర్ క్వెరీని స్వీకరిస్తుంది మరియు డొమైన్ పేరు పొడిగింపు ఆధారంగా టాప్-లెవల్ డొమైన్ నేమ్ సర్వర్‌కుแทనిని పంపుతుంది. https://root-servers.org/

DNS వ్యవస్థ యొక్క రూట్ జోన్ డేటాను నిర్వహించడంలో ఇది ప్రధాన స్థానం కలిగి ఉంది. ఇది DNS ట్రీలో అత్యున్నత స్థాయి. ఈ పనిలో అగ్రస్థాయి డొమైన్ డేటా రిజిస్ట్రీలు, రూట్ డొమైన్ సర్వర్‌లను నిర్వహించే సంస్థలు మరియు ICANN యొక్క పాలసీ-రచయిత బృందం కృషి చేస్తారు. రూట్ జోన్‌లో DNSSEC‌ను అమలు చేయడానికి కీ సైన్నింగ్ కార్యక్రమం కూడా జరుగుతుంది. కార్యకలాపంలో anycast IP చిరునామాను ఉపయోగించి 13 రూట్ సర్వర్లు ఉన్నాయి. నెట్‌వర్క్‌లో ఉన్న కంప్యూటర్‌లు గరిష్టంగా డొమైన్‌కి IP చిరునామాను స్థానికంగా డేటా‌స్టోర్‌లో ఉంచినందున రూట్ సర్వర్‌లకు ఎక్కువ క్వెరీస్ రాదు. అయినప్పటికీ, ఇవి ఇంటర్నెట్ నిర్మాణంలో కీలక భాగం. రూట్ సర్వర్‌లను నిర్వహించే సంస్థలు ఎక్కువగా స్వతంత్రంగా работают చేసినప్పటికీ, వారు పరస్పరం మరియు ICANNతో సమన్వయంగా పని చేయాల్సి ఉంటుంది.

#### టాప్-లెవల్ డొమైన్ నేమ్ సర్వర్లు / Top Level Domain Name Servers
ఒక టాప్-లెవల్ డొమైన్ సర్వర్ నిర్దిష్ట డొమైన్ ఎండింగ్‌కి చెందిన అన్ని డొమైన్‌ల సమాచారాన్ని నిర్వహిస్తుంది. వీటిని సంబంధిత టాప్-లెవల్ డొమైన్‌ను స్థాపించిన సంస్థలు మరియు టాప్-లెవల్ డొమైన్ రిజిస్ట్రీలు నడుపుతాయి. సాధారణ టాప్-లెవల్ డొమైన్‌లు (gTLD - .com, .net), దేశ-నమూనా టాప్-లెవల్ డొమైన్‌లు (ccTLD - .in, .uk).

#### అథారిటేటివ్ నేమ్ సర్వర్ / Authoritative Name Server
ఒక నిర్దిష్ట డొమైన్ కోసం సమాచారాన్ని కలిగి ఉంటుంది. A రికార్డులో ఉన్న డొమైన్ IP చిరునామాను అందిస్తుంది. CNAME రికార్డు ఉంటే ప్రత్యామ్నాయ డొమైన్ పేరును అందిస్తుంది.


#### రికర్సివ్ రిజాల్వర్స్ / Recursive Resolvers
డొమైన్ క్వెరీలో ఇది మొదటి స్టాప్. ఇది క్లయింట్ మరియు డొమైన్ సర్వర్‌ల మధ్య మద్యస్థానంగా పనిచేస్తుంది. ఒక క్వెరీకు ప్రత్యామ్నాయ డొమైన్ పేరు అందించినప్పుడు, అదే పేరు కోసం కొత్త రికర్సివ్ DNS క్వెరీను ప్రారంభిస్తుంది. రికర్సివ్ రిజాల్వర్స్ సాధారణంగా ISPలు లేదా పబ్లిక్ ప్రొవైడర్‌లచే అందించబడతాయి. అలాగే కొన్ని పబ్లిక్ సంస్థలు కూడా ఈ సేవలను అందిస్తాయి.
