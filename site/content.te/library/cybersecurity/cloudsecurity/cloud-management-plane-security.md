### క్లౌడ్ నిర్వహణ ప్లేన్ మరియు API భద్రత

క్లౌడ్ వనరులను సృష్టించడానికి, అమర్చడానికి, నిర్వహించడానికి ఉపయోగించే కన్సోల్‌లు, APIలు, సాధనాల సమాహారమే నిర్వహణ ప్లేన్. ఇది మొత్తం వాతావరణాన్ని నియంత్రిస్తుంది కాబట్టి, నిర్వహణ ప్లేన్‌ను చేజిక్కించుకోవడం ఒక్క వర్క్‌లోడ్‌ దెబ్బతినడం కంటే చాలా తీవ్రమైన పరిణామాలకు దారితీస్తుంది.

<img src="/images/en/cybersecurity/cloudsecurity/cloud-management-plane-security.png">

### పరిపాలనా స్థాయులు

- **రూట్/మాస్టర్ ఖాతా:** క్లౌడ్ ఖాతాపై అపరిమిత నియంత్రణ కలిగిన అత్యంత అధికారవంతమైన గుర్తింపు.
- **సూపర్ అడ్మిన్:** ఖాతా మొత్తానికి వర్తించే అమరికలను నిర్వహించి, యాక్సెస్‌ను అప్పగించే నిర్వాహకులు.
- **సర్వీస్ అడ్మిన్:** నిర్దిష్ట సేవలు లేదా వర్క్‌లోడ్‌లకే పరిమితమైన నిర్వాహకులు.
- **సేవలు:** వినియోగదారులు ఉపయోగించే వనరులు, అప్లికేషన్‌లు.

### ముఖ్యమైన ప్రమాదాలు

- చేజిక్కించుకున్న లేదా ఇతరులతో పంచుకున్న రూట్ ఆధారాలు
- అవసరానికి మించిన పరిపాలనా అనుమతులు
- రక్షణ లేని లేదా సరైన ధృవీకరణ లేని APIలు
- పర్యవేక్షణ లేని అమరికల మార్పులు

### సిఫార్సు చేసిన నియంత్రణలు

- రూట్ ఖాతాకు బలమైన బహుళ-దశల ధృవీకరణ అమలు చేసి, రోజువారీ పనులకు దాన్ని ఉపయోగించవద్దు
- కనిష్ఠ అనుమతి సూత్రాన్ని పాటించి, పరిపాలనా స్థాయుల మధ్య విధుల విభజన చేయండి
- ప్రతి API కాల్‌కు ధృవీకరణ, అనుమతి తనిఖీ చేసి, స్వల్పకాలిక ఆధారాలు ఉపయోగించండి
- నిర్వహణ ప్లేన్, API కార్యకలాపాలన్నింటినీ లాగ్ చేసి పర్యవేక్షించండి
- నెట్‌వర్క్ స్థానం, పరికరం, సందర్భం ఆధారంగా నిర్వహణ యాక్సెస్‌ను పరిమితం చేయండి

### భద్రతా లక్ష్యం

క్లౌడ్‌ను ఎవరు నిర్వహించగలరో పరిమితం చేసి, ప్రతి పరిపాలనా చర్య ధృవీకరించబడినదిగా, అనుమతించబడినదిగా, ఆడిట్ చేయగలిగినదిగా ఉండేలా చూడాలి. నిర్వాహక ఖాతా చేజిక్కినా దాని ప్రభావాన్ని అదుపులో ఉంచాలి.
