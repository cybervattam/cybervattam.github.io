### క్లౌడ్ భద్రత అవలోకనం

క్లౌడ్ ఆధారిత వ్యవస్థలు, డేటా, అప్లికేషన్‌లు, గుర్తింపులు, వర్క్‌లోడ్‌లను ముప్పులు, దుర్వినియోగం నుంచి రక్షించడమే క్లౌడ్ భద్రత.

క్లౌడ్ ప్రొవైడర్లు విస్తృత ప్రైవేట్ నెట్‌వర్క్‌లు, ప్రత్యేక బ్యాక్‌బోన్ కనెక్టివిటీ, పెద్ద స్థాయి మౌలిక సదుపాయాలను నిర్వహిస్తారు. అయినప్పటికీ, భద్రతను అనేక పొరల్లో రూపకల్పన చేయాలి. ప్రొవైడర్ వాతావరణంతో పాటు సంస్థల స్వంత వర్క్‌లోడ్‌లు, గుర్తింపులు, అప్లికేషన్‌లు, డేటాను కూడా రక్షించాలి.

### భద్రతలోని ప్రధాన విభాగాలు

- భౌతిక మౌలిక సదుపాయాల భద్రత
- వర్చువలైజేషన్, హైపర్‌వైజర్ భద్రత
- నెట్‌వర్క్ భద్రత
- గుర్తింపు, యాక్సెస్ నియంత్రణ
- డేటా రక్షణ, ఎన్‌క్రిప్షన్
- అనుగుణ్యత, పాలన
- ముప్పు గుర్తింపు, ప్రతిస్పందన

### క్లౌడ్ ప్లాట్‌ఫారమ్ భద్రత, క్లౌడ్‌లో సేవల భద్రత

క్లౌడ్ భద్రతను పరస్పరం పూరించే రెండు కోణాల్లో చూడవచ్చు.

#### క్లౌడ్ ప్లాట్‌ఫారమ్ భద్రత
అంతర్లీన ప్లాట్‌ఫారమ్‌ను రక్షించేందుకు ప్రధానంగా క్లౌడ్ సేవా ప్రొవైడర్ నిర్వహించే నియంత్రణలు:
- భాగస్వామ్య బాధ్యత నమూనా
- సదుపాయాలు, భౌతిక భద్రత
- హార్డ్‌వేర్ భద్రత
- వర్చువలైజేషన్ భద్రత
- క్లౌడ్ ప్రధాన కనెక్టివిటీ భద్రత
- క్లౌడ్ నిర్వహణ ప్లేన్, API భద్రత
- వ్యాపార కొనసాగింపు, విపత్తు పునరుద్ధరణ

#### క్లౌడ్‌లో అమలు చేసే సేవల భద్రత
ప్లాట్‌ఫారమ్‌పై తాము నిర్మించి నడిపే వాటిని రక్షించేందుకు వినియోగదారులు అమలు చేసే నియంత్రణలు:
- క్లౌడ్ భద్రతకు పునాది అంశాలు
- CWPP, CSPM, SSPMలను కలిగిన క్లౌడ్-నేటివ్ అప్లికేషన్ రక్షణ ప్లాట్‌ఫారమ్ (CNAPP)
- SWG, CASB, ZTNAలను కలిగిన సురక్షిత యాక్సెస్ సర్వీస్ ఎడ్జ్ (SASE)
- క్లౌడ్ గుర్తింపు, క్లౌడ్ ఇన్‌ఫ్రాస్ట్రక్చర్ ఎంటైటిల్‌మెంట్ నిర్వహణ (CIEM)
- క్లౌడ్ డేటా భద్రత
