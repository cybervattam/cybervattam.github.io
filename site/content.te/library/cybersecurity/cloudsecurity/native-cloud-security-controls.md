### క్లౌడ్ ప్రొవైడర్ స్థానిక భద్రతా నియంత్రణలు

పబ్లిక్ క్లౌడ్ సేవా ప్రొవైడర్లు వర్క్‌లోడ్‌లు, గుర్తింపులు, నెట్‌వర్క్‌లు, అప్లికేషన్‌లను సురక్షితం చేయడానికి అనేక స్థానిక భద్రతా నియంత్రణలను అందిస్తారు.

### ఉదాహరణలు

#### AWS
- IAM, SSO
- Cognito
- Security Hub
- GuardDuty
- Inspector
- Config
- CloudTrail
- CloudWatch
- Macie
- KMS, HSM
- Firewall, WAF, Shield
- Certificate Manager
- Secret Manager

#### Azure
- Active Directory
- Application Gateway
- Defender
- DDoS Protection
- HSM, Key Vault
- Front Door
- Information Protection
- Sentinel
- Security Center

### ఉద్దేశ్యం

ప్రొవైడర్ వేదికలోనే అందుబాటులో ఉండే పర్యవేక్షణ, గుర్తింపు, ఎన్‌క్రిప్షన్, అనుగుణ్యత నియంత్రణలతో క్లౌడ్ కార్యకలాపాలను సురక్షితం చేయడానికి ఈ స్థానిక సాధనాలు సంస్థలకు సహాయపడతాయి.
